Manutenir Operação Navio - A.0100.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Referentes as ações possíveis na Grid 2.
Incluir Operação Navio: Esta função permite ao usuário adicionar uma nova operação de navio no sistema TOS. Isso envolve preencher as informações necessárias sobre o navio, como nome, tipo, dimensões, data de chegada e partida, carga, entre outros dados relevantes.
Alterar Operação Navio: Essa função permite ao usuário editar informações sobre uma operação de navio já existente no sistema TOS. Isso inclui alterar as informações preenchidas anteriormente.
Excluir Operação Navio: Esta função permite ao usuário excluir uma operação de navio existente no sistema TOS. Ao selecionar essa opção, o usuário será solicitado a confirmar a exclusão.
Registrar Evento Modal: Esta função permite ao usuário registrar um evento que ocorreu durante a operação de um navio, como a movimentação de contêineres ou a chegada de um caminhão para transportar a carga. 
Realocar Fluxo Grupo: Essa função permite ao usuário reorganizar o fluxo de trabalho em um grupo de operações relacionadas. 
Fechar Operação: Esta função permite ao usuário encerrar uma operação de navio que tenha sido concluída. Isso significa que todas as atividades associadas a essa operação serão finalizadas e todas as informações relevantes serão arquivadas no sistema TOS.
Imprimir TDR: Essa função permite ao usuário imprimir o TDR (Transfer Dispatch Report), que é um relatório que contém informações sobre a movimentação de contêineres entre o navio e o terminal. Esse relatório é geralmente usado para fins contábeis e fiscais, bem como para rastrear a carga durante a operação de um navio.
6 - Botões de ação
Referentes as ações possíveis na Grid 3.
Carregar propriedades da operação navio: Descreve o processo de carregar as propriedades relacionadas à operação de um navio. Ao carregar as propriedades da operação do navio no sistema TOS, o usuário terá acesso a essas informações para gerenciar efetivamente as operações portuárias.
Excluir propriedade: permite excluir uma propriedade específica associada à operação de um navio. Pode ser necessário excluir uma propriedade se ela estiver incorreta, desatualizada ou não for mais relevante para a operação em questão. 
Incluir propriedade: permite incluir uma nova propriedade na operação de um navio. É necessario adicionar Chave e valor para completar a ação.

Pesquisar/Filtrar Operação Navio
Para buscar uma Operação específica na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Operação Navio
Esta função permite ao usuário adicionar uma nova operação de navio no sistema TOS. Isso envolve preencher as informações necessárias sobre o navio, como nome, tipo, dimensões, data de chegada e partida, carga, entre outros dados relevantes.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

Redobrigatório 
Busque o transporte movimento (que deve estar cadastrado anteriormente). 
As informações da vigem serão preenchidas nos campos em amarelo. 
Berço: Busque pelo fluxo grupo. 
Finalidade: selecione entre Movimentação de carga, Abastecimento e outros. 
Bordo: Selecione entre bordo e Estibordo. 
BlueOpcional 
Datas de Previsão de Pátio a bordo, Previsão atracação, inicio da operação, termino da operação, desatracação e inicio da janela. 
Calado de entrada*: Ex: 1132
*O termo "calado de entrada" é usado em referência à profundidade da água necessária para que um navio possa entrar em um porto ou canal sem encalhar ou sofrer danos. O calado de entrada é determinado pela distância vertical entre a linha d'água do navio e a parte mais baixa da embarcação (a quilha, por exemplo) quando o navio está totalmente carregado.
Após preencher as informações clique em Ok para salvar o usuário no banco.
Alterar Operação Navio
Essa função permite ao usuário editar informações sobre uma operação de navio já existente no sistema TOS. Isso inclui alterar as informações preenchidas anteriormente, como a data de chegada, a carga ou o navio em si.
Para alterar as informações de uma operação de navio específica, siga as etapas abaixo:
Na grade de dados 2, selecione a operação de navio que você deseja modificar. Verifique se você está trabalhando com a linha correta na grade para evitar alterações incorretas.

Localize o botão de ação "ALTERAR" e clique nele. Esse botão geralmente está posicionado próximo à operação selecionada ou pode estar disponível em uma barra de ferramentas ou menu suspenso específico para ações de edição.

Uma vez que você tenha clicado no botão "ALTERAR", uma janela ou formulário de edição será aberto, permitindo que você faça as alterações desejadas nas informações da operação do navio. 

Dentro da janela ou formulário de edição, localize os campos ou seções relevantes que contêm as informações que você deseja alterar. Edite as informações conforme necessário, como nome do navio, tipo de carga, data de chegada, porto de origem, entre outros detalhes.

Após realizar as alterações, verifique se todas as informações estão corretas e completas.

Por fim, confirme as alterações clicando em um botão como "Salvar" ou "Confirmar". Essa ação atualizará as informações da operação do navio no sistema TOS com os novos dados que você modificou.

Certifique-se de seguir esses passos com atenção para garantir que as alterações sejam feitas corretamente e evite modificar informações importantes por engano.
Excluir Operação Navio
Esta função permite ao usuário excluir uma operação de navio existente no sistema TOS. Ao selecionar essa opção, o usuário será solicitado a confirmar a exclusão e, em seguida, o sistema removerá todas as informações relacionadas a essa operação de navio.
Para excluir uma operação de navio específica, siga as etapas abaixo:
Na grade de dados 2, localize a operação de navio que você deseja excluir. Certifique-se de selecionar a linha correta na grade para evitar exclusões incorretas.

Uma vez que você tenha identificado a operação de navio a ser excluída, localize o botão de ação "Excluir" e clique nele. Esse botão normalmente está posicionado próximo à operação selecionada ou pode estar disponível em uma barra de ferramentas ou menu suspenso específico para ações de exclusão.

Após clicar no botão "Excluir", uma confirmação pode ser solicitada para garantir que você realmente deseja prosseguir com a exclusão da operação do navio. Certifique-se de ler atentamente a mensagem de confirmação e verifique se você selecionou corretamente a operação que pretende excluir.

Se estiver seguro de que deseja excluir a operação de navio selecionada, confirme a exclusão clicando em um botão como "Confirmar" ou "Excluir". Isso concluirá a ação de exclusão.

Lembre-se de ter cuidado ao realizar essa operação, pois a exclusão de uma operação de navio pode ter consequências irreversíveis. Certifique-se de selecionar corretamente a operação a ser excluída antes de prosseguir com a ação e verifique se você possui permissões adequadas para realizar essa tarefa no sistema TOS.
Registrar Evento Modal
Esta função permite ao usuário registrar um evento que ocorreu durante a operação de um navio, como a movimentação de contêineres ou a chegada de um caminhão para transportar a carga. Isso ajuda a manter um registro preciso de todas as atividades que ocorrem no terminal.
Selecione a operação de navio desejada.

Clique no botão de ação "Registrar Evento Modal".

Será aberto um popup para preenchimento das informações.

Selecione o evento: Chegada, inicio, termino, saida, pratico a bordo, atracação ou desatracação.
Informe a data e Hora do evento Modal: DD/MM/YYYY HH:MM.
Realocar Fluxo Grupo
Essa função permite ao usuário reorganizar o fluxo de trabalho em um grupo de operações relacionadas. Por exemplo, é possível mover um contêiner de uma pilha de espera para outra ou reorganizar a fila de caminhões aguardando para carregar ou descarregar.
Selecione o registro de operação que você deseja realocar.

Clique no botão correspondente à ação de realocação.

Será aberto um popup para preenchimento das informações.

Berço: Realize uma busca pelo berço cadastrado no sistema. Informe a sigla correspondente.
Os fluxos de operação da realocação serão exibidos no segundo campo.
Revise e confirme os fluxos de operação da realocação exibidos.
Clique em "OK" para confirmar a realocação.
Fechar Operação
Esta função permite ao usuário encerrar uma operação de navio que tenha sido concluída. Isso significa que todas as atividades associadas a essa operação serão finalizadas e todas as informações relevantes serão arquivadas no sistema TOS.
Selecione o registro de operação que você deseja fechar.

Clique no botão correspondente à ação de fechamento.

Será aberto um popup de confirmação.

No popup de confirmação, você será solicitado a confirmar a ação de fechamento do registro de operação selecionado. Certifique-se de revisar todas as informações relevantes antes de prosseguir.
Imprimir TDR 
Essa função permite ao usuário imprimir o TDR (Transfer Dispatch Report), que é um relatório que contém informações sobre a movimentação de contêineres entre o navio e o terminal. Esse relatório é geralmente usado para fins contábeis e fiscais, bem como para rastrear a carga durante a operação de um navio.
Selecione o registro de operação no qual deseja imprimir o TDR.

Clique no botão de ação correspondente à impressão do TDR.

As informações serão geradas e disponibilizadas para visualização e impressão.

Carregar propriedades da operação navio
Descreve o processo de carregar as propriedades relacionadas à operação de um navio. As propriedades podem incluir informações como nome do navio, tipo de carga, capacidade, data de chegada, porto de origem, porto de destino, entre outros detalhes relevantes. 
Selecione o registro desejado na Grid 2.

Role a tela até a Grid 3 (Propriedades).

Clique no botão "Carregar" para recuperar as informações.

Cadastro de propriedade
Esta seção  inclui uma nova propriedade na operação de um navio. Pode ser necessário adicionar uma propriedade adicional para capturar informações adicionais sobre o navio, carga ou requisitos operacionais específicos.
Selecione o registro de operação desejado na Grid 2.

Role a tela até a Grid 3.

Informe a chave e o valor da propriedade que deseja incluir.

Clique no botão de ação "Incluir".

Ao clicar no botão "Incluir", a propriedade com a chave e o valor especificados será adicionada ao registro de operação selecionado. Certifique-se de fornecer as informações corretas e completas para garantir uma inclusão adequada.
Excluir propriedade
Essa seção excluir uma propriedade específica associada à operação de um navio. Pode ser necessário excluir uma propriedade se ela estiver incorreta, desatualizada ou não for mais relevante para a operação em questão. 
Selecione a propriedade que deseja excluir.

Clique no botão de ação "Excluir".

Confirme a ação.
