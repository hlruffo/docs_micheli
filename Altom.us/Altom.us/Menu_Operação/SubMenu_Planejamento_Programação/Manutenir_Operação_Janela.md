Manutenir Operação Janela - A.0102.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
4 - Botões de ação
Refentes as ações possíveis na Grid 2.
Incluir Operação janela: oferece ao usuário a possibilidade de adicionar uma nova janela de operação ao sistema. Ao selecionar essa função, é aberta uma tela onde é possível inserir as informações relevantes para a criação da nova janela, como nome, configurações, parâmetros e preferências específicas.
Alterar Operação Janela: permite ao usuário modificar as configurações e parâmetros associados a uma janela específica. Essa função possibilita ajustar as preferências e os detalhes de operação da janela conforme as necessidades e requisitos do sistema.
Excluir Operação Janela: permite ao usuário remover permanentemente uma janela existente no sistema. Ao selecionar essa opção, todas as informações e atividades associadas à janela em questão serão excluídas. 
Iniciar Operação Janela: é utilizada para iniciar as atividades associadas a uma determinada janela do sistema. Ao selecionar essa função, a janela selecionada entra em funcionamento, permitindo o início das operações e o processamento dos dados relacionados.
Parar Operação Janela: é utilizada para interromper temporariamente as atividades e o processamento de uma janela específica. Ao selecionar essa opção, a janela selecionada é pausada, suspendendo as operações em andamento até que a função "Iniciar Operação Janela" seja acionada novamente.
Terminar Operação Janela: encerra definitivamente as atividades e o funcionamento de uma janela específica. Ao selecionar essa função, a janela selecionada é finalizada, encerrando todas as operações e liberando os recursos associados a ela.

Pesquisar/Filtrar uma Operação Janela
Para buscar uma Janela específica na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Operação janela
oferece ao usuário a possibilidade de adicionar uma nova janela de operação ao sistema. Ao selecionar essa função, é aberta uma tela onde é possível inserir as informações relevantes para a criação da nova janela, como nome, configurações, parâmetros e preferências específicas.
Alterar Operação Janela
permite ao usuário modificar as configurações e parâmetros associados a uma janela específica. Essa função possibilita ajustar as preferências e os detalhes de operação da janela conforme as necessidades e requisitos do sistema.
Excluir Operação Janela
permite ao usuário remover permanentemente uma janela existente no sistema. Ao selecionar essa opção, todas as informações e atividades associadas à janela em questão serão excluídas. 
Iniciar Operação Janela
é utilizada para iniciar as atividades associadas a uma determinada janela do sistema. Ao selecionar essa função, a janela selecionada entra em funcionamento, permitindo o início das operações e o processamento dos dados relacionados.
Para iniciar uma operação específica, siga os passos abaixo:
Pesquise a operação desejada: Utilize a função de pesquisa para localizar a operação que você deseja iniciar. Digite o nome ou utilize filtros disponíveis para encontrar a operação desejada de forma rápida e eficiente.

Selecione a operação: Após encontrar a operação desejada na lista de resultados da pesquisa, clique sobre ela para selecioná-la. Isso permitirá que você acesse as opções e ações relacionadas a essa operação específica.

Clique no botão de ação "Iniciar": uma vez selecionada a operação desejada, localize o botão de ação "Iniciar" e clique nele. Essa ação dará início ao processo ou atividade associada à operação selecionada, permitindo que você comece a executar as tarefas designadas ou iniciar o fluxo de trabalho correspondente.

Parar Operação Janela
é utilizada para interromper temporariamente as atividades e o processamento de uma janela específica. Ao selecionar essa opção, a janela selecionada é pausada, suspendendo as operações em andamento até que a função "Iniciar Operação Janela" seja acionada novamente.
Terminar Operação Janela
encerra definitivamente as atividades e o funcionamento de uma janela específica. Ao selecionar essa função, a janela selecionada é finalizada, encerrando todas as operações e liberando os recursos associados a ela.
