Na tela Fluxo Buffer - A.0108.00 é possível 
Processar Fluxo Buffer
Função que permite ao usuário do sistema TOS+ processar as operações de entrada e saída de veículos no terminal. A tela de Fluxo transporte é utilizada apenas para processar esses Fluxos. 
obrigatórioRed
Entrada/Saída: Informe se o fluxo a ser processado é de entrada ou saída.
Placa do veículo: Informe a placa do veículo vinculada ao processo.
Motorista: Informe o motorista correspondente.
O campo nome é preenchido automaticamente.
