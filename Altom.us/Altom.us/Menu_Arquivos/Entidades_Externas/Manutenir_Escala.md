Manutenir Escala - A.0126.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis da Grid 2.
Comparar BAPLIE: A funcionalidade "Comparar BAPLIE" permite ao usuário comparar duas versões do arquivo BAPLIE, que contém informações sobre a estiva e estocagem de contêineres em um navio. Ao selecionar essa opção, o sistema irá realizar a comparação entre as duas versões do arquivo BAPLIE, identificando diferenças e fornecendo um resumo das alterações ocorridas. Isso ajuda a verificar e validar eventuais modificações realizadas nos planos de estiva do navio.
Transferir base: A funcionalidade "Transferir base" permite ao usuário transferir dados ou informações de uma base de dados para outra. Ao selecionar essa opção, o usuário poderá definir se a transferência irá ocorrer como importação e/ou exportação. O sistema irá executar a transferência de forma segura e eficiente, garantindo que as informações sejam devidamente movidas de uma base para outra.
6 - Botão de ação 
Referente a ação possível na Grid 3. 
Carregar Arquivo de Mensagem: Essa funcionalidade permite ao usuário carregar mensagens específicas relacionado a uma escala de operações no terminal.

Pesquisar/Filtrar uma Escala
Para encontrar uma Escala específica basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Comparar BAPLIE
A funcionalidade "Comparar BAPLIE" permite ao usuário comparar duas versões do arquivo BAPLIE, que contém informações sobre a estiva e estocagem de contêineres em um navio. Ao selecionar essa opção, o sistema irá realizar a comparação entre as duas versões do arquivo BAPLIE, identificando diferenças e fornecendo um resumo das alterações ocorridas. Isso ajuda a verificar e validar eventuais modificações realizadas nos planos de estiva do navio.
Selecione o registro de escala desejado.

Clique no botão de ação "Comparar BAPLIE".

Um pop-up será aberto para permitir a pesquisa do ID do BAPLIE a ser comparado.

No pop-up, pesquise e selecione o ID do BAPLIE desejado.

Após selecionar o ID do BAPLIE, clique em "COMPARAR" para iniciar a comparação.

O sistema realizará a comparação entre os dois BAPLIEs, identificando as diferenças e apresentando um resumo das alterações.

Analise o resultado da comparação para entender as modificações ocorridas entre os BAPLIEs selecionados.

Transferir base
A funcionalidade "Transferir base" permite ao usuário transferir dados ou informações de uma base de dados para outra. Ao selecionar essa opção, o usuário poderá definir se a transferência irá ocorrer como importação e/ou exportação. O sistema irá executar a transferência de forma segura e eficiente, garantindo que as informações sejam devidamente movidas de uma base para outra.
Selecione o registro de escala desejado.

Clique no botão de ação "Transferir base".

Um pop-up será aberto para permitir a seleção do tipo de transferência desejada.

No pop-up, escolha entre as opções de importação e/ou exportação, dependendo do tipo de transferência que você deseja realizar.

Após selecionar o tipo de transferência desejada, clique no botão de ação "Transferir" para concluir a ação.

O sistema iniciará o processo de transferência de acordo com as configurações definidas.

Aguarde enquanto o sistema realiza a transferência dos dados do registro de escala de acordo com as opções selecionadas.

Carregar Arquivo de Mensagem
Essa funcionalidade permite ao usuário carregar mensagens específicas relacionado a uma escala de operações no terminal.
Selecione o registro de escala desejado na grid 2.

Role a tela até a grid 3, onde a mensagem será carregada.

Localize o botão de ação "Carregar arquivo de mensagem".

Clique no botão "Carregar arquivo de mensagem".

O sistema processará as informações do arquivo de mensagem e as carregará na grid 3.

As informações relevantes contidas no arquivo de mensagem serão exibidas, fornecendo detalhes adicionais sobre o registro de escala selecionado.
