Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botão de ação
Referente a ação possível na Grid 2.
Gerar Arquivo: 
O recurso de "Gerar arquivo" permite que o usuário crie um arquivo contendo informações das entidades externas cadastradas no sistema TOS. 
6 - Botões de ação que resultam informações da Grid 2
Esse botão está presente nas duas abas da Grid 3 e tem a função de carregar dados, tanto para a aba de Ação quanto para a aba de Log. Ao clicar no botão, o sistema irá carregar as informações da aba selecionada e exibi-las na Grid 3. Esse recurso é útil para visualizar o histórico de ações realizadas no sistema ou para verificar informações específicas de um determinado registro.

Pesquisar/Filtrar Arquivo
Para encontrar um Arquivo, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Gerar Arquivo
O recurso de "Gerar arquivo" permite que o usuário crie um arquivo contendo informações das entidades externas cadastradas no sistema TOS. Para utilizar esse recurso, o usuário deve seguir os seguintes passos:
Acesse a tela de "Manutenção de Arquivo para Entidades Externas".

Utilize o filtro de pesquisa para localizar as entidades externas desejadas.

Selecione as entidades externas que deseja incluir no arquivo.

Clique no botão "Gerar arquivo".

O sistema irá gerar um arquivo contendo as informações das entidades externas selecionadas.

noteO arquivo gerado poderá ser salvo em diferentes formatos, dependendo das opções disponíveis no sistema. Esse recurso é útil para exportar dados de entidades externas para outros sistemas ou para fins de backup.

Para gerar informações de ação e log, siga estes passos:
Na Grid 2, selecione o registro correspondente ao qual deseja carregar os dados de ação ou log.

Role a página para chegar na Grid 3.

Selecione a aba correspondente, seja de Ação ou de Log.

Clique no botão de ação "Carregar" para carregar os dados na Grid 3.

Ao seguir esses passos, as informações de ação ou log correspondentes ao registro selecionado serão carregadas na Grid 3, permitindo ao usuário visualizar as atividades realizadas em relação a esse registro. Esse recurso é útil para monitorar o histórico de alterações e atividades relacionadas a determinado registro no sistema.
