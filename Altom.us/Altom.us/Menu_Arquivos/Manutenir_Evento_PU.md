Pesquisar/Filtrar um Evento
Para encontrar um evento, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Reenviar Evento Portal Único
Essa ação permite reprocessar mensagem de EventoPU. Siga os passo abaixo para executar essa ação corretamente.
Localize o evento que deseja reprocessar usando a ferramenta de filtro.

Os resultados devem aparecer no campo 2 (Evento Portal Único).

Selecione o evento clicando sobre ele.

Clique no botão de ação "Reenviar".

O sistema processará a ação e retornará uma mensagem confirmando o envio.

Carregar dados Evento Portal Único
Para carregar dados relacionados a um evento com informações de estado, ocorrência e mensagem no campo "Ação", é preciso seguir as etapas abaixo:
Selecione um registro de evento na grid 2.

Após a seleção do registro de evento, navegue para a grid 3 e clique no botão de ação "Carregar dados do Evento PU".
