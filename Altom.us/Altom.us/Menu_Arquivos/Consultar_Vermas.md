Consulta Vermas - A.0130.00
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2 e 3
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.

Pesquisar/Filtrar Arquivo Vermas
Para encontrar um Arquivo Vermas especifico, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Transferir Vermas
Para transferir o Arquivo Vermas primeiro é necessário pesquisar pelo arquivo que deseja transferir. Utilize a ferramenta de filtro para isso pesquisando por arquivo ou numero do container.  

Após localizar o arquivo basta selecioná-lo na grid 2 e clicar no botão de ação Transferir Vermas. 

Após concluir a ação, uma mensagem de confirmação irá aparecer na tela: 

Carregar dados Container Vermas
Selecione o arquivo Vermas que você deseja visualizar as informações na grid 2.

Role a tela até a grid 3.

Clique no botão de ação "Carregar" para carregar os dados do contêiner, incluindo peso, lacre e estiva associados ao arquivo Vermas selecionado.
