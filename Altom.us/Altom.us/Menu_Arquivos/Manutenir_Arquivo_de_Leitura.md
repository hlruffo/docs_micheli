Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2 e 3
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis na Grid 2.
Upload de arquivo: Essa funcionalidade permite ao usuário realizar o upload de arquivos para o sistema. É possível fazer o upload de arquivos dos seguintes tipos: BAPLIE, SISCARGA, COPARN, VERMAS e MOVINS. Ao selecionar essa opção, o usuário pode escolher um arquivo do seu dispositivo local e enviá-lo para o sistema. Isso permite que o sistema processe e utilize as informações contidas no arquivo para realizar as operações necessárias.
Processar arquivo: Essa funcionalidade permite ao usuário realizar o processamento de um arquivo específico, no formato SISCARGA. Ao selecionar essa opção, o sistema irá processar as informações contidas no arquivo SISCARGA, executando as ações necessárias com base nos dados fornecidos. Esse processamento pode incluir a atualização de informações, a geração de documentos ou qualquer outra ação relacionada ao arquivo SISCARGA.
6 - Botão de ação
O botão de ação "Carregar Arquivo de Mensagem" está disponível no registro do campo de leitura de Mensagem (grid 3) para a funcionalidade de carregar um arquivo de mensagem.
Ao selecionar esse botão, o usuário poderá escolher e carregar um arquivo de mensagem específico associado ao registro em questão. Essa ação permite que o sistema processe o arquivo de mensagem, capturando as informações relevantes e realizando as operações correspondentes com base nos dados contidos no arquivo.

Pesquisar/Filtrar um Arquivo de Leitura
Para encontrar um Arquivo de Leitura, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Upload de arquivo
Essa funcionalidade permite ao usuário realizar o upload de arquivos para o sistema. É possível fazer o upload de arquivos dos seguintes tipos: BAPLIE, SISCARGA, COPARN, VERMAS e MOVINS. 
Ao selecionar essa opção, o usuário pode escolher um arquivo do seu dispositivo local e enviá-lo para o sistema. Isso permite que o sistema processe e utilize as informações contidas no arquivo para realizar as operações necessárias.
Clique no botão de ação "Upload de arquivo".

Após clicar no botão, um pop-up será aberto para permitir a inserção das informações necessárias e a seleção do arquivo a ser enviado.

No pop-up, preencha as informações solicitadas, como nome do arquivo, descrição ou qualquer outro detalhe relevante.

Em seguida, clique no botão de ação "Subir arquivo" para iniciar o processo de upload.

Aguarde enquanto o sistema processa e realiza o upload do arquivo.

Após o upload ser concluído com sucesso, o arquivo estará disponível no sistema para uso e referência conforme necessário.

Os tipos de arquivo BAPLIE, SISCARGA, COPARN, VERMAS e MOVINS são formatos de arquivos utilizados na indústria do transporte marítimo e logística para troca de informações relacionadas a cargas, movimentos de contêineres e comunicação entre diferentes sistemas.
BAPLIE (Bay Plan/Stowage Plan Information Exchange)
É um formato de arquivo utilizado para trocar informações sobre o plano de estiva e estocagem de contêineres em um navio. Ele contém detalhes sobre a localização dos contêineres no navio, suas dimensões, pesos, identificadores e outras informações relevantes.

SISCARGA
É um formato de arquivo específico para o sistema SISCARGA, utilizado para trocar informações sobre movimentações de cargas em terminais e portos. Pode conter detalhes sobre os embarques, cargas, contêineres, movimentos, entre outros dados relacionados à logística portuária.

COPARN (Container Announcement)
É um formato de arquivo utilizado para fornecer informações antecipadas sobre a chegada de contêineres em um terminal ou porto. Contém dados como o número de identificação do contêiner, detalhes do transportador, estimativa de chegada, entre outros.

VERMAS (Vessel Monitoring Advice)
É um formato de arquivo utilizado para trocar informações sobre o monitoramento de navios, como a posição geográfica atual, velocidade, rumo, entre outros dados relevantes. É utilizado para rastrear e monitorar o movimento de navios em tempo real.

 MOVINS (Movement Instruction)
É um formato de arquivo utilizado para fornecer instruções de movimentação de contêineres ou cargas em terminais, ou portos. Pode conter informações sobre o transporte, destino, manuseio, prioridade e outros detalhes necessários para realizar as movimentações com eficiência.

Processar arquivo
Essa funcionalidade permite ao usuário realizar o processamento de um arquivo específico, no formato SISCARGA. Ao selecionar essa opção, o sistema irá processar as informações contidas no arquivo SISCARGA, executando as ações necessárias com base nos dados fornecidos. Esse processamento pode incluir a atualização de informações, a geração de documentos ou qualquer outra ação relacionada ao arquivo SISCARGA.
Selecione o arquivo SISCARGA desejado.

Clique no botão de ação "Processar arquivo".

O sistema iniciará o processamento do arquivo SISCARGA selecionado.

Aguarde enquanto o sistema executa as ações necessárias com base nas informações contidas no arquivo.

Uma vez concluído o processamento, as operações relacionadas ao arquivo SISCARGA serão realizadas conforme definido no sistema.

Carregar Arquivo de mensagem
Essa ação permite que o sistema processe o arquivo de mensagem, capturando as informações relevantes e realizando as operações correspondentes com base nos dados contidos no arquivo.
Selecione o registro do arquivo de leitura desejado na grid 2.

Role a tela até a grid 3, onde as mensagens correspondentes serão exibidas.

Localize o botão de ação "Carregar arquivo de mensagem".

Clique no botão "Carregar arquivo de mensagem".

O sistema processará as informações do arquivo selecionado e exibirá as mensagens correspondentes na grid 3.
