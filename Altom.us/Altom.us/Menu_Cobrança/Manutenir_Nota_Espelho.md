Pesquisar/Filtrar Nota Espelho
Para buscar uma Nota específica na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cancelar Nota Espelho
Essa função permite aos usuários cancelarem uma nota espelho previamente criada, quando necessário.
Ao selecionar a opção de cancelamento de uma nota espelho, o sistema exibe uma confirmação para garantir a precisão da ação. Após a confirmação, a nota espelho é marcada como cancelada no sistema, indicando que ela não é mais válida e não deve ser considerada nas operações portuárias em andamento.
O cancelamento de uma nota espelho pode ser necessário em situações como erros de registro, mudanças nas informações da carga, alterações no status do contêiner, cancelamento do transporte, entre outros cenários em que a nota espelho precise ser anulada.
Detalhar nota espelho
A funcionalidade de Detalhar Nota Espelho é essencial para fornecer aos usuários uma visão abrangente e detalhada das informações registradas para uma determinada nota espelho. 
Ao utilizar a opção de Detalhar Nota Espelho, os usuários podem verificar e confirmar as informações registradas, realizar consultas específicas e obter um panorama completo da nota espelho. Essa funcionalidade é fundamental para a verificação da precisão dos dados, bem como para a tomada de decisões baseadas nas informações contidas na nota espelho.

Carregar Item Espelho
Para utilizar a opção, basta seguir os seguintes passos:
Na Grid 2, selecione a nota espelho desejada.

Navegue para a Grid 3, onde serão exibidos os detalhes da nota selecionada.

Clique no botão de ação "Carregar" para acessar todas as informações relacionadas à nota.

Essa funcionalidade permite aos usuários obterem uma visão completa e precisa dos dados registrados na nota espelho selecionada. Através dessa visualização detalhada, é possível verificar e confirmar informações, realizar consultas específicas e tomar decisões embasadas nos dados apresentados.
Integrar ERP
Essa função permite a integração entre o sistema TOS e um sistema ERP (Enterprise Resource Planning). 
Ao selecionar essa opção, o sistema TOS estabelece uma conexão com o ERP, possibilitando a troca de informações relevantes entre os dois sistemas. Essa integração visa sincronizar os dados da nota espelho com o ERP. 
Para incluir basta informar a nota cobrança. Primeiro informe a data de vencimento dessa nota, os campos clientes e nota cobrança serão liberados para preenchimento. 
Carregar nota cobrança
Essa função permite aos usuários associar informações de cobrança a uma nota espelho específica. Ao selecionar essa opção, o sistema apresenta campos para preenchimento dos dados relacionados à cobrança, como valor a ser cobrado, prazo de pagamento, forma de pagamento, entre outros. Essa funcionalidade possibilita o registro preciso das informações financeiras referentes à operação portuária, facilitando o controle e a gestão dos aspectos financeiros envolvidos.
Carregar dado nota espelho
Essa função permite aos usuários carregar os dados gerais de uma nota espelho específica. Ao selecionar essa opção, o sistema exibe campos para preencher informações como número da nota, data de emissão, detalhes da carga, entre outros dados relevantes. 
Pesquisar Nota excluída
Essa função permite aos usuários pesquisar e recuperar notas espelho previamente excluídas do sistema. Ao selecionar essa opção, o sistema exibe campos de pesquisa, cliente, usuário responsável pela exclusão, faixa de data de exclusão e o número da Nota cobrança.
