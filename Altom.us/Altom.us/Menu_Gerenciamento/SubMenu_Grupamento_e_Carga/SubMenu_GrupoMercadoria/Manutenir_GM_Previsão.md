Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis da Grid 2.
Incluir - Cadastro de um novo GM Previsão
Alterar - Alterar dados pré-cadastrados nessa tela. 
Excluir - Excluir GM Previsão pré-existente. 
6 - botão de ação Grid 3
Após selecionar um GM Previsão na Grid 2 (GM Previsão), desça até a Grid 3 (Container Previsão) e clique no botão “Carregar” para exibir as informações do Número do Contêiner, ID do Movimento do Contêiner e ID do Trânsito do Contêiner na Grid.

Pesquisar/Filtrar um GM Previsão
Para encontrar um GM Previsão, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão “PESQUISAR” para obter todas as informações pré-existentes na tela.
Cadastro de um GM Previsão
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Orientações preliminares
Pesquise o Grupo mercadoria na Grid de Filtro.

Obtenha o Movimento ID na Grid 3.

Volte para Grid 2 e clique no botão incluir(+).

Alterar dados de um GM Previsão
Na Grid 2, após localizar e selecionar o GM que deseja alterar, clique no botão 'Alterar' e faça as alterações nas informações desejadas.
Excluir GM Pré-existente
Para excluir um GM, selecione-o e clique no botão 'Excluir'.
Carregar dados de um GM Previsão
Após selecionar o GM que deseja carregar (Grid 2 - GM Previsão) na (Grid 3 - Container Previsão), clique no botão de ação ‘carregar' e execute a ação desejada para a informação carregada.
