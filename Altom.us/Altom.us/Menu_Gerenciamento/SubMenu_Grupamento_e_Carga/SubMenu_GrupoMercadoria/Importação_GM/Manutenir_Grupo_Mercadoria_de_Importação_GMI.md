Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima. 
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+. 
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro. 
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.

7 - Botão de ação Detalhar 
Pode ser acionado após selecionar um registro da Grid 2.
O botão "DETALHAR" na tela de manutenção do grupo Mercadoria Importação (GMI) tem como objetivo fornecer informações mais detalhadas sobre um determinado grupo de mercadorias de importação. Ao clicar nesse botão, os usuários podem obter uma visão aprofundada das configurações, atributos e características do grupo selecionado.
8 - Abas
Abas separados por Container, Carga e Granel referentes aos resultados da Grid 2. 
Cada aba contem um campo de pesquisa, onde se pode pesquisar por Número do Container, Id da Carga e Id do Granel, respectivamente.

Pesquisar/Filtrar um GMI
Para buscar um GMI específico na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar GMI
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

Campos de cadastro
obrigatórioRed 
Id : Campo de controle com a referência do GMI no produto. Preenchido automaticamente pelo sistema após finalização do cadastro. 
Status: Traz o status do grupo. Que pode variar entre Realizado e Em Realização.
N° da viagem: número da viagem cadastrada. Ex: 999S
Tipo: Tipo de mercadoria. Ex: BOOKING. 
Modalidade: Buscar entre as opções disponíveis (LONGO CURSO, MERCOSUL e CABOTAGEM).
N° do Grupo Mercadoria: Número do grupo gerado no cadastro do passo anterior. 
Data da emissão: dd/mm/yyyy e HH:MM.
Consignatário: Buscar pelo cliente consignatário. 
Porto de origem: neste campo deve ser inserida a sigla do porto de origem da carga, no exemplo fornecido, "USNYC", que se refere ao porto de Nova York, nos Estados Unidos.
Próximo porto: Buscar porto pela sigla vigente.
Porto de destino final: Buscar porto pela sigla. Ex: BRRIO.
Armador: Pesquisar armador correspondente.
opcionalBlue 
Descritivo dos camposTipo de movimento: este campo deve ser preenchido com a opção "EXPORTAÇÃO CONTAINER CHEIO", que indica que o movimento envolve o transporte de containers cheios para exportação.
Localidade: este campo pode ser utilizado para especificar a localidade ou endereço onde a carga será entregue ou retirada.
Armador: este campo deve ser preenchido com o nome ou código da empresa responsável pelo transporte marítimo da carga.
Slot Charterer: este campo é utilizado para especificar o nome ou código do slot charterer, que é a empresa que aluga o espaço no navio para transportar a carga.
Agência de Carga: este campo deve ser preenchido com o nome ou código da agência de carga responsável pela logística da operação.
Designado: este campo pode ser utilizado para especificar o nome ou código do responsável pelo grupo de mercadorias.
Instrução especial: este campo é utilizado para inserir qualquer instrução especial que possa ser necessária para a operação logística.
Área: este campo deve ser preenchido com a área correspondente ao tipo de carga em questão, como "Primaria", que indica que se trata de uma carga de produtos primários.
Obs.: Para achar a viagem usar o nome do navio. 
Os campos em amarelo não precisam ser preenchidos, pois serão buscados pelo sistema de forma automática.
Alterar GMI
Na Grid 2, após localizar e selecionar o GMI que deseja alterar, clique no botão 'Alterar' e faça as alterações nas informações desejadas.
Excluir GMI
Para excluir um GMI, selecione-o e clique no botão 'Excluir'.
Pesquisar e carregamento de Contêineres que fazem parte de um GMI
Após selecionar o GMI na Grid 2, role a tela para a Grid 3 e certifique-se de que está na aba 'Contêiner'. Em seguida, clique no botão 'Carregar Dado Contêiner' do grupo de exportação ou no botão 'Carregar Dado Carga Solta' do contêiner, dependendo do tipo de operação desejado. Você também pode pesquisar por um número específico de contêiner para o GMI.
Pesquisar e carregamento das Cargas que fazem parte de um GMI
Após selecionar o GMI na Grid 2, role a tela para a Grid 3 e certifique-se de que está na aba 'Cargas'. Em seguida, clique no botão 'Carregar Carga dado GMI' do grupo de exportação ou no botão 'Carregar Dado Carga Solta' do contêiner, dependendo do tipo de operação desejado. Você também pode pesquisar pelo ID especifico da carga. 
Pesquisar e carregamento do(os) Granel que faz parte de um GMI
Após selecionar o GMI na Grid 2, role a tela para a Grid 3 e certifique-se de que está na aba 'Granel'. Em seguida, clique no botão 'Carregar Carga dado Granel', dependendo do tipo de operação desejado você também pode pesquisar pelo ID especifico do Granel.
