Manutenir Container (Movimento) - A.0056.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro. 
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela. 
5 - Botões de ação
Refentes as ações possíveis da Grid 2.
Incluir: esse ponto refere-se à ação de adicionar um novo registro de contêiner no sistema TOS. Para incluir um novo contêiner, o usuário deve preencher todas as informações necessárias, como número de contêiner, tipo de contêiner, peso, data de chegada, entre outras.
Alterar: este ponto se refere à possibilidade de atualizar as informações de um contêiner já cadastrado no sistema TOS. É necessário selecionar o contêiner desejado e realizar as alterações necessárias, como correções de dados ou atualizações de status.
Excluir: este ponto se refere à possibilidade de remover um contêiner já cadastrado no sistema TOS. É importante lembrar que a exclusão de um contêiner pode afetar outras informações relacionadas, como movimentações ou documentações associadas a ele.
Carregar dados de um Grupo mercadoria: este ponto se refere à funcionalidade de importar dados de um grupo de mercadorias já cadastrado no sistema TOS para facilitar o preenchimento de informações sobre o contêiner. Essa ação pode economizar tempo e evitar erros manuais.
Carregar dados de uma carga solta: este ponto se refere à funcionalidade de importar dados de uma carga solta já cadastrada no sistema TOS para preencher informações sobre o contêiner. Essa ação pode ajudar a agilizar o processo de cadastro e garantir a precisão dos dados.
Carregar dados de um contêiner: este ponto se refere à possibilidade de importar informações de outro contêiner já cadastrado no sistema TOS para preencher automaticamente as informações de um novo contêiner.
Associar Grupo selecionado ao Contêiner Movimento: este ponto se refere à ação de vincular um grupo de mercadorias a um contêiner em movimento no sistema TOS. Isso pode ajudar a gerenciar melhor as informações de transporte e garantir que as cargas estejam corretamente identificadas.
Desacoplar Genset: este ponto se refere à ação de remover um Gerador Elétrico Auxiliar (Genset) de um contêiner. Essa ação é necessária quando o contêiner não precisa mais de energia para refrigeração ou quando o Genset precisa ser usado em outro contêiner.

Sintética

Pesquisar/Filtrar um Container
Para encontrar um Container, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Cadastro de um Container
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Orientações preliminares
Antes de iniciar o cadastro pesquise pelo código do Grupo Mercadoria no filtro (F1.);

Selecione o resultado da pesquisa e logo em seguida vá a GRID 2 na aba Container e carregue as informações (Fig 2.). 

Selecione o resultado gerado,  clique no botão de ação INCLUIR.

Campos de Preenchimento
obrigatórioRed 
N° do container: número do container. Caso existe mais de 1 container a operação deve se repetir. 
Código ISO: informe o código correspondente [International Organization for Standardization].
Tara: Informe a Tara correspondente. Ex: 3900 
Peso Total: Ex: 32000
Data de fabricação: dd/mm;yyyy HH:MM
Clique em OK e o sistema gravá aa informações no banco.
Cadastro de um Container Movimento
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Orientações preliminares
Utilize a grid de Filtro para pesquisar o Grupo de Mercadoria desejado;

Selecione o resultado desejado na grid 2;

Acesse a aba "Grupo Mercadoria" na grid 3;

Carregue os dados do Grupo de Mercadoria selecionado na grid 2;

Volte para a grid 2;

Clique no botão "INCLUIR" para adicionar o novo contêiner com o Grupo de Mercadoria selecionado.

Campos de preenchimento
obrigatórioRed 
Número Container: Ex: ATHN1234567
Regime: Escolher a opção correspondente.
Escolha se o contêiner será exportado cheio ou vazio.
Modo: Selecione o modo. Ex: FCL.
Gupo ISO: [International Organization for Standardization]. Ex: HB (high clube)
Quantidade de containers.
Peso bruto total: Ex: 64000
Código ISO: informe o código correspondente [International Organization for Standardization]. Ex: 45G1
Escolha o formato do cantainer.
Escolha a modalidade do container.
Clique em OK e o sistema gravá as informações no banco.

Sintética
A sintética é uma forma de apresentar informações essenciais do contêiner de forma sucinta e objetiva, como tipo de contêiner, tamanho, peso, informações de carga e outros detalhes importantes para facilitar a identificação e operação do contêiner no sistema. 
A apresentação sintética de informações é útil para uma rápida visualização e para a tomada de decisões baseadas em informações importantes em um ambiente de logística.
