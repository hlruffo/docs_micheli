Alterar Granel
Essa funcionalidade permite modificar informações de um registro de granel existente no sistema. Ao selecionar um granel específico, geralmente por meio de uma lista ou busca, uma tela de alteração será aberta. Nessa tela, é possível visualizar e editar as informações atualmente registradas para o granel, como nome, características, código, entre outros campos. Após realizar as alterações necessárias, é possível salvar as informações atualizadas para o granel.
Para modificar um granel específico, siga estes passos:
Utilize a ferramenta de filtro para pesquisar o granel desejado.

O resultado da pesquisa será exibido na Grid 2.

Selecione o granel desejado na Grid 2.

Clique no botão de ação "ALTERAR".

Faça as alterações desejadas nas informações do granel.

Após realizar as alterações, clique em "OK" para salvar as informações no banco.

Excluir Granel
Essa funcionalidade permite remover um registro de granel do sistema. Ao selecionar um granel específico, geralmente por meio de uma lista ou busca, você terá a opção de excluir o granel. Ao confirmar a exclusão, o granel será removido permanentemente do sistema. É importante ter cuidado ao utilizar essa função, pois a exclusão é irreversível.
Para excluir um granel específico, siga estes passos:
Utilize a ferramenta de filtro para pesquisar o granel que deseja excluir.

O resultado da pesquisa será exibido na Grid 2.

Selecione o granel desejado na Grid 2.

Clique no botão de ação "EXCLUIR".

Uma mensagem de confirmação será exibida para garantir a exclusão do granel. Verifique novamente se é o granel correto que deseja excluir.

Se tiver certeza da exclusão, clique em "OK" para confirmar.

Pesquisar GM Granel
O botão localizado na Grid 3 tem a função de auxiliar na busca de um Grupo Mercadoria específico relacionado ao granel selecionado na Grid 2.
Na tela do sistema TOS, localize a Grid 2, onde os graneis são exibidos.

Selecione o granel desejado na Grid 2, clicando sobre ele.

Na mesma tela, localize a Grid 3, que exibe informações relacionadas ao granel selecionado.

Na Grid 3, procure pelo botão designado para a busca do Grupo Mercadoria relacionado.

Clique no botão de busca do Grupo Mercadoria.

Aguarde o sistema realizar a busca e retornar o resultado relacionado ao granel selecionado.

Carregar Dados de GM Granel
Na tela do sistema TOS, localize a Grid 2 onde os graneis são exibidos.

Selecione o granel desejado na Grid 2, clicando sobre ele.

Na mesma tela, localize a Grid 3, que exibe informações relacionadas ao granel selecionado.

Procure pelo botão designado para carregar os dados do Grupo Mercadoria.

Clique no botão de carregamento de dados do Grupo Mercadoria.

Aguarde o sistema carregar os dados do Grupo Mercadoria relacionados ao granel selecionado.

Os dados do Grupo Mercadoria serão exibidos na Grid 3 ou em uma área designada para apresentar as informações carregadas.
