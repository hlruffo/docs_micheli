Pesquisar/Filtrar Etiqueta
Para encontrar uma Etiqueta, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Gerar Etiqueta
Essa função permite adicionar uma nova etiqueta a uma determinada carga ou grupo mercadoria. P
Preencha os campos, conforme descrição abaixo.

Clique no botão Gerar Etiqueta presente na Grid 2.

Gerar Etiqueta
Após isso um ajanela se abrirá com dois campos: 
Campo de busca de grupo mercadoria. nele é necessário informar qual grupo mercadoria será vinculado a etiqueta. Basta utilizar o campo de busca para encontrar um  registro de grupo mercadoria. Logo, os registros exixtentes irão aparecer no campo de rsultado e você poderá selecionar a mercadoria que deseja gerar etiqueta.

b. Após selecionar o registro desejado, basta descer a janela até os campos de preenchimento da eqtiqueta. Preencha conforme recomendações abaixo: 
obrigatórioRed  
Quantidade de Volume: Neste campo, você precisa inserir o número total de volumes que compõem a carga ou o grupo de mercadorias.
QTD Etiquetas: Aqui, você deve especificar o número de etiquetas que deseja gerar para a carga ou grupo de mercadorias. 
opcionalBlue 
Formato: Ex.: AMARR/ATAD/FEIXE (0.6 X 1.0 X 1.05)
Código Cliente: Neste campo, você deve inserir o código do cliente para o qual as etiquetas estão sendo geradas.
Observação: Aqui, você pode adicionar quaisquer observações adicionais relevantes para a geração das etiquetas.
Após preencher as informações clique em OK para salvar os dados no banco.

Imprimir Etiqueta
Para imprimir uma etiqueta, é necessário primeiro selecionar o registro específico que deseja imprimir. Você pode utilizar o filtro no sistema para localizar o registro da etiqueta desejada. Uma vez localizado, basta clicar sobre o registro para selecioná-lo.

Em seguida, clique no botão de ação "Imprimir Etiqueta". Ao fazer isso, o sistema abrirá uma janela exibindo a etiqueta selecionada, permitindo que você a visualize antes de prosseguir com a impressão.

Excluir Etiqueta
Para excluir uma etiqueta associada, siga os passos abaixo:
Localize o registro da etiqueta que deseja excluir no sistema.

Selecione o registro nos resultados exibidos.

Em seguida, clique no botão de ação "Excluir".

Caso o sistema solicite, confirme a exclusão.

Após seguir esses passos, a exclusão da etiqueta será realizada com sucesso.
