Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Referentes as ações possíveis na Grid 2.
Incluir Carga: Essa função permite adicionar uma nova carga ao sistema TOS. Pode envolver o fornecimento de informações como descrição da carga, peso, dimensões, origem, destino e outras informações relevantes.
Alterar Carga: Essa funcionalidade permite fazer modificações em uma carga existente no sistema TOS. Pode incluir a atualização de informações como peso, dimensões, status, destino, entre outros.
Excluir Carga: Essa função permite remover uma carga específica do sistema TOS. É útil quando uma carga foi inserida erroneamente ou se tornou irrelevante para o sistema.
Importar Packing Lista: Essa funcionalidade permite importar uma lista de embalagens (packing list) para o sistema TOS. A lista geralmente contém informações sobre as embalagens, como número de contêineres, identificadores de carga, descrição da carga, quantidade, peso e outras informações relevantes. Importar essa lista facilita o registro das cargas no sistema.
Carregar dados do contêiner movimento: Essa funcionalidade permite carregar dados relacionados ao movimento de contêineres no sistema TOS. Pode incluir informações como número do contêiner, tipo de movimento (carga, descarga, transferência), data e hora do movimento, localização e outras informações relevantes.
Carregar cargas desovadas dado o contêiner movimento: Essa função permite carregar as informações das cargas desovadas de um determinado contêiner no sistema TOS. As cargas desovadas são as cargas retiradas de um contêiner específico. Essa funcionalidade pode envolver a atualização de informações relacionadas à carga no sistema, como status, destino, localização, entre outros.

Pesquisar/Filtrar Carga
Para encontrar uma carga, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.

Origem: Este campo refere-se à origem da carga. Escolha entre manifestado, novo lote, sobra e packing list.
Formato Tipo: Este campo indica o formato ou tipo da carga.
Tipo: Solta ou granel.
QTD: quantidade de unidades da carga.

 O código NCM é utilizado para fins de tributação e identificação do tipo de mercadoria.

Alterar quantidade prevista
A função de 'Alterar quantidade prevista de carga' permite realizar modificações na quantidade estimada de carga associada a um determinado item ou registro. Essa funcionalidade é útil quando ocorrem mudanças nas quantidades planejadas inicialmente, seja para aumentar ou reduzir a quantidade prevista. 
A carga precisa estar como tipo entrada.
Ao selecionar a carga desejada, o usuário pode acessar a opção de alteração e inserir a nova quantidade prevista, refletindo as atualizações necessárias. 
A quantidade prevista nova deve seguir as seguintes regras:
Se a quantidade prevista nova for maior do que a atual e a quantidade (qtd) for igual à quantidade prevista atual, não será possível salvar as alterações. Isso ocorre quando todo o lote já foi incluído, sendo permitido apenas marcar a carga como entrada, desde que o fluxo de carga não tenha sido fechado para contagem.

Se a quantidade prevista nova for menor do que a atual e essa nova quantidade prevista for menor ou igual à quantidade que já foi registrada (qtd), também não será possível salvar as alterações. Isso ocorre porque a quantidade prevista é menor do que a quantidade já registrada.

Pesquisar Container(Movimento)
Para pesquisar um contêiner movimento basta seguir os passos simples abaixo:
Desça a tela até o campo 3.

Localize a aba Container(Movimento).

Encontre os campos de preenchimento 'BUSCAR PELO MOVIMENTO POR NAVIO' e CONTAINER.

Insira as informações desejadas, seja o movimento por navio ou o número do container.

Clique no botão de ação PESQUISAR na mesma aba.

Carregar dados de uma carga
Para carregar os dados de uma carga é necessario localizar primeiro o registro de CARGA que deseja ver as informações de Container movimento. Para isso siga os passos abaixo:
Inicie localizando o registro de carga desejado utilizando o campo de filtro disponível.

Após a pesquisa, o resultado será exibido no campo 2. Selecione o resultado desejado clicando sobre ele.

Em seguida, desça até o campo 3, correspondente à aba Container Movimento.

Clique no botão de ação "Carregar Dados de uma Carga".

O sistema apresentará os resultados no campo 3, revelando eventuais registros de movimento de containers associados à carga em questão.

Verificar consistência do Grupo Mercadoria (Consistência)
A verificação da consistência do Grupo Mercadoria é uma tarefa simples no sistema. Siga os passos abaixo para realizar essa verificação de forma eficiente:
Identifique o registro de transporte movimento que deseja verificar, utilizando o campo de busca na Aba Grupo Mercadoria (Consistência).

Após localizar o registro desejado, clique no botão de ação "VERIFICAR CONSISTÊNCIA".

O sistema retornará uma mensagem indicando a consistência dos dados, como por exemplo: "O somatório das cargas de origem Manifestada é igual ao somatório de origem PackList."

Incluir NCM
Para adicionar um NCM (Nomenclatura Comum do Mercosul) a uma carga, siga os passos simples abaixo:
Selecione o registro desejado na aba NCM.

Realize a pesquisa do NCM desejado que deseja associar a essa carga.

Clique no botão de ação "Incluir".

O sistema associará automaticamente o NCM selecionado à carga escolhida.
Excluir NCM
Para remover um NCM (Nomenclatura Comum do Mercosul) associado a uma carga, siga os passos abaixo:
Acesse a aba NCM e selecione o registro que contém o NCM que deseja excluir.

Localize o NCM específico que deseja remover.

Clique no botão de ação "Excluir".

O sistema realizará a exclusão do NCM associado à carga selecionada.
