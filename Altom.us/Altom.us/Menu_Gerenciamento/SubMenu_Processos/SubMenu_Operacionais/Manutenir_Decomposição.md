Alterar Decomposição
Para realizar uma alteração em um registro de decomposição, siga estes passos simples:
Utilize a ferramenta de filtro para localizar o registro que deseja modificar na grade "Decomposição".

Após localizar o registro desejado, selecione-o na grade "Decomposição".

Clique no botão de ação "Alterar" para acessar as opções de edição.

Faça as modificações nas informações conforme necessário.

Para confirmar as alterações, clique em "OK" para salvar as informações atualizadas.

Excluir Decomposição
Use a ferramenta de filtro para localizar o registro de Decomposição que deseja excluir na grade "Decomposição".

Após localizar o registro desejado, selecione-o na grade "Decomposição".

Clique no botão de ação "Excluir".

Confira se esta excluindo o registro correto e confirme a ação.

Fechar Decomposição
Para encerrar uma desistência de embarque, siga estes passos simples:
Utilize a ferramenta de filtro para localizar o registro que deseja fechar na grade "Decomposição".

Após localizar o registro desejado, selecione-o na grade "Decomposição".

Clique no botão de ação "Fechar" para executar a ação.

O sistema irá encerrar o processo e exibirá uma mensagem de confirmação na tela.

Carregar dado um Grupo Mercadoria
Para obter informações detalhadas sobre um GM, siga estas etapas:
Comece por selecionar um registro na "Grid 2". Localize o arquivo ou item específico do qual deseja obter informações.

Role a tela para acessar a "Grid 3".

Clique no botão "CARREGAR" para gerar dados na grid.

Incluir Decomposição 
Escolha a decomposição que deseja associar na grid 3 e selecione-a.

Desloque-se até a Grid 3, guia de Grupo Mercadoria.

Informe o grupo mercadoria desejado, buscando e selecionando na lista disponível.

Após selecionar o grupo mercadoria desejado, clique no botão de ação "Incluir". Isso permitirá que o sistema associe a decomposição ao grupo mercadoria selecionado.

Excluir Grupo Mercadoria
Antes de iniciar a exclusão do registro de Grupo mercadoria, execute o passo de carregar dados de um grupo mercadoria. Isso garantirá que as informações necessárias estejam disponíveis.

Após carregar os dados do grupo mercadoria, escolha a decomposição que deseja excluir.

Após selecionar o grupo mercadoria desejado, clique no botão de ação "Excluir". 

Carregar dados Mercadoria
Esta funcionalidade está diretamente vinculada à guia Grupo Mercadoria. Portanto, os dados só podem ser carregados aqui se algum registro de grupo mercadoria estiver selecionado. Siga os passos anteriores deste manual para carregar dados em um grupo mercadoria.
Execute os passos anteriores deste manual para carregar dados em um grupo mercadoria. Certifique-se de que um registro de grupo mercadoria esteja selecionado.

Após encontrar o registro desejado na guia Grupo Mercadoria, mude para a guia Mercadoria.

Na guia Mercadoria, localize o botão de ação "Carregar". 

Após clicar em "Carregar", os dados de mercadorias associados à decomposição e ao grupo mercadoria selecionados serão exibidos no campo correspondente.

Cadastrar Mercadoria
Para cadastrar uma mercadoria em uma decomposição, é necessário que um Grupo Mercadoria esteja selecionado na guia Grupo Mercadoria. Siga os passos abaixo:
Certifique-se de que um Grupo Mercadoria esteja selecionado na guia Grupo Mercadoria. Siga os procedimentos anteriores para realizar essa seleção.

Após selecionar o registro correspondente na guia Grupo Mercadoria, mude para a guia Mercadoria.

Na guia Mercadoria, clique no botão de ação "Incluir" (+). Isso abrirá um formulário para preenchimento com as informações da mercadoria.

No formulário de inclusão, forneça todas as informações necessárias sobre a mercadoria que está sendo cadastrada na decomposição.

Após preencher o formulário, clique em "OK" para confirmar o cadastro da mercadoria na decomposição.

Excluir Mercadoria
Para excluir uma mercadoria em uma decomposição, é necessário que um Grupo Mercadoria esteja selecionado na guia Grupo Mercadoria. 
Comece por selecionar o registro que deseja excluir. Use a função "Carregar" para localizar os registros disponíveis.

Os registros correspondentes serão exibidos na "Grid," organizados em colunas com suas informações. Escolha o registro que deseja excluir.

Na mesma "Grid," clique no botão de ação "Excluir" associado ao registro que você deseja remover.
