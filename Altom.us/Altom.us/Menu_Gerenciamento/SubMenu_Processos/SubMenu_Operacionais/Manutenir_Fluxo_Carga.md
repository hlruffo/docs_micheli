Pesquisar/Filtrar Fluxo Carga
Para buscar um Fluxo Carga específico na tela de filtro, basta informar o conjunto de informações refentes ao registro. Se desejar pesquisar todos os dados disponíveis na tela, deixe o campo em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Fluxo Carga
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed 
Fluxo: Insira o nome do fluxo específico que deseja cadastrar.
Selecione o modo operante: Escolha entre "Container" ou "Transporte Movimento", dependendo do modo operante do fluxo de carga que está cadastrando.
Container: Busque o container associado a este fluxo, inserindo o código ou nome do container.
Grupo Mercadoria: Insira o código ou nome do grupo de mercadoria relacionado a este fluxo de carga.
Tipo: Pode ser "Entrada" ou "Saída", dependendo do contexto.
Conferente: Insira o nome ou código do profissional que será responsável pela conferência deste fluxo de carga.
opcionalBlue  
Documento: Informe o tipo de documento associado a este fluxo de carga. 
Mecanização: Escolha o tipo de fluxo, que pode ser "Manual", "Automatizada" ou "Ambos", dependendo do método de mecanização usado.
Preenchimento: Indique se o preenchimento do fluxo de carga é "Parcial" ou "Total", com base nas informações disponíveis.
Alterar Fluxo Carga
Para realizar uma alteração em um registro de Fluxo Carga, siga estes passos simples:
Utilize a ferramenta de filtro para localizar o registro que deseja modificar na grade "Fluxo Carga".

Após localizar o registro desejado, selecione-o.

Clique no botão de ação "Alterar" para acessar as opções de edição.

Faça as modificações nas informações conforme necessário.

Para confirmar as alterações, clique em "OK" para salvar as informações atualizadas.

Excluir Fluxo Carga
Para excluir um registro de Fluxo Carga, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Fluxo Carga que deseja excluir.

Na lista de resultados, selecione o registro que deseja excluir clicando sobre ele para destacá-lo.

Localize o botão de ação "EXCLUIR" e clique nele para finalizar a ação.

Abrir Fluxo Carga
Para abrir um registro de Fluxo Carga, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Fluxo Carga que deseja abrir.

Na lista de resultados, selecione o registro que deseja abrir clicando sobre ele para destacá-lo.

Localize o botão de ação "ABRIR FLUXO CARGA" e clique nele para abir e finalizar a ação.

O sistema irá confirmar a abertura.

Fechar Fluxo Carga
Para fechar um registro de Fluxo Carga, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Fluxo Carga que deseja fechar.

Na lista de resultados, selecione o registro que deseja abrir clicando sobre ele para destacá-lo.

Localize o botão de ação "ABRIR FLUXO CARGA" e clique nele para fechar e finalizar a ação.

O sistema irá confirmar o fechamento.

Duplicar Fluxo Carga
Para duplicar um registro de Fluxo de Carga, siga estas etapas:
Localize o registro de Fluxo de Carga que deseja duplicar na grade 2.

Selecione o registro desejado na grade 2.

Clique no botão de ação "DUPLICAR".

:info:atlassian-info#F4F5F7O sistema executará a duplicação do fluxo, desde que o fluxo ainda esteja aberto. Observe que esta ação não pode ser realizada em fluxos que já tenham sido fechados. Certifique-se de que o fluxo esteja em estado aberto antes de prosseguir com a duplicação.
Carregar dados de Fluxo Carga
A grade 3 (Itens do Fluxo de Carga) na tela de Fluxo de Carga está diretamente relacionada às informações da grade 2 (Fluxo de Carga). Para acessar e visualizar informações relevantes, como carga solta, etiqueta, quantidade e peso líquido real, associadas a um registro na grade 2, siga as seguintes etapas:
Selecione o registro de Fluxo de Carga na grade 2 que deseja visualizar para acessar as informações detalhadas.

Desloque-se até a grade 3, onde os itens relacionados serão exibidos.

Clique no botão de ação "Carregar Dados de Fluxo de Carga".

Os itens associados a esse registro serão automaticamente apresentados na grade 3, organizados em colunas para facilitar a visualização e análise. 
Cadastrar/Tratar Item Fluxo Carga
Para incluir/tratar um item no Fluxo de Carga, é necessário que um registro de Fluxo de Carga seja selecionado na grade 2 para associar esse item ao Fluxo de Carga.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

Observação Importante: Uso da Grade e Avarias
opcionalBlue 
No início do formulário, você encontrará uma grade onde informações de registros de Fluxo de Carga já cadastrados são apresentadas. Isso facilita a visualização e permite que você copie informações relevantes para o preenchimento de novos registros. Para duplicar essas informações, basta clicar no botão de ação "Duplicar", e os dados serão automaticamente transferidos para os campos de preenchimento.
opcionalBlue 
Além disso, ao final do formulário, na seção de avarias, você pode cadastrar avarias associadas a este fluxo. Para obter informações detalhadas sobre como cadastrar uma avaria, consulte o manual do sistema. Manutenir Tipo Avaria 
obrigatórioRed  
Formato: Selecione o formato do item no campo "BUSCAR FORMATO".
QTD: Insira a quantidade do item.
QtdP: Preencha a quantidade de peças ou unidades do item, se aplicável.
NCM: Selecione o NCM (Nomenclatura Comum do Mercosul) associado a esse item. O NCM é um código que identifica o produto.
opcionalBlue 
Peso Bruto Manifestado: Informe o peso bruto manifestado do item.
Peso Líquido Real: Insira o peso líquido real do item, conforme verificado.
M3: Preencha o volume em metros cúbicos (M3) do item.
M2: Insira a área em metros quadrados (M2) do item, se aplicável.
Marca: Insira a marca do item, se aplicável.
Contra Marca: Preencha o campo da contra marca, se necessário.
Complemento: Forneça qualquer informação adicional ou complementar relacionada ao item.
Ordem Controle: Insira o número da ordem de controle, se aplicável.
IMO: No campo "BUSCAR IMO POR ONU", selecione o código IMO associado à ONU (Organização das Nações Unidas) correspondente ao item, se necessário. Isso é relevante para produtos perigosos.

Excluir Item Fluxo Carga
Para excluir um item do Fluxo de Carga, é fundamental que haja informações registradas na grade. Portanto, antes de prosseguir com a exclusão, siga o processo de "Carregar Dados" conforme descrito neste manual. Após ter as informações carregadas na grade, você poderá selecionar o registro que deseja excluir. Em seguida, siga estas etapas:
Selecione o registro que você deseja remover.

Clique no botão de ação "Excluir" para concluir a ação.

Imprimir Etiquetas 
O processo para imprimir uma etiqueta é semelhante ao descrito anteriormente, com a opção adicional de visualizar as etiquetas antes da impressão. Siga estas etapas:
Garanta que haja informações registradas na grade antes de prosseguir com a impressão da etiqueta. Se necessário, siga o processo de "Carregar Dados" conforme mencionado anteriormente.

Selecione o registro para o qual deseja imprimir a etiqueta.

Clique no botão de ação "Imprimir Etiqueta".

Uma janela de visualização de etiquetas será exibida, permitindo que você revise as etiquetas antes de imprimir ou salvá-las.

Após revisar as etiquetas e garantir que estejam corretas, clique em "OK" para iniciar a impressão.

:note:atlassian-note#F4F5F7Essa abordagem oferece a vantagem de uma revisão visual antes da impressão ou salvamento, garantindo que as etiquetas estejam precisas e prontas para uso.
