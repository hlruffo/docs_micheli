2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1.

Pesquisar/Filtrar Transcontainer
Para buscar um Transcontainer específico na tela de filtro, basta informar o conjunto de informações refentes ao registro. Se desejar pesquisar todos os dados disponíveis na tela, deixe o campo em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Transcontainer
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed 
Documento: campo é destinado à inclusão de um documento de referência associado ao transcontainer.
Container Origem: Neste campo, você deve inserir as informações relativas ao contêiner de origem. Busque pelo contêiner correspondente.
opcionalBlue 
Container Destino: Similar ao campo "Container Origem," aqui você insere as informações referentes ao contêiner de destino.
Tratar Estado Transcontainer/Mudar estado
Para tratar um registro de Transcontainer, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Transcontainer que deseja tratar.

Na lista de resultados, selecione o registro de Transcontainer que deseja tratar clicando sobre ele para destacá-lo.

Localize o botão de ação "Mudar Estado" e clique nele. Isso fará com que uma janela seja aberta para modificar o Estado:

Excluir Transcontainer
Para excluir um registro de Transcontainer, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Transcontainer que deseja excluir.

Na lista de resultados, selecione o registro de Transcontainer que deseja excluir clicando sobre ele para destacá-lo.

Localize o botão de ação "EXCLUIR" e clique nele para finalizar a ação.

Carregar Dado Transcontainer
Antes de visualizar as informações do Estado Transcontainer, é necessário seguir estas etapas:
Utilize o filtro para localizar o registro de Transcontainer que deseja acessar.

Identifique e selecione o registro desejado para visualizar as informações.

Role a tela até a "Grid 3" e clique no botão de ação "Carregar Dado Transcontainer".
