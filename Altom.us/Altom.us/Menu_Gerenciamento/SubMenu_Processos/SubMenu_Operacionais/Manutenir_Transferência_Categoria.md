Alterar Transferência de Categoria
Utilize a função de busca para localizar o registro de Transferência Categoria que deseja alterar. 

Na lista de resultados, selecione o registro desejado de Transferência Categoria clicando sobre ele para destacá-lo.

Localize o botão de ação "ALTERAR" e clique nele. Isso permitirá acessar a tela de edição para modificar as informações desejadas.

Na tela de edição, faça as alterações necessárias nas informações relevantes de acordo com suas necessidades. Certifique-se de inserir os novos valores corretamente nos campos apropriados.

Após realizar as alterações desejadas, clique em "OK" para confirmar as modificações e salvar as informações atualizadas.

Excluir Transferência de Categoria
Para excluir um registro de Transferência Categoria, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Transferência Categoria que deseja excluir.

Na lista de resultados, selecione o registro de Transferência Categoria que deseja excluir clicando sobre ele para destacá-lo.

Localize o botão de ação "EXCLUIR" e clique nele. 

Clique em "OK" para confirmar a exclusão do registro. O sistema processará a solicitação e removerá o registro selecionado da base de dados.

Realizar Transferência de Categoria
Para realizar uma Transferência de Categoria, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Transferência Categoria que deseja realizar.

Na lista de resultados, selecione o registro de Transferência Categoria clicando sobre ele para destacá-lo.

Localize o botão de ação "REALIZAR TRANSFERÊNCIA DE CATEGORIA" e clique nele. 

O sistema ira retornar uma mensagem de confirmação na tela.

Só é possível realizar esse processo 1x por registro.
Cadastrar Item Transferência de Categoria (GMM)
Para efetuar o cadastro de um Item de Transferência de Categoria (GMM), siga os passos abaixo:
Primeiro, selecione um registro de Transferência Categoria →  Aba: Transferência Categoria. Escolha o registro ao qual você deseja associar este Item de Transferência.

Acesse a guia "Item Transferência de Categoria (GMM)" dentro do registro selecionado e clique no botão de ação "Incluir"(+).

Preencha os campos conforme a descrição abaixo.

obrigatórioRed  
Grupo Mercadoria:  procure e selecione o grupo de mercadoria associado a essa transferência. O grupo de mercadoria é uma categoria que classifica os produtos ou itens que estão sendo transferidos.
opcionalBlue  
Mercadoria: Selecione a mercadoria que deseja associar ao Item Transferência de Categoria (GMM), caso pertinente.
Excluir Item Transferência de Categoria (GMM)
Para excluir um Item de Transferência de Categoria (GMM), siga os passos abaixo:
Comece por localizar o item que deseja excluir. Certifique-se de que tenha um registro selecionado na guia "Transferência de Categoria".

Em seguida, mude para a guia "Item Transferência de Categoria (GMM)".

Agora, é possível pesquisar todos os itens associados à Transferência de Categoria selecionada na grade anterior. Clique no botão de ação "Pesquisar Todos".

Após a pesquisa, os registros relacionados serão apresentados na tela. Selecione os itens que deseja excluir conforme necessário. e clique no botão de ação excluir para concluir a ação.

Pesquisar Todos os Itens de Transferência de Categoria (GMM)
Para pesquisar itens de Transferência de Categoria (GMM) utilizando a ação "PESQUISAR TODOS," siga as etapas abaixo:
Comece por localizar o item que deseja pesquisar. Certifique-se de que tenha um registro selecionado na guia "Transferência de Categoria."

Mude para a guia "Item Transferência de Categoria (GMM)."

Agora, você pode buscar todos os itens associados à Transferência de Categoria selecionada na grade anterior.

Clique no botão de ação "PESQUISAR TODOS."

Após a pesquisa, os registros relacionados serão apresentados na tela. Você poderá examinar e selecionar os itens conforme necessário.

Isso facilita a identificação de itens associados à Transferência de Categoria e sua subsequente gestão.
Cadastrar Tipo Transferência de Categoria
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+) na Guia 3 Aba: Tipo Transferência de Categoria.

obrigatórioRed  
Nome: Insira um nome descritivo que identifique o tipo de mercadoria que você está cadastrando.
Constante: Preencha este campo com um valor numérico ou alfanumérico que represente uma constante associada a este tipo de mercadoria, se aplicável. Ex: A/I
Origem: Escolha a que melhor descreve a origem da mercadoria que está sendo cadastrada.
Destino: Especifique o destino da mercadoria. Importação, Exportação ou armazenagem.
opcionalBlue  
Tipo de Documento: Escolha o tipo de documento associado a este tipo de mercadoria.
Alterar Tipo Transferência de Categoria
Para utilizar essa funcionalidade primeiro é necessário pesquisar os registros de Tipo Transferência de Categoria existentes nesta tela. 
Antes de iniciar pesquise por todos os itens clicando no botão de ação ‘'PESQUISAR TODOS’';

Selecione o registro que deseja alterar clicando no botão de ação ''ALTERAR'';

Uma janela se abrirá com os campos que podem ser alterados no registro;

Após finalizar as alterações desejadas, clique em OK para salvar as informações no banco.

Excluir Tipo Transferência de Categoria
Para utilizar essa funcionalidade primeiro é necessário pesquisar os registros de Tipo Transferência de Categoria existentes nesta tela. 
Antes de iniciar pesquise por todos os itens clicando no botão de ação ‘'PESQUISAR TODOS’';

Selecione o registro que deseja remover clicando no botão de ação “EXCLUIR”;

Confirme a exclusão do registro e logo ele será removido dos registros de Tipo Transferência de Categoria.
