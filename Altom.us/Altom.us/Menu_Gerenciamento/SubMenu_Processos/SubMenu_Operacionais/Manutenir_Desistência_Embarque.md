Para buscar uma Desistência Embarque específica na tela de filtro, basta informar o conjunto de informações refentes ao registro. Se desejar pesquisar todos os dados disponíveis na tela, deixe o campo em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.

Cadastrar Desistência Embarque
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

 ObrigatórioRed 
Tipo: Nesse campo, você deve selecionar o tipo de ação, que pode ser um dos seguintes: Redirecionamento, Desistência ou Rolagem
GME Origem: Este campo deve ser preenchido buscando pelo grupo de mercadoria de origem relacionado à desistência de embarque.
Motivo: Neste campo, você deve buscar pelo motivo da desistência de embarque. Ex.: DESISTENCIA_EMB_MOTIV_REDIRECIONAMENTO
Cliente: Busque o cliente que está solicitando a desistência de embarque.
opcionalBlue 
GME Destino: Semelhante ao campo anterior, aqui você deve preencher buscando pelo grupo de mercadoria de destino relacionado à desistência de embarque.
Mercadoria: Selecione a mercadoria que está sendo afetada pela desistência de embarque. Isso pode incluir a escolha da mercadoria a partir de uma lista de produtos ou itens disponíveis no sistema.
Alterar Desistência Embarque
Para realizar uma alteração em um registro de desistência de embarque, siga estes passos simples:
Utilize a ferramenta de filtro para localizar o registro que deseja modificar na grade "Desistência Embarque".

Após localizar o registro desejado, selecione-o na grade "Desistência Embarque".

Clique no botão de ação "Alterar" para acessar as opções de edição.

Faça as modificações nas informações conforme necessário.

Para confirmar as alterações, clique em "OK" para salvar as informações atualizadas.

Excluir Desistência Embarque
Use a ferramenta de filtro para localizar o registro de desistência de embarque que deseja excluir na grade "Desistência Embarque".

Após localizar o registro desejado, selecione-o na grade "Desistência Embarque".

Clique no botão de ação "Excluir".

Confira se esta excluindo o registro correto e confirme a ação.

Encerrar Desistência Embarque
Para encerrar uma desistência de embarque, siga estes passos simples:
Utilize a ferramenta de filtro para localizar o registro que deseja encerrar na grade "Desistência Embarque".

Após localizar o registro desejado, selecione-o na grade "Desistência Embarque".

Clique no botão de ação "Encerrar" para executar a ação.

O sistema irá encerrar o processo e exibirá uma mensagem de confirmação na tela.

Carregar dados de Desistência Embarque
Guia: Mercaodria    
Para obter informações detalhadas sobre uma Desistência Embarque, siga estas etapas:
Comece por selecionar um registro na "Grid 2". Localize o arquivo ou item específico do qual deseja obter informações.

Role a tela para acessar a "Grid 3".

Clique no botão "CARREGAR DADO desistência EMBARQUE" para gerar dados, como Ocorrência, QTD e Mercadoria associados a Desistência Embarque selecionada.  

Pesquisar Motivo de Desistência Embarque
Guia: Motivo  
Para pesquisar todos os registros disponíveis, siga estas etapas:
Basta clicar no botão de ação em forma de lupa localizado nesta grid.

As informações de motivos serão exibidas na grid.

Alterar Motivo de Desistência Embarque
Guia: Motivo    
Para modificar um motivo existente, siga estas etapas:
Comece por selecionar o registro que deseja alterar. Utilize a função "PESQUISAR TODOS" para localizar os registros disponíveis.

Os registros correspondentes serão exibidos na "Grid," organizados em colunas com suas informações. Escolha o registro que deseja alterar.

Na mesma "Grid," clique no botão de ação "Alterar" associado ao registro que você deseja modificar.

Excluir Motivo de Desistência Embarque
Guia: Motivo    
Para remover um Motivo existente, siga as seguintes etapas:
Comece por selecionar o registro que deseja excluir. Use a função "PESQUISAR TODOS" para localizar os registros disponíveis.

Os registros correspondentes serão exibidos na "Grid," organizados em colunas com suas informações. Escolha o registro que deseja excluir.

Na mesma "Grid," clique no botão de ação "Excluir" associado ao registro que você deseja remover.
