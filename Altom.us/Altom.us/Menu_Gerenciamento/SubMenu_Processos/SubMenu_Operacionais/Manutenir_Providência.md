Pesquisar/Filtrar Providência
Para buscar uma Providência específica na tela de filtro, basta informar o conjunto de informações refentes ao registro. Se desejar pesquisar todos os dados disponíveis na tela, deixe o campo em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Providência
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed 
Código: Forneça o código da providência a ser cadastrada.
Nome: Forneça um nome a sua providência.
Clique em Ok para salvar as informações do registro no banco.
Alterar Providência
Utilize a função de busca para localizar o registro de Procidência que deseja alterar. 

Na lista de resultados, selecione o registro desejado de Procidência clicando sobre ele para destacá-lo.

Localize o botão de ação "ALTERAR" e clique nele. Isso permitirá acessar a tela de edição para modificar as informações desejadas.

Na tela de edição, faça as alterações necessárias nas informações relevantes de acordo com suas necessidades. Certifique-se de inserir os novos valores corretamente nos campos apropriados.

Após realizar as alterações desejadas, clique em "OK" para confirmar as modificações e salvar as informações atualizadas.
Excluir Providência
Para excluir um registro de Procidência, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Procidência que deseja excluir.

Na lista de resultados, selecione o registro de Procidência que deseja excluir clicando sobre ele para destacá-lo.

Localize o botão de ação "EXCLUIR" e clique nele. Isso abrirá uma janela de confirmação para confirmar a exclusão do registro.
