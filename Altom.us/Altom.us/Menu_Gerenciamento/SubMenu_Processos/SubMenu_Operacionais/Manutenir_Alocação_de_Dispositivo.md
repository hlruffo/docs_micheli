Pesquisar/Filtrar uma Alocação de Dispositivo
Para encontrar uma Alocação de Dispositivo, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Cadastrar Alocação de Dispositivo
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Clique em OK e o sistema gravá a nova movimentação no banco.
obrigatórioRed 
Dispositivo: Neste campo, você deve buscar o dispositivo que deseja alocar.
Usuário: Aqui, você deve buscar o usuário que será responsável pela alocação do dispositivo. 
Início: Preencha este campo com a data e hora de início da alocação. Utilize o formato "DD/MM/YYYY HH:MM" para especificar a data e a hora exatas em que a alocação terá início.
opcionalBlue  
Término Previsto: Insira neste campo a data e hora previstas para o término da alocação do dispositivo. Utilize o formato "DD/MM/YYYY HH:MM" para definir a data e a hora estimadas para o término da alocação.
Alterar Alocação de Dispositivo
Para realizar uma alteração em um registro de Alocação de Dispositivo, siga estes passos simples:
Utilize a ferramenta de filtro para localizar o registro que deseja modificar na grade "Alocação de Dispositivo".

Após localizar o registro desejado, selecione-o na grade "Alocação de Dispositivo".

Clique no botão de ação "Alterar" para acessar as opções de edição.

Faça as modificações nas informações conforme necessário.

Para confirmar as alterações, clique em "OK" para salvar as informações atualizadas.

Excluir Alocação de Dispositivo
Use a ferramenta de filtro para localizar o registro de Alocação de Dispositivo que deseja excluir.

Após localizar o registro desejado, selecione-o na grade "Alocação de Dispositivo".

Clique no botão de ação "Excluir".

Certifique-se de revisar as informações e confirmar que deseja excluir o registro.

Após a confirmação, o registro será excluído permanentemente do sistema.

Finalizar Alocação de Dispositivo
Para finalizar uma Alocação de Dispositivo, siga estes passos simples:
Utilize a ferramenta de filtro para localizar o registro que deseja finalizar na grade "Alocação de Dispositivo".

Após localizar o registro desejado, selecione-o na grade "Alocação de Dispositivo".

Clique no botão de ação "Finalizar".

O sistema retornará uma mensagem com a posição da ação.
