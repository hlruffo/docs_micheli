Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.

Pesquisar/Filtrar Dispositivo Operação
Para buscar um Dispositivo Operação específico na tela de filtro, basta informar o conjunto de informações refentes ao registro. Se desejar pesquisar todos os dados disponíveis na tela, deixe o campo em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Incluir Fotografia
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed 
Identificador: Insira um identificador exclusivo ou nome para o dispositivo de operação que você está cadastrando.
Processo: Selecione uma das opções disponíveis: "Ativação," "Vistoria," "Posicionamento," ou "Pré-Gate." Escolha o processo que melhor descreve a operação que esse dispositivo realizará.
Processo Id: Forneça um identificador específico associado ao processo selecionado anteriormente. 
Classe: Selecione a classe do dispositivo a partir das opções disponíveis, como "BALANCA," "BIOMETRIA," "CANCELA," "CARGO HANDLING LAND," "CARGO HANDLING VESSEL," "CARGO IDENTIFIER," "CONSOLE," "LOAD-CARRYING," "NULO," "OCR," "SCANNER," "TABLET" ou "VIRTUAL SYSTEM." Escolha a classe que melhor descreve o tipo de dispositivo.
Dispositivo: Especifique o nome ou tipo específico do dispositivo que está sendo cadastrado.
Arquivo de Mídia: anexe um arquivo de mídia(imagem) para associar a este dispositivo.
opcionalBlue 
Entidade: Escolha uma das opções disponíveis: "Mercadoria," "Mercadoria Trânsito," "Etiqueta," ou "Transporte Movimento," com base na entidade à qual o dispositivo está relacionado.
Entidade Id: Insira um identificador associado à entidade escolhida anteriormente. 
Visualizar mídia
Para utilizar esta funcionalidade, é necessário existirem registros de dispositivos na tela. Siga os passos a seguir para visualizar mídia associada a esses dispositivos:
Utilize a função de filtro, se necessário, para localizar uma mídia específica que você deseja visualizar.

Após encontrar a mídia desejada, selecione o registro de dispositivo associado a ela.

Clique no botão de ação "VISUALIZAR MÍDIA."

Uma janela se abrirá, exibindo a imagem associada ao registro selecionado.
