Pesquisar/Filtrar Monitoramento Reefer
Para buscar um Monitoramento Reefer específico na tela de filtro, basta informar o conjunto de informações refentes ao registro. Se desejar pesquisar todos os dados disponíveis na tela, deixe o campo em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastro de Monitoramento Reefer
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed 
Container: Neste campo, insira o código de identificação do contêiner refrigerado que você deseja monitorar. 
Unidade de Temperatura: Aqui, você deve indicar a unidade de medida de temperatura que está sendo utilizada para o monitoramento. Pode ser Celsius (°C) ou Fahrenheit (°F). 
Ligado: Indique se o reefer está ligado ou desligado. 
opcionalBlue  
Temperatura: Insira a temperatura atual do contêiner refrigerado. Lembre-se de usar a unidade de medida especificada anteriormente (Celsius ou Fahrenheit).
Umidade: Insira a umidade relativa do ar dentro do contêiner. Isso pode ser expresso em porcentagem (%).
Alarme: Se houver algum alarme ou evento de notificação associado ao contêiner refrigerado, indique-o aqui. Isso pode incluir alarmes de temperatura, alarmes de funcionamento ou qualquer outra informação relevante.
Observação: Este campo é destinado a observações adicionais ou notas que você deseja adicionar ao registro de monitoramento do contêiner.
Alterar Monitoramento Reefer
Utilize a função de busca para localizar o registro de Monitoramento Reefer que deseja alterar. 

Na lista de resultados, selecione o registro desejado de Monitoramento Reefer clicando sobre ele para destacá-lo.

Localize o botão de ação "ALTERAR" e clique nele. Isso permitirá acessar a tela de edição para modificar as informações desejadas.

Na tela de edição, faça as alterações necessárias nas informações relevantes de acordo com suas necessidades. Certifique-se de inserir os novos valores corretamente nos campos apropriados.

Após realizar as alterações desejadas, clique em "OK" para confirmar as modificações e salvar as informações atualizadas.

Excluir Monitoramento Reefer
Para excluir um registro de Monitoramento Reefer, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Monitoramento Reefer que deseja excluir.

Na lista de resultados, selecione o registro de Monitoramento Reefer que deseja excluir clicando sobre ele para destacá-lo.

Localize o botão de ação "EXCLUIR" e clique nele. 

Clique em "OK" para confirmar a exclusão do registro. O sistema processará a solicitação e removerá o registro selecionado da base de dados.

Cancelar Monitoramento Reefer
Para cancelar um Monitoramento Reefer, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Monitoramento Reefer que deseja cancelar.

Na lista de resultados, selecione o registro de Monitoramento Reefer clicando sobre ele para destacá-lo.

Localize o botão de ação "CANCELAR" e clique nele.
