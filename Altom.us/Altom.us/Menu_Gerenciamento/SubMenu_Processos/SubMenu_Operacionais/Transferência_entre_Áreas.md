Pesquisar/Filtrar uma 
Para encontrar uma Transferência entre Áreas, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Planejar Transferência entre Áreas
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Clique em OK e o sistema gravá a nova movimentação no banco.
obrigatórioRed 
Destino: Neste campo, você deve especificar o local para onde a transferência de mercadorias está sendo realizada. Insira o código ou nome da área de destino.

Previsão: Aqui, você deve informar a data prevista para a conclusão da transferência. Geralmente, é a data em que se espera que as mercadorias estejam disponíveis na área de destino.

Limite: Data limite para a realização da transferência.

Mercadoria: Especifique o tipo de mercadoria que está sendo transferida. Insira o nome ou código da mercadoria para identificá-la.

QTD: Indique a quantidade da mercadoria que está sendo transferida. 

Alteração de Transferência entre Áreas
Se você deseja realizar uma alteração em um registro de Transferência entre Áreas, siga as etapas abaixo:
Na grade de registros (grid 2), selecione o registro que deseja modificar. Use o recurso de filtragem e pesquisa para encontrar o registro específico que deseja alterar.

Após selecionar o registro desejado, clique no botão de ação "Alterar" para iniciar o processo de edição. Isso permitirá que você faça as modificações necessárias no registro.

Excluir Transferência entre Áreas
Para excluir um registro de Transferência entre Áreas, siga os seguintes passos:
Na grade de registros (grid 2), selecione o registro que deseja excluir. Você pode fazer isso usando o recurso de filtragem e pesquisa para localizar o registro específico que deseja excluir.

Após selecionar o registro desejado, clique no botão de ação "Excluir" para finalizar o processo de exclusão.
