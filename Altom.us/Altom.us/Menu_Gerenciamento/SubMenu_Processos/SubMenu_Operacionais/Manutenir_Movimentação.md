Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
4 - Botões de ação
Refentes as ações possíveis da Grid 2.
Ativar Movimentação
Permite que o usuário habilite ou desabilite uma determinada movimentação de carga. Por exemplo, se a movimentação estiver desabilitada, o sistema não permitirá que o usuário execute ou programe uma movimentação para aquele contêiner.
Excluir Movimentação
Permite que o usuário exclua uma movimentação previamente programada. Por exemplo, se uma movimentação foi agendada por engano, o usuário pode excluí-la para evitar que a operação seja executada.
Executar Movimentação
Permite que o usuário execute uma movimentação previamente programada. Por exemplo, se um contêiner foi programado para ser movido de uma determinada pilha para outra, o usuário pode executar a operação através desta funcionalidade.
Reprogramar Movimentação
Permite que o usuário reprograma uma movimentação previamente agendada. Por exemplo, se houver um atraso no horário de chegada de um navio, o usuário pode reprogramar a movimentação do contêiner para uma data e hora posterior.

Pesquisar/Filtrar uma Movimentação
Para encontrar uma Movimentação, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Cadastro de Movimentação
Permite que o usuário habilite ou desabilite uma determinada movimentação de carga. Por exemplo, se a movimentação estiver desabilitada, o sistema não permitirá que o usuário execute ou programe uma movimentação para aquele contêiner.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Clique em OK e o sistema gravá a nova movimentação no banco.
Redobrigatório 
ID: este campo é preenchido automaticamente pelo sistema após o cadastro da movimentação. Ele permite identificar de forma única a movimentação registrada no sistema.
Endereço: este campo permite ao usuário informar o endereço onde a carga será movimentada. Por exemplo, o usuário pode informar o número da pilha onde a carga será armazenada.
Blueopcional 
Mercadoria: este campo permite ao usuário buscar informações sobre a mercadoria a ser movimentada. Ao clicar no botão "Buscar Mercadoria", o sistema exibirá uma lista de mercadorias disponíveis no terminal. O usuário pode selecionar a mercadoria desejada e as informações serão preenchidas automaticamente no formulário.
Etiqueta: este campo permite ao usuário buscar informações sobre uma etiqueta de mercadoria específica. Ao clicar no botão "Buscar etiqueta mercadoria", o sistema exibirá uma lista de etiquetas disponíveis no terminal. O usuário pode selecionar a etiqueta desejada e as informações serão preenchidas automaticamente no formulário.
Mercadoria Transito: este campo permite ao usuário buscar informações sobre uma mercadoria em trânsito. Ao preencher o campo "Buscar mercadoria Transitório", o sistema exibirá uma lista de mercadorias em trânsito disponível no terminal. O usuário pode selecionar a mercadoria desejada e as informações serão preenchidas automaticamente no formulário.
QTD: este campo permite ao usuário informar a quantidade de cargas a serem movimentadas. Por exemplo, se o usuário deseja mover dois contêineres, ele deve informar o número "2" neste campo.
Transporte: este campo permite ao usuário informar o tipo de transporte a ser utilizado na movimentação. Por exemplo, o usuário pode digitar "caminhão" ou "empilhadeira".
Dispositivo: este campo permite ao usuário informar o dispositivo utilizado na movimentação. Por exemplo, o usuário pode selecionar "balança" ou "Biometria".
Fluxo: este campo permite ao usuário informar o fluxo de carga da movimentação.
Excluir Movimentação
Permite que o usuário exclua uma movimentação previamente programada. Por exemplo, se uma movimentação foi agendada por engano, o usuário pode excluí-la para evitar que a operação seja executada.
Para excluir uma movimentação do sistema, é necessário pesquisar a movimentação desejada na lista, selecioná-la e, em seguida, clicar no botão "Excluir" para que a movimentação seja removida do sistema.
Executar Movimentação
Permite que o usuário execute uma movimentação previamente programada. Por exemplo, se um contêiner foi programado para ser movido de uma determinada pilha para outra, o usuário pode executar a operação através desta funcionalidade.
Para executar uma movimentação, siga os seguintes passos:
Pesquise a movimentação desejada na lista da tela de manutenção de movimentação e selecione-a na grid 2.

Clique no botão "Executar" na barra de ações.

Informe o endereço correspondente a essa movimentação e clique em "OK".

Após a confirmação, a movimentação será executada com sucesso.

Clique em OK e o sistema gravá as informações no banco.
Reprogramar Movimentação
Permite que o usuário reprograma uma movimentação previamente agendada. Por exemplo, se houver um atraso no horário de chegada de um navio, o usuário pode reprogramar a movimentação do contêiner para uma data e hora posterior.
Para reprogramar uma movimentação, siga os seguintes passos:
Pesquise a movimentação desejada na lista da tela de manutenção de movimentação e selecione-a na grid 2.

Clique no botão "Reprogramar" na barra de ações.

Informe o endereço correspondente a essa movimentação e clique em "OK".

Após a confirmação, a movimentação será executada com sucesso.

Clique em OK e o sistema gravá as informações no banco.
