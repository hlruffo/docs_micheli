1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.

Alterar Tipo Avaria
Utilize a função de busca para localizar o registro de Tipo Avaria que deseja alterar. 

Na lista de resultados, selecione o registro desejado de Tipo Avaria clicando sobre ele para destacá-lo.

Localize o botão de ação "ALTERAR" e clique nele. Isso permitirá acessar a tela de edição para modificar as informações desejadas.

Na tela de edição, faça as alterações necessárias nas informações relevantes de acordo com suas necessidades. Certifique-se de inserir os novos valores corretamente nos campos apropriados.

Após realizar as alterações desejadas, clique em "OK" para confirmar as modificações e salvar as informações atualizadas.

Excluir Tipo Avaria
Para excluir um registro de Tipo Avaria, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Tipo Avaria que deseja excluir.

Na lista de resultados, selecione o registro de Tipo Avaria que deseja excluir clicando sobre ele para destacá-lo.

Localize o botão de ação "EXCLUIR" e clique nele. Isso abrirá uma janela de confirmação para confirmar a exclusão do registro.

Clique em "OK" para confirmar a exclusão do registro de Tipo Avaria. O sistema processará a solicitação e removerá o registro selecionado da base de dados.
