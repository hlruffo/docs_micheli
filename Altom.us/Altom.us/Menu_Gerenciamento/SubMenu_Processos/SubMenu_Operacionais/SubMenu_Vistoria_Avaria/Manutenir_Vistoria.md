Alterar Vistoria
Utilize a função de busca para localizar o registro de Vistoria que deseja alterar. 

Na lista de resultados, selecione o registro desejado de Vistoria clicando sobre ele para destacá-lo.

Localize o botão de ação ‘ALTERAR’ e clique nele. Isso permitirá acessar a tela de edição para modificar as informações desejadas.

Na tela de edição, faça as alterações necessárias nas informações relevantes de acordo com suas necessidades. Certifique-se de inserir os novos valores corretamente nos campos apropriados.

Após realizar as alterações desejadas, clique em OK para confirmar as modificações e salvar as informações atualizadas.
Excluir Vistoria
Para excluir uma vistoria busque pelo registro específico que deseja excluir.  Utilize a função d filtro para isso.

Selecione o registro que deseja excluir e clique no botão de ação ‘Excluir’.

Após isso a vistoria selecionada será removida dos registros.

Realizar Vistoria
Utilize o filtro no sistema para localizar o registro de vistoria que você deseja realizar. 

Após encontrar o registro de vistoria desejado, clique nele para selecioná-lo.

Clique no botão ‘REALIZAR’ para iniciar o processo de realização da vistoria.

O sistema precisará processar a solicitação. Aguarde até que o sistema termine de carregar e atualizar as informações.

Após o processo de realização ser concluído com sucesso, o estado da vistoria no sistema deve ser atualizado para "REALIZADA".

:warning:atlassian-warning#F4F5F7Uma vez que a vistoria tenha sido realizada, não será mais possível relacionar avarias a essa vistoria. Portanto, é importante garantir que todos os registros de avarias estejam vinculados à vistoria antes de prosseguir com o processo de realização.
Carregar dado Avaria
Utilize um dos campos de filtro disponíveis na guia "Avaria" (campo 3) para pesquisar os registros de avarias que você deseja verificar.

Após a apresentação dos dados, selecione a avaria desejada na lista.

Agora, acesse o campo "Vistoria" (campo 2) e clique na opção "Carregar dado Avaria".

O sistema irá destacar/indicar em qual vistoria essa avaria foi lançada no campo "Vistoria" (campo 2).

Carregar dado Lacre
Utilize um dos campos de filtro disponíveis na guia "Lacre" (campo 3) para pesquisar os registros de lacre que você deseja verificar.

Após a apresentação dos dados, selecione o lacre desejado na lista.

Agora, acesse o campo "Vistoria" (campo 2) e clique na opção "Carregar dado Lacre".

O sistema irá destacar/indicar em qual vistoria esse lacre foi lançado no campo "Vistoria" (campo 2).

Pesquisar/Filtrar Avaria
Para realizar uma pesquisa de avarias, é indispensável fornecer informações ao filtro localizado na guia correspondente (avaria). Qualquer um dos campos pode ser preenchido para localizar a avaria desejada. Você pode buscar por Mercadoria, etiqueta, Grupo de Mercadoria, Severidade, Tipo de Avaria ou Movimento de Transporte.
Logo após fornecer algumas das informações acima, basta clicar no botão de ação ‘Pesquisar’ que os dados de Avaria serão apresentados na grid(3).
Carregar dado uma Vistoria (avaria)
Antes de utilizar essa ação, informe ao sistema qual registro de vistoria deseja visualizar informações sobre avarias.

Vá até a grid 2 (Campo Vistoria) para utilizar o filtro e encontrar o registro específico que você deseja examinar.

Selecione o registro desejado clicando sobre ele.

Em seguida, navegue para a grid 3 (Guia Avaria) no sistema.

Clique no botão de ação denominado "Carregar dado uma Vistoria".

Os dados de avaria associados à vistoria selecionada serão carregados e exibidos na mesma grid.

As informações apresentadas incluem Vistoria, ID, Vistoriado, Mercadoria, Quantidade, Peso, estado (Liberado ou não), localização e tipo de avaria, caso existam.

Incluir Avaria
Utilize o campo de filtro para pesquisar e selecionar o registro específico de vistoria ao qual deseja associar a avaria.

Após a seleção, os dados do registro de vistoria serão exibidos na Grid 2. Certifique-se de ter o registro correto.

Na mesma tela, role para baixo até a Grid 3, que corresponde à guia de avarias.

Preencha os campos conforme descrição abaixo.

Clique no botão Incluir (+).

Clique em Ok para salvar.
obrigatórioRed  
Tipo de Avaria: Escolha o tipo de avaria dentre as opções cadastradas (ex.: Sujo, Solto).
Quantidade (QTD): Indique a quantidade de itens avariados.
opcionalBlue  
Mercadoria: Realize a busca pela mercadoria associada à avaria.
Etiqueta: Informe o identificador correspondente.
Trânsito: Selecione a opção que representa a mercadoria em trânsito.
Providência: Selecione a providência necessária em relação à avaria.
Peso: Informe o peso relacionado à avaria.
Localização: Descreva a localização da avaria.
Certifique-se de que esse processo seja realizado antes da realização da vistoria, pois após a conclusão, não será possível cadastrar novas avarias.

Pesquisar/Filtrar Lacre
Para realizar uma pesquisa de lacres, siga os passos abaixo:
Vá até a guia correspondente a lacre na grid(3)

Forneça informações nos campos disponíveis para filtrar a pesquisa. Você pode preencher qualquer um dos seguintes campos: Número do Container e Transporte.

Após inserir as informações desejadas, clique no botão de ação "Pesquisar".

Os dados de lacre que correspondem aos critérios de pesquisa serão apresentados na grid(3).

Carregar dado uma Vistoria (lacre)
Antes de utilizar esta ação, informe ao sistema qual registro de vistoria deseja visualizar informações sobre lacres.
Vá até a Grid 2 (Campo Vistoria) para utilizar o filtro e encontrar o registro específico que você deseja examinar.

Selecione o registro desejado clicando sobre ele.

Em seguida, navegue até a Grid 3 (Guia Avaria) no sistema.

Clique no botão de ação denominado "Carregar Dados de uma Vistoria". Os dados de avaria associados à vistoria selecionada serão carregados e exibidos na mesma grid.

Selecione o registro desejado e mude para a guia Lacre.

Após isso, basta clicar no botão de ação "Carregar Dados de uma Avaria". As informações de lacre serão apresentadas na mesma grid, caso existam.

Cadastro de Lacre

Clique no botão Incluir (+) na gria Lacre.

obrigatórioRed  
Container (Movimento): Insira o identificador do contêiner associado ao movimento.
Transporte Movimento: Indique o tipo de transporte relacionado ao movimento, por exemplo, terrestre, marítimo, aéreo, etc.
Origem: Escolha a origem do lacre entre as opções disponíveis: ALFÂNDEGA, IMPORTADOR, CARRIER, MINISTÉRIO DA AGRICULTURA, EXPORTADOR ou TERMINAL.
Número: Atribua um número de identificação único ao lacre.
Registro na Grid →  Os registros de lacres cadastrados são armazenados e exibidos nesta Grid.
"Incluir"dentro do formulário: Após preencher as informações, clique neste botão para cadastrar o lacre. Essa opção facilita o cadastros de muitos lacres para uma mesmo container.
Exclusão de Registros: Caso necessário, é possível excluir registros diretamente na grid, proporcionando flexibilidade e controle sobre os dados cadastrados.

Alterar Lacre
Para efetuar a alteração de um registro de lacre, é essencial garantir que haja dados carregados e mantidos nessa grid. Não se esqueça de seguir o passo de "Carregar um dado de Lacre" antes de prosseguir.
Após carregar os dados na grid, selecione o registro que deseja alterar.

O formulário de alteração será aberto, permitindo que o usuário modifique as informações conforme necessário.

Clique em "OK" para salvar as alterações.

Excluir Lacre 
Para excluir um registro de lacre, siga os passos abaixo:
Antes de prosseguir com a exclusão, assegure-se de carregar os dados na grid de lacres. Siga o passo de "Carregar um Dado de Lacre" para garantir que os dados estejam disponíveis.

Com os dados carregados, identifique e selecione o registro de lacre que deseja excluir.

Após selecionar o registro desejado, clique no botão de ação "Excluir". Pode ser necessário confirmar a exclusão.
