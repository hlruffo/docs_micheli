1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 e 3 - Campos de resultados
O campo 2 exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. O campo 3 fornece informações a partir de registro que podem ser selecionados no campo 2. 
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 e 6 - Botões de ação
Referente as ações possíveis nas Grid 2 e 3.

Pesquisar/Filtrar Termo Avaria
Para buscar um Termo Avaria específico na tela de filtro, basta informar o conjunto de informações refentes ao registro. Se desejar pesquisar todos os dados disponíveis na tela, deixe o campo em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Gerar Termo Avaria
Para gerar um Termo Avaria preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed 
Mercadoria: Busque e selecione a mercadoria que deseja associar ao Termo de Avaria.
Grupo Mercadoria: Busque e selecione o grupo de mercadoria relevante.
Fiscal: Busque e selecione o fiscal responsável pelo Termo de Avaria.
Clique em OK para salvar.
Termo avaria por mercadoria só para Container, para Granel e Carga utilizar Grupo Mercadoria.
Alterar Termo Avaria
Utilize a função de busca para localizar o registro de Termo Avaria que deseja alterar. 

Na lista de resultados, selecione o registro desejado de Termo Avaria clicando sobre ele para destacá-lo.

Localize o botão de ação "ALTERAR" e clique nele. Isso permitirá acessar a tela de edição para modificar as informações desejadas.

Na tela de edição, faça as alterações necessárias nas informações relevantes de acordo com suas necessidades. Certifique-se de inserir os novos valores corretamente nos campos apropriados.

Após realizar as alterações desejadas, clique em OK para confirmar as modificações e salvar as informações atualizadas.
Liberar Termo Avaria
Para liberar um Termo de Avaria, siga as etapas abaixo:
Utilize a função de busca para localizar o registro do Termo de Avaria que deseja liberar.

Na lista de resultados, selecione o registro desejado do Termo de Avaria clicando sobre ele para destacá-lo.

Localize o botão de ação "LIBERAR" e clique nele.

O sistema irá carregar as informações e retornará uma mensagem de confirmação caso a operação tenha sido bem-sucedida.

Imprimir Termo Avaria
Para imprimir um Termo de Avaria, siga as etapas abaixo:
Utilize a função de busca para localizar o registro do Termo de Avaria que deseja imprimir.

Na lista de resultados, selecione o registro desejado do Termo de Avaria clicando sobre ele para destacá-lo.

Localize o botão de ação “Imprimir Termo de Avaria” e clique nele.

O sistema irá carregar as informações e retornará com o download do arquivo no seu navegador contendo as informações da avaria, pronto para impressão.

Carregar dados de Avaria
Para carregar dados de Avaria, siga estas etapas:
Lembre-se de que os campos de resultados nesta tela são interativos entre si. Isso significa que, para carregar dados de Avaria, é necessário seguir os seguintes passos:
Comece selecionando o registro de Termo Avaria que deseja visualizar os dados no Campo 2 (Termo Avaria).

Após selecionar o registro relevante no Campo 2, siga para o Campo 3.

No Campo 3, clique no botão de ação "Carregar". Isso gerará os dados para visualização, que incluem o número da vistoria, o estado da vistoria (vistoriado ou não), informações sobre a mercadoria, o Container trânsito Id, a quantidade (QTD), o peso, a liberação, o tipo, as providências e o número do termo relacionados à avaria.

Excluir Avaria
Para excluir um registro de avaria, siga as etapas semelhantes ao processo anterior:
Comece selecionando o registro de Termo Avaria que deseja excluir no Campo 2 (Termo Avaria).

Após selecionar o registro relevante no Campo 2, siga para o Campo 3.

No Campo 3, clique no botão de ação "Excluir".

O sistema realizará a exclusão do registro de avaria, removendo-o do sistema.
