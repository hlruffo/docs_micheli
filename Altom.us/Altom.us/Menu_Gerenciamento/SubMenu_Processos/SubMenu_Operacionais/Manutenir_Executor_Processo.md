Upload Executor Processo
Para iniciar o upload de um arquivo antes é necessário selecionar o tipo Executor para que a ação seja bem sucedida. Abaixo informamos as definições de cada uma das opções que podem ser selecionadas.
Rolagem: O Tipo de Executor "Rolagem" refere-se a um processo que envolve o movimento de contêineres ou carga de um ponto para outro, geralmente dentro do mesmo terminal portuário. Pode incluir a transferência de contêineres de áreas de armazenamento para áreas de carregamento, descarregamento ou outras áreas dentro do terminal.

Transferência Categoria: O Tipo de Executor "Transferência Categoria" é usado para processos que envolvem a movimentação de contêineres entre categorias específicas, como a transferência de contêineres de importação para exportação ou entre categorias de armazenamento diferentes. 

Transbordo entre Terminais Saída: Este Tipo de Executor é aplicado quando o processo requer a transferência de contêineres ou carga de um terminal de origem para outro terminal de destino, com o objetivo de saída do material ou carga do terminal de origem. É comum em casos de transbordo de carga entre terminais de diferentes localizações geográficas.

Transbordo entre Terminais Entrada: Ao escolher o Tipo de Executor "Transbordo entre Terminais Entrada," o processo envolve a transferência de contêineres ou carga de um terminal de origem para outro terminal de destino, mas com o objetivo de entrada da carga no terminal de destino. Isso é relevante para situações em que a carga deve ser recebida em um novo terminal para posterior processamento ou distribuição.

Processar Arquivo
Para Processar o Arquivo Lote, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Arquivo que deseja processar.

Na lista de resultados, selecione o registro que deseja processar clicando sobre ele para destacá-lo.

Localize o botão de ação “Processar Arquivo” e clique nele. Isso fará com que o arquivo seja processado. 

  
Pesquisar Logs(Erros/Avisos) 
Aba Logs(Erros/Avisos)  
Para realizar uma pesquisa nos logs, siga os seguintes passos:
Comece por selecionar um registro na "Grid 2". Localize o arquivo ou item do qual deseja obter informações nos logs.

Role a tela para acessar a "Grid 3".

Clique no botão "Pesquisar" para iniciar a pesquisa.

Além disso, é possível refinar a pesquisa filtrando os logs por tipos, que podem incluir informações, avisos, erros e registros do sistema.

Dessa forma, você poderá acessar e analisar os registros de logs de acordo com as suas necessidades, garantindo um gerenciamento eficiente das informações registradas.
Carregar dado Executor Processo
Aba Logs(Erros/Avisos)  
Para obter informações detalhadas sobre um Executor de Processo, siga estas etapas:
Comece por selecionar um registro na "Grid 2". Localize o arquivo ou item específico do qual deseja obter informações.

Role a tela para acessar a "Grid 3".

Clique no botão "CARREGAR DADO EXECUTOR PROCESSO" para gerar dados, como mensagens e tipos associados ao Executor de Processo selecionado.  

Cadastrar Tipo Executor
Aba Tipo Executor 
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

 ObrigatórioRed 
Nome: Indique o nome so executor nesse campo.
Tipo Mensagem: Selecione dentre as opções pre-cadastradas qual o tipo mensagem que se encaixa a este executor.
Sintaxe: se refere à estrutura ou formato específico que as mensagens ou informações seguem ao serem processadas por esse Tipo de Executor
Descrição: Este campo é usado para fornecer uma descrição mais detalhada do Tipo de Executor.
Exemplo: é destinado a fornecer um exemplo prático ou amostra de como as mensagens são formatadas ou processadas pelo Tipo de Executor.
Altera Tipo Executor
Aba Tipo Executor  
Para modificar um Tipo Executor existente, siga estas etapas:
Comece por selecionar o registro que deseja alterar. Utilize a função "PESQUISAR TODOS" para localizar os registros disponíveis.

Os registros correspondentes serão exibidos na "Grid," organizados em colunas com suas informações. Escolha o registro que deseja alterar.

Na mesma "Grid," clique no botão de ação "Alterar" associado ao registro que você deseja modificar.

Excluir Tipo Executor
Aba Tipo Executor  
Para remover um Tipo Executor existente, siga as seguintes etapas:
Comece por selecionar o registro que deseja excluir. Use a função "PESQUISAR TODOS" para localizar os registros disponíveis.

Os registros correspondentes serão exibidos na "Grid," organizados em colunas com suas informações. Escolha o registro que deseja excluir.

Na mesma "Grid," clique no botão de ação "Excluir" associado ao registro que você deseja remover.

Pesquisar todos
Aba Tipo Executor  
Para pesquisar todos os registros disponíveis, siga estas etapas:
Basta clicar no botão de ação em forma de lupa localizado nesta grid.

As informações, como tipo de mensagem, nome, sintaxe, descrição e exemplo, serão exibidas na grid, organizadas em colunas para facilitar a visualização.

Carregar Propriedades
Aba Propriedades 
Para carregar os dados com chave e valor de um registro específico, siga estas etapas:
Comece por encontrar e selecionar o registro desejado na "Grid 2".

Após a seleção, role a tela para acessar a "Grid 3".

Clique no botão de ação "CARREGAR" para executar a ação.

Cadastrar Propriedades
Aba Propriedades  
Para cadastrar uma propriedade, siga estas etapas:
Comece por encontrar e selecionar o registro desejado na "Grid 2."

Após a seleção, role a tela para acessar a "Grid 3."

Escolha o tipo de propriedade, que neste caso, pode ser sinalizado como "EXECUTOR."

Preencha os campos de "Chave" e "Valor" localizados no topo da grid.

Após preencher esses campos, clique no botão de ação "Incluir," e os dados serão vinculados ao registro de arquivo selecionado.

Excluir Propriedades
Aba Propriedades  
Para excluir um registro de propriedade, siga os passos abaixo:
Utilize a função de busca para localizar o registro que deseja excluir.

Na lista de resultados, selecione o registro deseja excluir clicando sobre ele para destacá-lo.

Localize o botão de ação "EXCLUIR" e clique nele para finalizar a ação.
