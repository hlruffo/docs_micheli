Pesquisar/Filtrar um Indicador
Para encontrar um Indicador, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Cadastro de Indicador
Os indicadores determinam se as medidas seguirão um padrão temporal ou serão consolidadas, tendo um impacto direto na forma como são visualizadas quando incluídas em um painel de controle.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

Clique em OK e o sistema gravá a nova movimentação no banco.
obrigatórioRed 
Nome: de um nome para seu indicador. 
Ex: ENTRADA CONTAINER CHEIO.
Classe: Este campo pode ser usado para atribuir uma classe específica ao indicador, se aplicável. Busque pelo CoReflexion.
Abreviador: Aqui, você pode fornecer uma abreviação ou sigla para o indicador. 
Meta: Este campo é destinado a especificar a meta ou o objetivo associado ao indicador. 
Ex.: MON_CARGA_ENTRADA
Classe (Tendência ou Sinal): Esse campo permite definir se o indicador está relacionado a uma tendência ou a um sinal. Tendências indicam a direção do indicador ao longo do tempo, enquanto sinais podem ser pontos de virada ou eventos específicos.
Tipo (TI, Financeiro, Comercial, Gestão ou Operacional): Aqui, você deve selecionar o tipo ou categoria do indicador. Os tipos podem incluir Tecnologia da Informação (TI), Financeiro, Comercial, Gestão ou Operacional, dependendo do contexto.
Estilo (Temporal ou Consolidado): Esse campo define o estilo de apresentação do indicador. Selecione "Temporal" se o indicador for exibido ao longo do tempo, mostrando sua evolução, e escolha "Consolidado" se o indicador for apresentado de forma resumida ou agregada, geralmente para análises mais abrangentes.
Alterar Indicador
Para alterar um indicador, siga os seguintes passos:
Primeiro, localize o registro do indicador que deseja modificar. Utilize o campo de filtro para a busca. Os resultados serão exibidos na grade 2.

Selecione o indicador desejado na grade 2 e clique no botão de ação “Alteração”.

Faça as alterações nas informações que deseja modificar.

Clique em 'OK' para concluir a ação de alteração do indicador.
Excluir Indicador
Para excluir um indicador, siga os seguintes passos:
Primeiro, localize o registro do indicador que deseja excluir. Utilize o campo de filtro para a busca. Os resultados serão exibidos na grade 2.

Selecione o indicador desejado na grade 2.

Clique no botão de exclusão ou na opção "Excluir" para iniciar o processo de exclusão.

Clique em 'OK' para concluir a ação de Exclusão do indicador.

Cadastro de Meta
As metas são a representação das aspirações da empresa. Embora possam ser diversas, cada meta não necessariamente tem visibilidade sobre os indicadores, medidas, métricas e sensores que possam estar direta ou indiretamente associados a outras metas.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed  
Nome: Nome da sua meta. Ex: AUMENTAR_ROBUSTEZ.
OpcionalBlue 
Descrição: Diz respeito a descrição dessa meta. Preencha caso queira dar mais detalhes acerca da Meta cadastrada. Ex: Aumentar a robustez não funcional(sistema) do TOS+
Clique em OK para salvar a Meta.
Alterar Meta
Para modificar uma meta existente, siga os seguintes passos:
Comece buscando o registro da meta que você deseja alterar. Utilize o botão de pesquisa representado por um ícone de lupa na grade 2. O sistema retornará os resultados da busca.

Selecione o registro da meta que precisa de alteração na lista de resultados.

Clique no botão de ação "Alterar" para iniciar o processo de modificação.

Faça as alterações necessárias nas informações desejadas.

Por fim, clique no botão "OK" para salvar as alterações.

Excluir Meta
Para excluir uma meta existente, siga os seguintes passos:
Inicie buscando o registro da meta que você deseja excluir. Use o botão de pesquisa representado por um ícone de lupa na grade 2. O sistema mostrará os resultados da busca.

Selecione o registro da meta que você deseja remover na lista de resultados.

Clique no botão de ação "Excluir" para começar o processo de exclusão.

Confirme a exclusão quando solicitado para finalizar.

Carregar dados de Medida
Aba: medida 
Para carregar dados de medida, siga as etapas abaixo:
Na grade de indicadores (grid 2), selecione o indicador para o qual deseja visualizar os dados de medida, incluindo nome, tipo e descrição.

Na grade 3, clique no botão de ação 'CARREGAR'.

O sistema retornará os resultados dos dados de medida associados ao indicador selecionado.

Cadastro de Medida
Aba: medida  
Medidas são entidades que contém as características do que se deseja medir. Denotada por um nome, serve para que o TOS+ capture propriedades eventos de eventos gerados no sistema para a construção de métricas. Elas não devem ser confundidas com valores!
Selecione um regsitro de indicadores para associar aqui.

Tipo: Selecione entre os tipos disponíveis conforme a medida a ser adastrada. Escolha entre Acumulador, Qualificador, Consolidador.
