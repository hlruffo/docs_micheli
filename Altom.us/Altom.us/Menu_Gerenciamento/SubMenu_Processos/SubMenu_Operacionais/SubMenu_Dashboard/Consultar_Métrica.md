1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. 2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. 
3 - Campo de resultados de registros
Exibe os registros de Propriedades de Evento associados a Métrica da gid 2.
4 - Botões de ação referentes ao filtro

O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.

Pesquisar/Filtrar Métrica
Para encontrar uma Métrica, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Simular Métrica
Comece a simulação Clicando no botão de ação “Simular Métrica”.
Busque o Indicador correspondente que deseja simular.

Busque a Medida correspondente que deseja simular.

Informe o Valor.

Clique no botão de ação incluir:

Clique em OK para iniciar a simulação.

Dependendo da simulação, O sensor será ativado e definirá data do alarme.

Carregar Propriedades Evento
Para obter os dados das propriedades dos indicadores, siga as etapas abaixo:
Primeiro, localize e selecione o registro do indicador na Grid 2.

Role a tela para a Grid 4.

Clique no botão de ação 'Carregar'.

O sistema fornecerá as chaves e valores das propriedades do indicador, caso existam.
