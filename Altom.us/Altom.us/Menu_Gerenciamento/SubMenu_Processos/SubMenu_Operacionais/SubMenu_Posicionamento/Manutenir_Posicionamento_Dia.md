1 - Campo filtro

2 - Campo de resultados
Exibe os resultados de um filtro e dados gerais de posicionamento em formato de calendário, aplicado a um conjunto de dados ou informações fornecidas no campo 1.
3 - Botão de ação
Conforme as informações fornecidas no filtro, como serviço, posicionamento e areá, o usuário pode gerar um novo posicionamento dia clicando neste botão.

Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.

Botões de navegação que facilitam o manuseio do calendário.

Pesquisar/Filtrar Posicionamento Dia
Para encontrar uma viagem de navio, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão “PESQUISAR” para obter todas as informações pré-existentes na tela.
Consultar Posicionamento
Permite visualizar os posicionamentos registrados e as programações usando um calendário mensal. Aqui estão os passos gerais para utilizar essa funcionalidade:
No calendário mensal exibido na tela, você deve ver uma lista de todos os dias do mês.

Passe o mouse sobre as bolas coloridas: Cada dia no calendário pode ter uma ou mais bolas coloridas associadas a ele. Essas bolas representam os posicionamentos registrados ou programações para o dia em questão. Para obter uma breve informação sobre o posicionamento, passe o mouse sobre a bola colorida que corresponde ao dia desejado.

Clique na bola para mais detalhes: Se você desejar obter informações mais detalhadas sobre um posicionamento específico, clique na bola colorida associada ao dia desejado no calendário. Uma janela pop-up deve aparecer, exibindo informações resumidas sobre o posicionamento.

Navegue pelo calendário: Você pode usar as setas ou os controles disponíveis na tela para navegar pelos meses ou alterar o período do calendário, permitindo que você visualize os posicionamentos registrados em meses anteriores ou futuros.

Gerar Posicionamento Dia
Para gerar um posicionamento basta seguir esses passos simples:
No calendário mensal exibido, localize o dia para o qual deseja gerar o posicionamento. Clique sobre o dia desejado para selecioná-lo.

Após selecionar o dia, clique no botão na tela que permita iniciar o processo de geração de posicionamento "Gerar Posicionamento Dia".

Aguarde o processamento. O sistema TOS+ carregará e gerará o posicionamento para o dia especificado.

Após a conclusão do processo de geração, o sistema deve retornar uma mensagem de confirmação indicando que o posicionamento foi gerado com sucesso.

Certifique-se de que o dia selecionado esteja correto antes de iniciar o processo de geração. Se você precisar gerar posicionamentos para vários dias, repita esse processo para cada dia desejado.
