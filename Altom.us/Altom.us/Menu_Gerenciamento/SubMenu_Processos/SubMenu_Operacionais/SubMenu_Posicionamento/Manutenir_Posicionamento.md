Alterar Posicionamento
Use a função de filtro ou pesquisa para localizar o registro específico que você deseja alterar.

Após localizar o registro desejado na "grid 2" (Posicionamento), clique sobre ele para selecioná-lo. Geralmente, isso pode ser feito clicando na linha do registro.

Depois de selecionar o registro, procure e clique em "ALTERAR".

Uma vez que você clicar no botão de "ALTERAR", a tela de edição deve aparecer. Agora você pode fazer as alterações desejadas nas informações do registro.

Após concluir as alterações, certifique-se de revisar tudo cuidadosamente para garantir que os dados estejam corretos e clique em OK para salvar os dados.

Excluir Posicionamento
Para excluir um posicionamento, siga estas etapas:
Use a função de filtro ou pesquisa para localizar o registro específico que você deseja excluir.

Após localizar o registro desejado na “grid 2” (Posicionamento), clique sobre ele para selecioná-lo. Isso pode ser feito clicando na linha do registro.

Após selecionar o registro, procure e clique em "EXCLUIR" .

Certifique-se de que o registro que você deseja excluir está correto, pois a exclusão pode ser irreversível.

Confirme a exclusão, e o registro selecionado será removido do sistema.

Cancelar Posicionamento
Essa funcionalidade permite que o usuário cancele qualquer registro de posicionamento previamente cadastrado.
Para cancelar um posicionamento, siga os passos abaixo:
Utilize a ferramenta de filtro para buscar o posicionamento que deseja cancelar.

Localize o registro desejado, selecione-o, e clique no botão de ação “Cancelar”.

Informe o motivo do cancelamento na janela de confirmação e clique no botão “OK” para confirmar.

Reposicionar Posicionamento
Para reposicionar um posicionamento, siga os passos abaixo:
Utilize a ferramenta de filtro para buscar o posicionamento que deseja reposicionar.

Localize o registro desejado, selecione-o, e clique no botão de ação “Reposicionar”.

Informe a data nova do reposicionamento na janela de confirmação e clique no botão “OK” para confirmar.

Trocar Serviço Posicionamento
Nesta tela, também é possível efetuar a troca do serviço de posicionamento de um registro. Siga estas etapas para realizar a ação:
Utilize a função de busca para localizar o registro no qual deseja trocar o serviço.

Após encontrar o registro desejado, selecione-o clicando sobre ele. 

Procure e clique no botão de ação “TROCAR SERVIÇO DE POSICIONAMENTO”.

Após clicar em “TROCAR SERVIÇO DE POSICIONAMENTO”, uma janela de confirmação será aberta.

Nessa janela de confirmação, informe o novo serviço de posicionamento que deseja atribuir ao registro.

Se houver uma data associada à troca de serviço, ajuste-a conforme necessário.

Clique em “OK” para confirmar a troca de serviço e salvar as informações.

Carregar dados Contêiner e Carga
Guia: Container Guia: Carga 
Na Grid 3, encontram-se duas abas (Contêiner e Carga) que possuem o botão de ação “Carregar”, permitindo obter informações relevantes sobre as mercadorias associadas ao posicionamento, como o ID do Movimento, Grupo de Mercadoria, Quantidade, IMO, entre outros.
Para carregar esses dados, siga os passos abaixo:
Selecione um registro de posicionamento desejado na Grid 2, clicando sobre ele para marcá-lo.

Role a página até a Grid 3 e selecione a aba correspondente à sua pesquisa (Contêiner ou Carga).

Clique no botão de ação “Carregar”.

Os dados solicitados serão exibidos imediatamente, fornecendo as informações necessárias sobre as mercadorias associadas ao posicionamento selecionado.

:info:atlassian-info#F4F5F7É fundamental realizar este passo antes de utilizar as ações disponíveis nas duas guias, já que a presença de informações na tela é um requisito essencial para que o usuário possa usar os seus recursos subsequentes.
