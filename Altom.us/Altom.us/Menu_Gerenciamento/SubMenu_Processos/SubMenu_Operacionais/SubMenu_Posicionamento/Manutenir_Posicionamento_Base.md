Pesquisar/Filtrar um Período Base
Para buscar um Período Base específico na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Período Base
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

OBRIGATÓRIORed
Período de Início: Insira a data e hora de início no formato DD/MM/YYYY HH:MM.
Período de Término: Insira a data e hora de término no formato DD/MM/YYYY HH:MM.
Número de Dias: Informe o número de dias desejado.
Clique em Ok e as informações serão salvas no banco.
Inativar/Reativar Período Base
Para inativar ou reativar um Período Base, siga estas etapas:
Passo 1: Use a função de filtro para localizar o registro de período base que deseja desativar ou reativar.
Passo 2: Selecione o registro desejado e clique no botão de ação "Inativar/Reativar".
Passo 3:  Uma janela de confirmação será aberta com a seguinte mensagem: 
Passo 4: Confirme a ação clicando em Ok.
Excluir Período Base
Use a função de filtro para localizar o registro de Período Base que você deseja excluir.

Após encontrar o registro desejado, clique sobre ele para selecioná-lo.

Em seguida, localize e clique no botão “Excluir” para finalizar a ação.

Carregar dados Posicionamento Base
Para carregar esses dados, siga os passos abaixo:
Busque pelo Período Base que deseja. Utilize a função de filtro para isso.

Selecione o registro de Período Base desejado na Grid 2, clicando sobre ele para marcá-lo.

Role a página até a Grid 3 e clique no botão de ação ‘Carregar’.

Os dados solicitados serão exibidos imediatamente, fornecendo as informações necessárias sobre o Posicionamento base associado/os ao Período Base selecionado que agora também podem ser manutenidos.

Cadastrar Posicionamento Base
Para cadastrar um Posicionamento Base, inicie localizando o Período Base ao qual deseja vinculá-lo. Certifique-se de seguir o processo de carregamento dos dados do Posicionamento Base antes de prosseguir.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2.

Clique em Ok e as informações serão salvas no banco.
OBRIGATÓRIORed  
Serviço Posicionamento: selecione o serviço de posicionamento apropriado a partir de uma lista de serviços disponíveis.
Área: Selecione a área à qual o Posicionamento Base está relacionado.
Classe Carga: Preencha este campo com a classe de carga específica associada ao Posicionamento Base. Container, Carga ou Granel.
Formato: Selecione o formato apropriado a partir de uma lista de formatos disponíveis.
QTD (Quantidade): Insira a quantidade desejada ou relevante para o Posicionamento Base.
Alterar Posicionamento Base
Para alterar um Posicionamento Base, siga os seguintes passos:
Comece localizando o registro de Posicionamento que deseja alterar. Certifique-se de seguir o processo de Carregamento de Posicionamento Base para visualizar e selecionar o registro desejado.

Após isso, continue com os seguintes passos:
Selecione o registro de Posicionamento Base que deseja alterar, clicando sobre ele. 

Clique no botão de ação 'Alterar'. 

Faça as alterações necessárias nas informações do registro. 

Por fim, clique em 'Ok' para salvar as modificações.

Excluir Posicionamento base
Comece localizando o registro de Posicionamento que deseja excluir. Certifique-se de seguir o processo de Carregamento de Posicionamento Base para visualizar e selecionar o registro desejado.

Após isso, continue com os seguintes passos:
Selecione o registro de Posicionamento Base que deseja excluir, clicando sobre ele.

Clique no botão de ação 'Excluir'.

O registro de Posicionamento Base será excluído do sistema. Certifique-se de confirmar a ação para finalizar a exclusão.
