Pesquisar/Filtrar Retenção
Para buscar uma Retenção específica na tela de filtro, basta informar o conjunto de informações refentes ao registro. Se desejar pesquisar todos os dados disponíveis na tela, deixe o campo em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Carregar Retenção
Para carregar os dados de uma retenção, siga estes passos simples:
Utilize o filtro para localizar o registro de retenção desejado.

Selecione o registro de retenção encontrado.

Clique no botão "Carregar" para executar a ação.

Dessa forma, você poderá facilmente carregar os dados de retenção necessários para o seu processo.
Cadastrar Retenção
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

Após o preenchimento, clique em “OK” para salvar as informações no banco de dados do TOS+.
obrigatórioRed 
Grupo Mercadoria: utilize o campo para buscar o grupo mercadoria associado a retenção a ser cadastrada. 
Número do Documento: Informe o número do documento de retenção.
Tipo: aqui você deve especificar o tipo de retenção a ser aplicada a esse registro. Pesquise por tipos já cadastrados ao sitema e selecione.
Fiscal: Neste campo, você deve indicar o nome do fiscal, ou responsável pela retenção.
opcionalBlue 
Nro. Processo: Este campo é opcional e pode ser usado para inserir o número de processo associado à retenção, se aplicável. 
Alterar Retenção
Utilize a função de busca para localizar o registro de Retenção que deseja alterar. 

Na lista de resultados, selecione o registro desejado clicando sobre ele para destacá-lo.

Localize o botão de ação "ALTERAR" e clique nele. Isso permitirá acessar a tela de edição para modificar as informações desejadas.

Na tela de edição, faça as alterações necessárias nas informações relevantes de acordo com suas necessidades. Certifique-se de inserir os novos valores corretamente nos campos apropriados.

Após realizar as alterações desejadas, clique em "OK" para confirmar as modificações e salvar as informações atualizadas.

Excluir Retenção
Para excluir um registro de Retenção, siga os passos abaixo:
Utilize a função de busca para localizar o registro de Retenção que deseja excluir.

Na lista de resultados, selecione o registro que deseja excluir clicando sobre ele para destacá-lo.

Localize o botão de ação "EXCLUIR" e clique nele. Isso abrirá uma janela de confirmação para confirmar a exclusão do registro.

Clique em "OK" para confirmar a exclusão do registro.

Carregar Item Retenção
Para carregar os dados de um Item Retenção, siga estes passos simples:
Utilize o filtro para localizar o registro de retenção desejado.

Selecione o registro de retenção encontrado na Grid 2.

Siga para a grid 3 e clique no botão de ação CARREGAR para trazer os dados da retenção selecionada na grid dois para a grid 3, onde as informações são separadas por Mercadoria, Qtd, Tipo, Localização, ocorrência e observação.

Dessa forma, você poderá facilmente carregar os dados de retenção necessários para o seu processo.
Cadastrar Item Retenção
Antes de iniciar o processo de cadastro de um novo item de retenção, é necessário associá-lo a um registro de retenção existente. Para fazer isso, siga as etapas abaixo:
Utilize o filtro para localizar o registro de retenção ao qual deseja vincular o novo item de retenção. Os resultados da pesquisa serão exibidos na "Grid 2".

Selecione o registro desejado e prossiga para a "Grid 3".

Na tela, localize o botão "Incluir".

Após clicar nele, uma janela pop-up se abrirá, permitindo a inserção das informações no formulário de cadastro.

Preencha os campos conforme demonstrado abaixo:
Clique no botão Incluir (+).

obrigatórioRed 
Mercadoria: utilize o campo para buscar a mercadoria associado ao item retenção a ser cadastrado.
Qtd: Informe a quantidade de itens.
Tipo: aqui você deve especificar o tipo de retenção a ser aplicada a esse registro. Reter ou Liberar.
Excluir Item Retenção
Com alguns registros de Item Retenção visiveis na grid 3, também é possível fazer a exclusão de registros. 
Na lista de resultados, selecione o registro que deseja excluir clicando sobre ele para destacá-lo.

Localize o botão de ação "EXCLUIR" e clique nele. Isso abrirá uma janela de confirmação para confirmar a exclusão do registro.

Clique em "OK" para confirmar a exclusão do registro.
