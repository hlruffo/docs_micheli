Manutenir Reserva Janela - A.0068.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis da Grid 3.
Carregar dado de registro de reserva
Permite que o usuário visualize as informações previamente registradas sobre uma reserva já existente no sistema. Essas informações podem incluir, por exemplo, a data de início e término da reserva, o tipo de carga, o número de contêineres ou equipamentos necessários, entre outros dados.
Incluir reserva
Esta função permite que o usuário crie uma nova reserva no sistema, informando as datas de início e término da reserva, o tipo de carga a ser transportada, a quantidade de contêineres ou equipamentos necessários, e outras informações relevantes. A inclusão de uma nova reserva permite que o usuário planeje suas operações de transporte com antecedência e garanta a disponibilidade dos recursos necessários para atender às demandas dos seus clientes.
Realocar reserva
Permite que o usuário altere as informações de uma reserva já existente no sistema, como a data de início e término da reserva, a quantidade de equipamentos necessários, entre outras informações. A realocação de uma reserva pode ser necessária, por exemplo, para acomodar mudanças na demanda do cliente ou alterações na programação de operações do terminal.
Cancelar, encerrar reserva
Esta função permite que o usuário cancele ou encerre uma reserva já existente no sistema. O cancelamento de uma reserva pode ser necessário, por exemplo, se o cliente desistir do transporte ou se ocorrer uma mudança na programação de operações do terminal que torne a reserva inviável. O encerramento de uma reserva, por sua vez, permite que o usuário finalize a operação de transporte de forma organizada e registre todas as informações relevantes para fins de controle e faturamento.

Pesquisar/Filtrar uma Reserva
Para encontrar uma reserva, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Carregar dado de Registro Reserva
Permite que o usuário visualize as informações previamente registradas sobre uma reserva já existente no sistema. Essas informações podem incluir, por exemplo, a data de início e término da reserva, o tipo de carga, o número de contêineres ou equipamentos necessários, entre outros dados.
Para carregar os dados de um registro específico, siga os passos abaixo:
Utilize a função de busca para localizar o registro desejado;

Selecione o registro na lista apresentada;

Acesse a Grid 3 para visualizar as informações detalhadas do registro selecionado;

Clique no botão "Carregar Dado de Registro" para exibir as informações na tela.

Dessa forma, você poderá acessar as informações relevantes de maneira rápida e eficiente, permitindo uma melhor gestão e controle dos processos no sistema.
Cadastrar Reserva
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 3 (+).

Clique em OK e o sistema gravá a nova Janela no banco.
Selecione o registro que deseja fazer a inclusão da reserva (Grid 2). Logo após desça a página para a Grid de reserva (3) e clique no botão de ação incluir.
