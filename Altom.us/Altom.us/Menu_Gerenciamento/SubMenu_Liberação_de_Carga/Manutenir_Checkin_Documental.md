Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botão de ação
Refente a ação possíveil da Grid 2.
Quando um Check-in Documental está aguardando liberação, é possível realizar a liberação manualmente. Para isso, basta selecionar o Check-in Documental na Grid 2 e clicar no botão de ação "Análise". Com essa ação, o documento será liberado e estará pronto para seguir para a próxima etapa do processo.

Pesquisar/Filtrar Checkin Documental
Para encontrar uma viagem de navio, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Analisar Checkin Documental
Para analisar um Check-in Documental, é necessário buscar o Check-in desejado na Grid 1, selecionar o resultado e clicar no botão de ação "Analisar" para liberar a análise do documento. Com essa ação, o Check-in Documental será liberado e estará pronto para seguir para a próxima etapa do processo.
Referentes a Grid 3
Upload de Checkin Documental 
Essa função permite o envio de documentos necessários para o processo de check-in documental de um contêiner, tais como notas fiscais, conhecimentos de embarque, entre outros.
Para realizar o upload de um Checkin Documental, acesse a terceira grid e selecione a aba "upload". Em seguida, clique no botão de ação "Upload", selecione o arquivo que deseja anexar e, por fim, clique em "OK" para concluir o upload.
Cancelar Checkin Documental
Essa opção é utilizada para cancelar um check-in documental que já tenha sido realizado. É necessário selecionar o registro desejado na lista de check-ins documentais e clicar no botão de ação "Cancelar".
Para excluir um Checkin Documental, primeiro selecione-o na Grid 2. Em seguida, acesse a Grid 3 e clique no botão de ação "Cancelar". Dessa forma, o Checkin Documental será excluído do sistema. 
Certifique-se de que selecionou o Checkin correto antes de prosseguir com a exclusão.
Carregar dado Documental
Essa funcionalidade permite o carregamento de dados referentes aos documentos enviados no check-in documental, como informações do remetente, destinatário, peso, entre outros.
Para carregar os dados de um Checkin Documental, primeiro selecione-o na Grid 2. Em seguida, acesse a Grid 3 e clique no botão de ação "Carregar dado Documental". Dessa forma, os dados aparecerão como resposta na Grid 3. 
Carregar dado checklist
Nessa opção, é possível carregar dados do checklist de verificação realizado durante o processo de check-in documental. Esses dados podem incluir informações sobre o estado físico do contêiner, a presença de danos ou avarias, entre outros.
Para carregar os dados de um Checkin Documental, primeiro selecione-o na Grid 2. Em seguida, acesse a Grid 3 e clique no botão de ação "Carregar dado Checklis ". Dessa forma, os dados aparecerão como resposta na Grid 3. 
Download Documental
Essa função permite o download dos documentos enviados no processo de check-in documental, como notas fiscais, conhecimentos de embarque, entre outros.
Selecione o arquivo que deseja baixar na Grid 3, em seguida, clique no botão de ação "Download" para iniciar o processo de download.
UpLoad CheckList
Ação que permite o envio e anexo de um arquivo contendo um checklist de verificação de documentos relacionados a um checkin documental.
Carregar dado UpLoad
Ação que permite o carregamento de um arquivo contendo os documentos a serem verificados durante o checkin documental.
Associar Checklist ao UpLoad 
Ação que permite a associação de um checklist de verificação previamente cadastrado ao arquivo UpLoad de documentos. Essa associação auxilia na verificação e validação dos documentos durante o checkin documental.
