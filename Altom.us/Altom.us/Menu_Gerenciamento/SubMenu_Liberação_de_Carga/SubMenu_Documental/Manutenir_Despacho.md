Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis da Grid 2.
Incluir Despacho: é uma opção que permite adicionar um novo registro de despacho no sistema TOS, preenchendo as informações necessárias para o processo de liberação de carga.
Alterar Despacho: é uma opção que permite modificar as informações de um despacho já registrado no sistema TOS. É necessário selecionar o despacho desejado na lista e fazer as alterações necessárias.
Excluir Despacho: é uma opção que permite remover um despacho já registrado no sistema TOS. É necessário selecionar o despacho desejado na lista e confirmar a exclusão.
Processar Despacho: é uma opção que permite executar as ações necessárias para liberar a carga associada a um despacho no sistema TOS, como conferência de documentos, vistorias e inspeções.
Vetar Despacho: é uma opção que permite rejeitar a liberação da carga associada a um despacho, geralmente devido a problemas encontrados durante o processo de análise. O despacho é marcado como vetado e não será processado até que os problemas sejam resolvidos.

Pesquisar/Filtrar Despacho
Para encontrar um despacho, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Extração de dados
Além disso, é possível extrair dados nesta tela. Para obter o relatório de Averbação, clique no botão "EXTRAÇÃO DE DADOS", selecione o formato de download desejado (CSV ou PDF) e aguarde enquanto o arquivo é gerado e baixado.
Cadastrar Despacho
Permite adicionar um novo registro de despacho no sistema TOS, preenchendo as informações necessárias para o processo de liberação de carga.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Redobrigatório 
Documento: Informar o Número do Documento.
RegimeDoc: Informe o regime. Ex: CARGA JÁ DESEMBARAÇADA.
TipoDoc: Informar o tipo de documento. Ex: DECLARAÇÃO ÚNICA DE EXPORTAÇÃO.
ClienteDoc: Buscar o ID co cliente.
ClienteFin: Buscar o ID co cliente.
Despachante: Buscar por despachante responsável. OBS.: O cadastro do Despachante já deve constar no Sistema. 
Terminal: Informar terminal responsável.
Moeda: Buscar tipo de moeda de transito nesse processo. Ex: DOLAR AMERICANO
TipoValor: Selecionar o tipo de valor. Ex: FOB 
Valor: Informar valor. Ex: 10000
Estado: PROPOSTO
Clique em OK e o sistema gravá a o novo despacho no banco.
Os campos em amarelo se preenchem automaticamente conforme preenchimento do formulário.

Processar Despacho
Opção que permite executar as ações necessárias para liberar a carga associada a um despacho no sistema TOS, como conferência de documentos, vistorias e inspeções.
Vetar Despacho
Permite rejeitar a liberação da carga associada a um despacho, geralmente devido a problemas encontrados durante o processo de análise. O despacho é marcado como vetado e não será processado até que os problemas sejam resolvidos.
Abas referentes a Grid 3
Incluir/vincular Grupo Mercadoria
Essa funcionalidade permite ao usuário criar um novo grupo mercadoria no sistema TOS. O grupo mercadoria é utilizado para agrupar diferentes tipos de cargas para fins de planejamento e gestão de operações portuárias.
Para selecionar um documento, acesse a Grid 1 e escolha o arquivo desejado. Em seguida, na aba "Grupo Mercadoria", pesquise pelo grupo correspondente à sua necessidade na Grid 3 e selecione-o. Por fim, clique no botão "Incluir" para adicionar o grupo ao seu documento. Repita o processo para cada mercadoria.
Excluir Grupo Mercadoria
Permite ao usuário excluir um grupo mercadoria existente no sistema TOS. Isso pode ocorrer quando um grupo mercadoria não é mais necessário ou quando foi criado por engano.
Carregar dado Documental
Permite ao usuário carregar documentos relacionados ao despacho no sistema TOS. Isso pode incluir documentos como notas fiscais, certificados de qualidade, laudos, entre outros.
Importar GMs
Importar grupos mercadoria de outros sistemas ou fontes de dados externas para o sistema TOS. Isso pode ser útil quando há uma grande quantidade de grupos mercadoria para serem criados e é mais prático importá-los em vez de criá-los manualmente.
Processo Ação
Para visualizar informações sobre a mercadoria relacionada a um despacho selecionado, siga os passos abaixo:
Acesse a Grid 2 e pesquise pelo despacho desejado.

Selecione-o na lista apresentada.

Role a página para baixo até chegar à Grid 3 e selecione a aba "Processo Ação".

Clique no botão "Carregar Dado Documental" para carregar as informações disponíveis sobre a mercadoria relacionada ao despacho selecionado.

Log
Esses dados são importantes para garantir a rastreabilidade das operações realizadas no terminal, permitindo que sejam identificadas eventuais falhas ou inconsistências no processo de despacho e garantindo a segurança e a eficiência das operações portuárias. Além disso, os dados de log podem ser utilizados para gerar relatórios e estatísticas sobre o desempenho do terminal e para subsidiar a tomada de decisões estratégicas.
