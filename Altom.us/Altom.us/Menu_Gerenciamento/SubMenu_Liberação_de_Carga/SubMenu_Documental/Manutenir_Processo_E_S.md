3 - Campo de resultados
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 2. As informações vem do banco de dados do TOS+.

Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.

Pesquisar/Filtrar Processo E/S
Para encontrar um Processo E/S, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.

Além disso, é possível extrair dados nesta tela. Para obter o relatório de Averbação, clique no botão "EXTRAÇÃO DE DADOS", selecione o formato de download desejado (CSV ou PDF) e aguarde enquanto o arquivo é gerado e baixado.
 
Cadastrar Processo E/S
Essa funcionalidade permite ao usuário cadastrar um novo processo de entrada e saída no sistema TOS. Ao selecionar essa opção, o usuário terá acesso a um formulário ou tela onde poderá preencher informações relevantes para o processo. Após o cadastro, o processo estará disponível para execução e gerenciamento no sistema.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

 
obrigatórioRed 
Clique para expandirRegime: Nesse campo, é necessário selecionar o regime aplicável ao processo de entrada e saída. 
Tipo de Documento: Nesse campo, deve-se selecionar o tipo de documento relacionado ao processo de entrada e saída. 
Número do Documento: Nesse campo, é necessário inserir o número do documento referente ao processo de entrada e saída. Trata-se de um campo para registrar o número único identificador do documento correspondente à operação em questão.
Cliente - Documentação: Esse campo se refere ao cliente relacionado à documentação do processo de entrada e saída. Aqui, é necessário fornecer informações sobre o cliente envolvido na operação.
Cliente - Financeiro: Esse campo se refere ao cliente relacionado aos aspectos financeiros do processo de entrada e saída. 
Terminal: O terminal é o local onde ocorrem as operações de carga, descarga, armazenamento e movimentação das mercadorias.
OpcionalBlue  
Clique para expandirDespachante: O despachante é a pessoa ou empresa responsável pela realização dos trâmites aduaneiros e logísticos relacionados à operação.
Comissária: A comissária é uma empresa especializada que atua como intermediária nos procedimentos aduaneiros e logísticos, auxiliando na regularização e liberação das mercadorias.
Grupo NCM: Nesse campo, é necessário selecionar o grupo NCM (Nomenclatura Comum do Mercosul) relacionado às mercadorias envolvidas no processo de entrada e saída. A NCM é um sistema utilizado para classificar produtos para fins aduaneiros e de estatísticas comerciais.
Tipo de Movimento: Esse campo requer a seleção do tipo de movimento associado ao processo de entrada e saída. 
Cliente (Consolidador): O consolidador é responsável por consolidar diferentes cargas ou mercadorias de diferentes clientes em uma única unidade de transporte.
Moeda: Nesse campo, é necessário selecionar a moeda utilizada nas transações financeiras relacionadas ao processo de entrada e saída. 
Tipo Valor: Esse campo requer a seleção do tipo de valor atribuído ao processo.
Referência: código interno, uma referência comercial ou qualquer outra informação que auxilie na identificação e rastreamento do processo.
Data de Registro:  É a data em que o processo foi cadastrado ou registrado no sistema.
Desembaraço: Indica se o processo já foi desembaraçado, está em andamento ou se ainda não foi iniciado.
Data de desembaraço: É a data em que o processo foi efetivamente desembaraçado, ou seja, quando a liberação das mercadorias foi autorizada pelas autoridades aduaneiras.
Doc. Origem: data ou qualquer outra informação relevante sobre o documento que originou a operação.
Despachante Responsável: É o despachante específico designado para lidar com as formalidades aduaneiras e logísticas relacionadas a esse processo.
Lacre: números dos lacres utilizados para garantir a integridade e segurança das mercadorias durante o transporte e armazenamento.
Alterar Processo E/S
 Ao selecionar essa funcionalidade, o usuário terá acesso à tela de edição do processo, onde poderá fazer modificações nos parâmetros, configurações, descrição ou qualquer outra informação relacionada ao processo. Após efetuar as alterações desejadas, o sistema irá atualizar os dados do processo de acordo com as novas configurações.
Utilize os filtros de busca disponíveis, para encontrar o registro específico que deseja alterar.

Selecione o registro desejado na lista de resultados da busca. 

Na tela de edição, identifique as informações relevantes que deseja alterar, como dados do cliente, valores, referências, entre outros. Preencha os campos correspondentes com as novas informações.

Revise cuidadosamente as alterações feitas para garantir que estejam corretas e de acordo com as necessidades do processo.

Após realizar todas as alterações necessárias, clique no botão "OK" para registrar as informações atualizadas no banco de dados do sistema.

Excluir Processo E/S
Essa funcionalidade possibilita ao usuário remover um processo de entrada e saída existente no sistema TOS+. Ao selecionar essa opção, o usuário será solicitado a confirmar a exclusão do processo selecionado. Uma vez confirmada, o sistema irá remover permanentemente o processo, excluindo todas as informações associadas a ele. 
Utilize os filtros de busca disponíveis, como número do processo, cliente, data de registro, entre outros, para encontrar o registro específico que deseja excluir.

Selecione o registro desejado na lista de resultados da busca. 

Caso esteja seguro de que deseja prosseguir com a exclusão, clique no botão denominado "Excluir".

Processar Processo E/S
Ao selecionar essa funcionalidade, o sistema irá processar as operações e tarefas associadas ao processo, realizando as ações especificadas. O status do processo será atualizado para refletir sua execução em análise ou concluída.
Selecione o processo desejado na grade ou tabela de resultados. Essa grade é frequentemente referida como "Grid 2".

Após selecionar o processo, identifique o botão específico para o processamento. 

Verifique o registro do processo para confirmar se o status foi atualizado corretamente. O status anterior, como "Em análise", deve ser alterado para "Liberado" ou outro status equivalente que indique que o processo foi processado com sucesso.

Incluir/vincular Grupo Mercadoria
Essa funcionalidade permite ao usuário incluir um grupo mercadoria no sistema TOS+. O grupo mercadoria é utilizado para agrupar diferentes tipos de cargas para fins de planejamento e gestão de operações portuárias.
Para selecionar um documento, acesse a Grid 2 e escolha o arquivo desejado. Em seguida, na aba "Grupo Mercadoria", pesquise pelo grupo correspondente à sua necessidade na Grid 3 e selecione-o. Por fim, clique no botão "Incluir" para adicionar o grupo ao seu documento. Repita o processo para cada mercadoria.
