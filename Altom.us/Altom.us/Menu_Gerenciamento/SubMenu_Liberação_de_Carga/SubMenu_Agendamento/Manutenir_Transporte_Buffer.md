Pesquisar/Filtrar um Transporte Buffer
Para encontrar um Transporte Buffer específico, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Carregar Janela Plano
A funcionalidade "Carregar" é utilizada para carregar informações importantes, como o ID do agendamento plano e o início/termino da janela de tempo.
Para utilizar essa funcionalidade, siga os passos abaixo:
Na tela principal, localize a "Grid 2" onde são exibidos os registros de Agendamento Plano.

Selecione o registro específico de Agendamento Plano que deseja carregar. Isso pode ser feito clicando sobre o registro na Grid 2.

Role a tela para baixo até encontrar a "Grid 3", responsável por exibir os detalhes do agendamento plano.

Na "Grid 3", localize o botão de ação identificado como "CARREGAR" e clique nele. Ao clicar nesse botão, as informações relevantes, como o ID do agendamento plano e a janela de tempo (início/termino), serão carregadas e apresentadas na "Grid 3".

Puxada Janela Plano
A funcionalidade "Puxada Janela Plano" permite executar a ação de puxada em um registro específico de janela plano. Para utilizar essa funcionalidade, siga os passos abaixo:
Primeiramente, siga os passos mencionados anteriormente para acessar a tela relevante e localizar o registro desejado de janela plano. Certifique-se de ter selecionado corretamente o registro na "Grid 2".

Após selecionar o registro de janela plano desejado, localize o botão de ação denominado "PUXADA" e clique nele. Essa ação iniciará o processo de puxada para o registro selecionado.

Aguarde até que a ação de puxada seja concluída. O sistema executará as etapas necessárias para realizar a puxada do registro de janela plano.

Copiar transporte buffer 
A funcionalidade "Copiar Transporte Buffer" permite duplicar um registro de transporte buffer. Para realizar essa ação, siga os passos abaixo:
Na "Grid 3" da tela principal, identifique o registro de janela plano que deseja copiar. Selecione esse registro clicando sobre ele na "Grid 3".

Após selecionar o registro de janela plano, localize o botão de ação chamado "COPIAR TRANSPORTE BUFFER" e clique nele. Essa ação irá iniciar o processo de duplicação do registro de transporte buffer.

Será exibida uma caixa de diálogo solicitando o "ID da Janela Destino". Insira o ID da janela para onde deseja copiar o transporte buffer. Essa informação identifica a janela de destino para onde a cópia será realizada.

Clique em "OK" ou em uma opção equivalente para confirmar e salvar as informações. O sistema irá criar uma cópia do transporte buffer com base no registro de janela plano selecionado e associá-lo à janela de destino especificada.

Cadastrar Transporte Buffer
Na tela principal, utilize a função de pesquisa para buscar o Agendamento Plano com base no Agendamento Base. Insira os critérios de pesquisa, como ID do Agendamento Base, e clique em "Buscar".

Após localizar o Agendamento Plano desejado, pesquise a Janela Plano associada a ele. Utilize a função de carregar para buscar a Janela Plano relacionada ao Agendamento Plano. 

Com a Janela Plano identificada, prossiga para cadastrar o Transporte Buffer na grid 4.

Na tela de cadastro do Transporte Buffer, o usuário deverá informar o Motorista responsável pelo transporte. Insira os dados do Motorista nos campos apropriados.

Em seguida, o usuário deve informar o tipo de Transporte a ser realizado. Insira as informações relevantes sobre o Transporte nos campos correspondentes.

Informe também o Número de Eixos do veículo utilizado no transporte. Insira essa informação no campo adequado.

Após preencher todos os dados necessários, clique no botão "OK" para incluir o Transporte Buffer.
