Manutenir Agendamento Modal - A.0144.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 2. As informações vem do banco de dados do TOS+.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis na Grid 2.
Incluir Agendamento Modal: Este item refere-se à funcionalidade que permite adicionar um novo agendamento modal ao sistema. Os usuários podem preencher informações relevantes, como data, horário, local, e detalhes específicos do agendamento.
Alterar Agendamento Modal: Possibilita a modificação de um agendamento modal existente no sistema. Os usuários podem fazer alterações nos detalhes do agendamento, como data, horário, local ou qualquer outra informação relacionada.
Excluir Agendamento Modal: Permite remover um agendamento modal do sistema. Ao selecionar um agendamento específico, os usuários podem excluir permanentemente as informações relacionadas a esse agendamento.
Ativar/Inativar Agendamento Modal: Essa opção permite aos usuários ativar ou desativar um agendamento modal específico. Ao ativar, o agendamento estará visível e funcionando conforme programado. Ao inativar, o agendamento não será mais considerado pelo sistema.
Gerar Agendamento Modal: Permite gerar automaticamente um agendamento modal com base em critérios pré-definidos. Os usuários podem especificar parâmetros, como frequência, data inicial, horário, locais, ou qualquer outro requisito relevante. O sistema, então, gera os agendamentos modais com base nesses critérios, agilizando o processo de criação de agendamentos repetitivos ou recorrentes.
6 - Botões de ação que resultam informações na Grid 3
Cada botão tem uma ação específica, representada nas imagens abaixo.
As ações mudam conforme a aba selecionada.
→ Aba Janela modal
Carregar Janela Modal: é utilizada para exibir uma janela modal específica do sistema. Para utilizar essa opção, o usuário deve selecionar o registro desejado na grid 2, o qual contém as informações a serem carregadas.
Incluir Janela Modal: funcionalidade que permite adicionar uma nova janela modal ao sistema. Os usuários podem preencher informações relacionadas à janela, como título, conteúdo, botões e outros elementos interativos necessários para a interação com o usuário.
Alterar Janela Modal: possibilita a modificação de uma janela modal existente no sistema. Os usuários podem fazer alterações no conteúdo, nos elementos interativos ou em outros aspectos da janela modal para atender às necessidades específicas da manutenção do agendamento modal.
Excluir Janela Modal: permite remover uma janela modal do sistema. Ao selecionar uma janela modal específica, os usuários podem excluí-la permanentemente, removendo-a do conjunto de opções disponíveis para a manutenção do agendamento modal.
Bloquear/Desbloquear Janela Modal: permite aos usuários bloquear ou desbloquear uma janela modal específica. Quando uma janela modal está bloqueada, ela não pode ser modificada ou excluída. Essa funcionalidade é útil para evitar alterações acidentais ou indesejadas em janelas modais importantes.
Realocar Janela: possibilita a realocação de uma janela modal em uma posição diferente na tela ou em uma área específica do sistema. Os usuários podem arrastar e soltar a janela modal em uma nova posição para facilitar a visualização ou melhorar a organização das janelas modais abertas no sistema.
→ Aba Restrição Janela
Carregar Restrição Janela: refere-se à ação de carregar as restrições relacionadas a uma janela modal específica do sistema. Ao selecionar essa opção, o sistema exibirá as restrições configuradas para essa janela modal, como limitações de horário, capacidade máxima de participantes, restrições de equipamentos ou qualquer outra restrição específica que possa estar associada à janela.
Incluir Restrição Janela: funcionalidade que permite adicionar uma nova restrição à janela modal. Os usuários podem definir diferentes tipos de restrições, como restrições de horário, disponibilidade de recursos, restrições de participantes ou qualquer outra restrição personalizada necessária para o agendamento modal. Essa opção permite especificar as condições e limitações para o uso da janela modal.
Alterar Restrição Janela: permite a modificação de uma restrição existente associada a uma janela modal. Os usuários podem fazer alterações nas configurações da restrição, como alterar horários permitidos, ajustar a capacidade máxima de participantes ou atualizar quaisquer outros parâmetros relacionados à restrição.
Excluir Restrição Janela: possibilita a remoção de uma restrição associada a uma janela modal. Ao selecionar uma restrição específica, os usuários podem excluí-la permanentemente do sistema. Isso permite remover limitações ou condições que não sejam mais necessárias ou precisem ser modificadas no agendamento modal.

Pesquisar/Filtrar um Agendamento Modal
Para encontrar um Agendamento especifico, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Cadastrar Agendamento Modal
Este item refere-se à funcionalidade que permite adicionar um novo agendamento modal ao sistema. Os usuários podem preencher informações relevantes, como data, horário, local, e detalhes específicos do agendamento.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Redobrigatório 
Agendamento Base: Busaque o agendamento base pela sigla. Ex.: IMP
Trasnporte Movimento: Busque o navio responsavel pelo tranaporte. Ex.: CUMBIA 3
Operador Modal: Terminal responsavel pela operação.
Clique em OK para finalizar a ação e salvar as informações no banco. 
Alterar Agendamento Modal
Possibilita a modificação de um agendamento modal existente no sistema. Os usuários podem fazer alterações nos detalhes do agendamento, como data, horário, local ou qualquer outra informação relacionada.
Selecione o registro de agendamento que deseja modificar.

Clique no botão de ação "Alterar".

Faça as alterações necessárias nas informações pertinentes.

Clique em "OK" para salvar as alterações.

Excluir Agendamento Modal
Permite remover um agendamento modal do sistema. Ao selecionar um agendamento específico, os usuários podem excluir permanentemente as informações relacionadas a esse agendamento.
Selecione o registro de agendamento que deseja remover.

Clique no botão de ação "Excluir".

Uma mensagem de confirmação será exibida, solicitando a confirmação da ação de exclusão.

Confirme a exclusão clicando em "OK".

Ativar/Inativar Agendamento Modal
Essa opção permite aos usuários ativar ou desativar um agendamento modal específico. Ao ativar, o agendamento estará visível e funcionando conforme programado. Ao inativar, o agendamento não será mais considerado pelo sistema.
Selecione o registro de agendamento desejado.

Clique no botão de ação "Ativar/Inativar".

Ao clicar no botão, o sistema realizará a ação de ativação ou desativação do agendamento, conforme a configuração atual.

O estado do agendamento será atualizado de acordo com a ação realizada. Por exemplo, se o agendamento estiver ativado, ele será desativado, e vice-versa.

Verifique o status atualizado do agendamento para confirmar que a ação foi concluída com sucesso.
Gerar Agendamento Modal
Permite gerar automaticamente um agendamento modal com base em critérios pré-definidos. Os usuários podem especificar parâmetros, como frequência, data inicial, horário, locais, ou qualquer outro requisito relevante. O sistema, então, gera os agendamentos modais com base nesses critérios, agilizando o processo de criação de agendamentos repetitivos ou recorrentes.
Selecione um registro de agendamento existente.

Clique no botão de ação "Gerar Agendamento Modal".

Ao clicar no botão, será exibido um formulário no qual você deverá preencher as seguintes informações:
Transporte Movimento: Preencha com os detalhes relacionados ao tipo de transporte ou movimento necessário para o agendamento.
Agendamento Base: Insira as informações referentes ao agendamento base.
QTD Puxada Inicial: Informe a quantidade inicial a ser puxada para o agendamento modal.
QTD Bloqueio Puxado: Indique a quantidade de bloqueio a ser aplicada ao puxar o agendamento.
Carregar Janela Modal
É utilizada para exibir uma janela modal específica do sistema. 
Para carregar os dados de uma janela modal, é necessário primeiro selecionar um registro de agendamento na Grid 2. Essa seleção permitirá que as informações relacionadas a esse agendamento sejam carregadas na janela modal correspondente.
Cadastrar Janela Modal
Funcionalidade que permite adicionar uma nova janela modal ao sistema. Os usuários podem preencher informações relacionadas à janela, como título, conteúdo, botões e outros elementos interativos necessários para a interação com o usuário.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 3 Aba Janela Modal (+).

Selecione um registro de agendamento na Grid 2.

Role a tela até a Grid 3.

Clique no botão de ação "Incluir" para adicionar o novo registro de agendamento.

Ao adicionar o novo registro, você precisará preencher as seguintes informações na tela de inclusão:
RedObrigatório 
Operação janela: Insira a operação relacionada a esse agendamento de janela.
Tipo: Selecione o tipo correspondente ao agendamento de janela desejado.
QTD: Preencha a quantidade relacionada a esse agendamento de janela.
QTD Puxada Inicial: Informe a quantidade inicial a ser puxada para esse agendamento de janela.
QTD bloquei Puxada: Indique a quantidade bloqueada a ser puxada para esse agendamento de janela.
Alterar Janela Modal
Possibilita a modificação de uma janela modal existente no sistema. Os usuários podem fazer alterações no conteúdo, nos elementos interativos ou em outros aspectos da janela modal para atender às necessidades específicas da manutenção do agendamento modal.
Selecione o registro de agendamento que deseja alterar e em seguida quique no botaõ de ação altera para altera as informações pertinetes. 
Excluir Janela Modal
Permite remover uma janela modal do sistema. Ao selecionar uma janela modal específica, os usuários podem excluí-la permanentemente, removendo-a do conjunto de opções disponíveis para a manutenção do agendamento modal.
Selecione a Janela Modal que deseja excluir.

Clique no botão de ação "Excluir".

Uma mensagem de confirmação será exibida.

Clique no botão "OK" para confirmar a exclusão.

Bloquear/Desbloquear Janela Modal
Permite aos usuários bloquear ou desbloquear uma janela modal específica. Quando uma janela modal está bloqueada, ela não pode ser modificada ou excluída. Essa funcionalidade é útil para evitar alterações acidentais ou indesejadas em janelas modais importantes.
Selecione o registro da Janela Modal que você deseja bloquear ou desbloquear.

Clique no botão de ação "Bloquear/Desbloquear" para concluir a ação.

Ao clicar no botão, o sistema realizará o bloqueio ou desbloqueio do registro da Janela Modal, dependendo do seu estado atual. Certifique-se de selecionar corretamente o registro desejado antes de prosseguir com a ação. O estado da Janela Modal será atualizado de acordo com a ação realizada.
Realocar Janela

Os usuários podem definir diferentes tipos de restrições, como restrições de horário, disponibilidade de recursos, restrições de participantes ou qualquer outra restrição personalizada necessária para o agendamento modal. Essa opção permite especificar as condições e limitações para o uso da janela modal.

Transportadora: Realize uma busca pela transportadora responsável.
Grupo Terminal: Realize uma busca pelo grupo terminal.
QTD: Informe a quantidade de restrições de janelas desejada.
BlueOpcional
