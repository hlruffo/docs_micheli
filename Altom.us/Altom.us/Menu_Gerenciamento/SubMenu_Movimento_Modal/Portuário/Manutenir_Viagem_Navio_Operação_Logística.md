Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima. 
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+. 
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro. 
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela. 
5 - Botões de ação
Refentes as ações possíveis da Grid 2. 
Incluir: permite cadastrar uma nova viagem de navio na operação logística. Essa opção permite preencher os dados necessários para a criação da nova viagem, como nome do navio, porto de origem e destino, data de saída e chegada, entre outras informações relevantes.
Alterar viagem de navio: essa opção permite alterar dados pré-cadastrados na tela, como os dados da viagem, o nome do navio, o porto de origem e destino, a data de saída e chegada, entre outras informações relevantes.
Aplicar Estiva: essa opção é utilizada para definir como as cargas serão acomodadas no navio. Ela permite criar um plano de estiva que informa como as cargas devem ser acomodadas no navio, garantindo que todas as cargas sejam transportadas de forma segura e eficiente.
Limpar Navio Movimento: essa opção permite limpar todos os dados da tela e recomeçar o preenchimento dos dados de uma nova viagem.
Cancelar: essa opção permite cancelar uma viagem de navio já cadastrada. É importante lembrar que essa ação pode ter impactos na operação logística, como atrasos e prejuízos financeiros, por isso deve ser realizada com cuidado e avaliando todas as consequências.

Pesquisar/Filtrar uma Viagem Navio
Para encontrar uma viagem de navio, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Cadastrar uma Viagem Navio 
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Clique em OK e o sistema gravá a nova viagem no banco.
RedCampos obrigatórios 
Terminal: buscar por terminal correspondente a Viagem Navio. 
Linha de serviço: Selecionar entre as opções existentes a que corresponde a esta viagem. 
Armador(carrier): Buscar armador correspondente. Ex: HAPAG - LLOYD CONTAINER LINE -HLC
Navio: Buscar por navio correspondente a Viagem.
Porto Origem: Pesquisar por sigla do porto existente no sistema. Ex: USNYC.
Porto anterior: Pesquisar por sigla do porto anterior. Ex: BRSSZ.
Porto de destino: Ex: BRRIO
Data da abertura do Gate: dd/mm/yyyy hh:mm
Deadline Gate: dd/mm/yyyy hh:mm
Deadline Documental: dd/mm/yyyy hh:mm
BlueCampos opcionais 
Modalidade: Selecionar modalidade (LONGO CURSO, MERCOSUL e CABOTAGEM). Ex: Longo Curso
ETA: dd/mm/yyyy hh:mm
ETD: dd/mm/yyyy hh:mm
Número Viagem Importação: Ex: 999N
Número Viagem Exportação: Ex: 999S
Alterar dados de uma Viagem
Na Grid 2, após localizar e selecionar a Viagem que deseja alterar, clique no botão 'Alterar' e faça as alterações nas informações desejadas.
Excluir Viagem Pré-existente
Para excluir uma viagem, selecione-o e clique no botão 'Excluir'.
Aplicar estiva
Utilizada para definir como as cargas serão acomodadas no navio. Ela permite criar um plano de estiva que informa como as cargas devem ser acomodadas no navio, garantindo que todas as cargas sejam transportadas de forma segura e eficiente.
Limpar Navio Movimento
Após selecionar a viagem navio que deseja limpar, clique no botão de ação Limpar Navio movimento para concluir a ação. 
Cancelar uma Viagem Navio
Selecione a viagem Navio que deseja cancelar e clique no botão de ação cancelar para completar a ação. 
Carregar dados de uma Viagem
Após selecionar a Viagem que deseja carregar (Grid 2) na Aba VIAGEM x CARRIER (Grid 3), clique no botão de ação ‘carregar dados de uma vigem' e executar a ação desejada para a informação carregada.
Incluir Viagem x Carrier
Selecione uma viagem na qual deseja incluir Carrier e Clique no botão 'Incluir' presente na Grid 3.  
Alterar Viagem x Carrier
Selecione uma viagem na qual deseja Alterar Carrier e Clique no botão 'Alterar' presente na Grid 3. 
Excluir Viagem x Carrier
Selecione uma viagem na qual deseja Excluir Carrier e Clique no botão 'Excluir presente na Grid 3.  
Carregar Propriedades
Selecione uma Operação Navio e clique no botão de ação 'carregar' para carregar as propriedades da Viagem. 
Incluir Propriedades
Selecione uma Operação Navio e clique no botão de ação 'Incluir' para Incluir propriedades da Viagem. 
Excluir Propriedades 
Selecione uma Operação Navio e clique no botão de ação 'Excluir' para carregar as propriedades da Viagem.
