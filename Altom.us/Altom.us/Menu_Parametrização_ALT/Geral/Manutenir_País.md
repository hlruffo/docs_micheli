Pesquisar/Filtrar um País
Para encontrar um País especifico, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Cadastrar País
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

ObrigatórioRed 
Nome: Insira o nome oficial do país que está sendo cadastrado. Ex.: Canada
Continente: Indique a região geográfica à qual o país pertence. Ex.: América do Norte
ISO 2: Utilize o código ISO de duas letras para identificar o país. No caso do Canadá, seu código ISO 2 é "CA".
ISO 3: O código ISO de três letras é outra forma de identificar o país. Para o Canadá, o código ISO 3 é "CAN".
opcionalBlue  
 Moeda: Informe a moeda oficial do país. Ex.: Dólar Canadense.
Alterar País 
Utilize o recurso de filtro para localizar o registro do país que deseja alterar.

Após a pesquisa, os resultados devem aparecer no campo de resultados(Campo 2).

Escolha o país específico que você deseja alterar dentro dos resultados. Basta clicar no registro desejado.

Clique no botão de ação "Alterar" para iniciar o processo de alteração do registro.

O formulário de alteração será aberto, semelhante ao formulário de cadastro. Aqui, você pode modificar as informações desejadas.

Faça as alterações necessárias no formulário para atualizar as informações do país conforme desejado.

Após concluir as alterações, clique no botão "OK".

Excluir País
Para excluir um registro específico de um País siga os passos abaixo:
Use o recurso de filtro para encontrar o registro do país que você deseja excluir.

Após a pesquisa, os resultados devem ser exibidos, incluindo o país que você deseja remover.

Escolha o país específico que você deseja excluir dentro dos resultados.

Clique no botão de ação "Excluir" e o registro será apagado do sistema.

Carregar dados por um Fluxo
Utilize o recurso de filtro para encontrar o registro do país do qual deseja carregar os dados.

Após a pesquisa, os resultados devem ser exibidos no campo de resultados 2 (País). Identifique e clique sobre o registro desejado.

Mova-se para o campo 3(UF) associadas ao país selecionado.

Clique no botão de ação "Carregar dados por um Fluxo".

Os dados, como nome, sigla e código UF, serão automaticamente carregados e exibidos na própria grid 3. Isso acontecerá se houver registros associados a esse país.

Cadastrar UF
Na grid 2 (País), localize o registro do país ao qual deseja associar a Unidade Federativa (UF). Clique sobre o registro do país desejado.

Desça a tela até a grid 3, associadas ao país selecionado e clique no botão de ação "Incluir". 

Um formulário de cadastro será aberto para a inclusão da nova Unidade Federativa. Preencha as informações necessárias conforme indicado abaixo:

Os exemplos abaixo foram definidos para o país Canadá. 
Nome: Ex.: Ontário
Sigla: Ex.: ON
Código UF: Ex.:  35
Clique em OK para salvar as informações.
Alterar UF
Vá para a grid 3, que exibe as Unidades Federativas (UF), e escolha o registro específico que deseja alterar.

Clique no botão de ação "Alterar", na grid 3. 

O formulário de alteração será aberto, faça as alterações desejadas no formulário, como nome, sigla, código UF e outras informações, conforme necessário.

Após concluir as alterações, clique no botão "OK" para salvar as informações atualizadas.

noteLembre-se de que é necessário ter registros na grid 3 para realizar alterações. Caso não haja registros, é preciso executar primeiro o procedimento "Carregar dados por um Fluxo" conforme descrito no manual.

Excluir UF
Acesse a grid 3, que exibe as Unidades Federativas (UF), e escolha o registro específico que deseja excluir.

Clique no botão de ação "Excluir" na grid 3 e o registro será excluído.

noteLembre-se de que a exclusão de registros é uma ação irreversível, então é importante ter certeza antes de confirmar a remoção. Certifique-se também de ter registros na grid 3 para realizar a exclusão. Caso não haja registros, execute primeiro o procedimento "Carregar dados por um Fluxo" conforme descrito no manual.
