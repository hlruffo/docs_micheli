Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis na Grid 2.
Incluir faixa de peso: permite a adição de uma nova faixa de peso ao Sistema TOS+. Ao selecionar essa opção, você poderá fornecer as informações necessárias, como valor mínimo e máximo da faixa de peso, para criar uma nova entrada na lista de faixas de peso do sistema.
Alterar faixa de peso: ao selecionar essa opção, você poderá acessar as informações da faixa de peso selecionada e fazer as modificações necessárias, como ajustar os valores mínimos e máximos da faixa de peso.
Excluir faixa de peso: ao selecionar essa opção, você poderá excluir uma faixa de peso específica do Sistema TOS. Antes de confirmar a exclusão, certifique-se de que não há dependências ou uso ativo dessa faixa de peso. Essa ação removerá permanentemente a faixa de peso selecionada do sistema.
Inativar faixa de peso: é possível desativar temporariamente uma faixa de peso no Sistema TOS, sem excluí-la permanentemente. Ao selecionar essa opção, a faixa de peso selecionada será marcada como inativa e não estará mais disponível para uso.
5 - Botões de ação
Refentes as ações possíveis na Grid 3 (Classe de Faixa de Peso).
Carregar dados de uma Classe de faixa de peso associada ao registro selecionado na grid 2. 

Adicionar uma nova Classe de faixa de peso

Alterar uma classe pré-existentes no sistema. 

Excluir uma classe pré-existentes no sistema.

Alterar faixa de peso
Ao selecionar essa opção, você poderá acessar as informações da faixa de peso selecionada e fazer as modificações necessárias, como ajustar os valores mínimos e máximos da faixa de peso.
Para realizar a alteração do registro de faixa de peso desejado, siga os passos abaixo:
Selecione a faixa de peso que deseja modificar.

Um popup será aberto, exibindo os campos de alteração.

Faça as alterações desejadas nas informações.

Clique em OK para salvar as informações atualizadas no banco de dados.

Excluir faixa de peso
Selecionando essa opção, você poderá excluir uma faixa de peso específica do Sistema TOS. Antes de confirmar a exclusão, certifique-se de que não há dependências ou uso ativo dessa faixa de peso. Essa ação removerá permanentemente a faixa de peso selecionada do sistema.
Selecione a faixa de peso que deseja excluir.

Um popup será aberto, exibindo os detalhes do registro selecionado.

Confirme a exclusão ao clicar no botão "Excluir" ou uma opção similar.

Uma mensagem de confirmação será exibida para garantir que você deseja prosseguir com a exclusão.

Clique em OK ou em uma opção semelhante para confirmar a exclusão.

Após a confirmação, o registro de faixa de peso selecionado será removido do banco de dados.

Carregar dados de uma Classe de faixa de peso
Para visualizar as informações da classe de faixa de peso, siga as etapas abaixo:
Na grade 2, selecione o registro de faixa de peso desejado.

Role a tela para a grade 3.

Localize o botão 'Carregar'.

Clique no botão de ação 'Carregar'.

As informações da classe de faixa de peso serão exibidas na grade 3, organizadas em suas colunas correspondentes.

Para adicionar uma Classe de Faixa de Peso, siga as etapas abaixo:
