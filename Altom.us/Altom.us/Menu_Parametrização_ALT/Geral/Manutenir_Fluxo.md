Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis na Grid 2.

Pesquisar/Filtrar um Fluxo
Para buscar um Fluxo específico na tela de filtro, basta selecionar entre os modais disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe o campo em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Carregar dado de um Fluxo Grupo
Para carregar os dados de um fluxo, siga os passos abaixo:
Antes de tudo, é necessário selecionar o registro do fluxo grupo do qual deseja visualizar outras informações. Para isso, localize o registro desejado na "Grid 3" e selecione-o clicando sobre ele.

Após selecionar o registro de fluxo grupo, role a tela para cima até a seção relevante e localize o botão de ação denominado "CARREGAR". Clique nesse botão para iniciar o processo de carregamento dos dados adicionais do fluxo.

Cadastrar Fluxo
Para fazer o cadastro de um novo fluxo, siga os passos abaixo:
Utilizando a ferramenta de filtro, busque o registro de fluxo que deseja cadastrar.

Na "Grid 2", selecione o registro de fluxo desejado clicando sobre ele. Certifique-se de escolher o registro correto para o cadastro.

Acesse a "Grid 3" e utilize o botão de ação "CARREGAR" presente nessa grade. Essa ação permitirá carregar as informações do fluxo Grupo relacionado ao registro selecionado.

Na "Grid 3", verifique os resultados carregados e identifique o resultado desejado do fluxo Grupo. Analise cuidadosamente as informações antes de prosseguir.

Volte para a "Grid 2" e clique no botão de ação "INCLUIR". Esse botão permitirá iniciar o processo de inclusão do novo fluxo.

Preencha as informações necessárias para o cadastro do fluxo.

Clique em "OK" para finalizar o cadastro do novo fluxo. O sistema processará as informações e realizará o registro do fluxo de acordo com os dados fornecidos.

Formulário de cadastro
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed 
Nome: Nomeei o Fluxo. Ex.: P4CA742
Código: Forneça o código de cadastro. Ex.: A7
Status: Selecione o status como ativo ou inativo.
Direção: Unidirecional ou Bidirecional
Carga: Selecione o tipo de carga. Contêiner, Granel, ou Carga.
Cor: Escolha a cor que representa esse fluxo.
opcionalBlue

Dispositivo (Saída): Busque pelo dispositivo. 
Entrada/Saída: Informe se o fluxo é de entrada ou saída.
Alteara Fluxo
Utilize a função de busca para localizar o registro de fluxo que deseja alterar. 

Na "Grid", identifique e selecione o registro de fluxo desejado. Clique sobre ele para destacá-lo.

Em seguida, localize o botão de ação "ALTERAR" e clique nele. Isso abrirá uma janela pop-up para o preenchimento das informações a serem alteradas.

Clique em "OK"para confirmar as alterações e salvá-las no registro de fluxo.

Excluir Fluxo
Para excluir um fluxo, siga os passos abaixo:
Utilize a função de busca para localizar o registro de fluxo que deseja excluir. Insira os critérios de pesquisa adequados e clique em "Buscar".

Na "Grid", identifique e selecione o registro de fluxo desejado. Clique sobre ele para destacá-lo.

Em seguida, localize o botão de ação "EXCLUIR" e clique nele. Essa ação abrirá uma janela de confirmação para confirmar a exclusão do fluxo.

Na janela de confirmação, verifique se o registro de fluxo a ser excluído está correto. Leia atentamente as informações apresentadas para garantir que você está excluindo o fluxo desejado.

Clique em "OK" para confirmar a exclusão do fluxo. O sistema processará a solicitação e removerá o registro de fluxo da base de dados.

Carregar dados por um fluxo
Para carregar dados de um Fluxo, siga os passos abaixo:
Primeiro, localize o registro do Fluxo no qual deseja carregar os dados. Utilize a opção de pesquisa ou filtro na grid 1 para encontrar o Fluxo desejado.

Na grid 2, selecione o Fluxo desejado clicando sobre ele. Certifique-se de escolher o registro correto para carregar as informações.

Em seguida, navegue até a grid 3, que contém as informações detalhadas do Fluxo. Utilize o botão de ação "CARREGAR" para iniciar o processo de carregamento dessas informações.

Ao clicar no botão "CARREGAR", o sistema irá processar a solicitação e exibir as informações detalhadas do Fluxo na grid 3.

Pesquisar Fluxo Grupo
Insira o nome do Fluxo Grupo que deseja encontrar no campo de pesquisa apropriado.

Após inserir o nome do Fluxo Grupo, clique no botão de ação "PESQUISAR".

Para pesquisar todos os registros existentes na tela do Fluxo Grupo, siga os passos abaixo:
Deixe o campo de busca em branco, sem inserir nenhum valor.

Em seguida, clique apenas no botão de pesquisa, sem preencher nenhuma informação no campo de busca.

Cadastrar Fluxo Grupo
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed  
Área: Informe a área relacionada ao Fluxo Grupo.
Nome: informe o nome do Fluxo Grupo. Ex.: GATE IN
Código: Informe o código que corresponde a este fluxo. Ex.: GO.
Modal: Selecione o modal referente a este Fluxo Grupo
Clique em OK para salvar as informações no banco.
    
Alterar Fluxo Grupo
Na Grid 3, selecione o registro no qual deseja realizar a alteração. Clique sobre ele para destacá-lo.

Localize o botão de ação "ALTERAR" e clique nele. Isso permitirá acessar a tela de edição para fazer as alterações necessárias.

Na tela de edição, altere as informações relevantes de acordo com suas necessidades. Certifique-se de inserir os novos valores corretamente nos campos apropriados.

Após fazer as alterações desejadas, clique em "OK" para confirmar as modificações e salvar as informações atualizadas.

Excluir Fluxo Grupo
Para excluir um registro de Fluxo Grupo, siga os passos abaixo:
Na Grid 3, selecione o registro que deseja excluir. Clique sobre ele para destacá-lo.

Localize o botão de ação "EXCLUIR" e clique nele. Isso abrirá uma janela de confirmação para confirmar a exclusão do Fluxo Grupo.

Na janela de confirmação, verifique se o registro de Fluxo Grupo a ser excluído está correto. Leia atentamente as informações apresentadas para garantir que você está excluindo o Fluxo Grupo desejado.

Clique em "OK" para confirmar a exclusão do Fluxo Grupo. O sistema processará a solicitação e removerá o registro de Fluxo Grupo da base de dados.
