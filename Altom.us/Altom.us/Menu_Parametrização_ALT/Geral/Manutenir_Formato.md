Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis na Grid 2.
Incluir um novo Formato Tipo;

Alterar Formato Tipo pre-existente no sistema;

Excluir Formato Tipo pre-existente no sistema.

6 - Botões de ação
Refentes as ações possíveis na Grid 2.
Incluir um novo Formato;

Excluir Formato pre-existente no sistema;

Carregar dado formato tipo de um registro(Tipo) selecionado na grid 2.

Pesquisar/Filtrar um Formato
Para buscar um Formato específico na tela de filtro, basta selecionar entre os modais disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe o campo em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Formato Tipo
Para inseri um novo registro de Formato Tipo basta clicar no botão de ação incluir. Preencher as informações que se pedem no formulário de cadastro e clicar no botão de ação OK para salvar. 
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

OBRIGATÓRIORed
Classe: Selecione a classe de cadastro. Contêiner, Carga ou Granel.
Nome: Nomeei o Formato de acordo com sua classe. 
Código: Insira o código correspondente a classe de cadastro. 
Clique em OK para salvar as informações do novo Formato no sistema.
Alterar Formato Tipo
Para realizar uma alteração em um Formato, siga os passos abaixo:
Utilize a ferramenta de filtro para buscar o registro específico que deseja alterar. Isso ajudará a localizar rapidamente o Formato desejado.

Após identificar o registro que deseja modificar, selecione-o clicando sobre ele.

Localize e clique no botão de ação denominado "ALTERAR". Essa opção permitirá que você faça as alterações necessárias no Formato selecionado.

Na tela de edição, faça as modificações desejadas no Formato.

Após realizar as alterações, certifique-se de salvar as informações no banco de dados para as mudanças serem efetivadas clicando no botão OK.

Excluir Formato Tipo
Utilize a ferramenta de filtro para localizar o registro específico do Formato que deseja excluir. Isso ajudará a identificar rapidamente o Registro desejado.

Após encontrar o registro do formato que deseja excluir, selecione-o clicando sobre ele.

Procure pelo botão de ação denominado "Excluir".

Antes de confirmar a exclusão, é importante revisar cuidadosamente as informações e garantir que está selecionando o formato correto para excluir. Verifique se não há dependências ou implicações significativas na exclusão desse formato.

Caso esteja certo de que deseja prosseguir com a exclusão, confirme a ação clicando no botão OK.

Cadastrar Formato
Para associar um novo Formato que será cadastrado, siga as etapas abaixo:
Na grid 2, utilize a funcionalidade de busca para localizar o registro específico que deseja associar a esse novo Formato. Isso ajudará a encontrar rapidamente o registro desejado.

Uma vez que tenha encontrado o registro desejado, selecione-o na grid 2, clicando sobre ele.

Role a tela para baixo, até chegar à grid 3.

Na grid 3, clique no botão de ação "Incluir" (+). Essa opção permite adicionar uma nova associação ou vínculo entre o registro selecionado na grid 2 e o novo Formato que será cadastrado.

Preencha o formulário abaixo e salve as informações no banco.

Excluir Formato
Utilize a ferramenta de filtro para localizar o registro específico do Formato que deseja excluir. Isso ajudará a identificar rapidamente o Registro desejado.

Após encontrar o registro do formato que deseja excluir, selecione-o clicando sobre ele.

Procure pelo botão de ação denominado "Excluir".

Antes de confirmar a exclusão, é importante revisar cuidadosamente as informações e garantir que está selecionando o formato correto para excluir. Verifique se não há dependências ou implicações significativas na exclusão desse formato.

Caso esteja certo de que deseja prosseguir com a exclusão, confirme a ação clicando no botão OK.

Carregar dado Formato
Na grid 2, localize e selecione o Tipo Formato desejado no qual você deseja carregar os dados. Você pode fazer isso clicando sobre o Tipo Formato na grid 2.

Role a tela para baixo até chegar à grid 3.

Na grid 3, clique no botão de ação denominado "CARREGAR DADO FORMATO". Essa opção permitirá que os dados correspondentes ao Tipo Formato selecionado sejam carregados na grid 3.
