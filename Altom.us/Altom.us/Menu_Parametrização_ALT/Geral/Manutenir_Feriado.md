Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vêm do banco de dados do TOS+.
3 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
4 - Botões de ação
Refentes as ações possíveis na Grid 2.

Pesquisar/Filtrar um Feriado
Para encontrar um Feriado específico, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão “PESQUISAR” para obter todas as informações pré-existentes na tela.
Cadastrar Feriado
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

RedObrigatório 
Nome: Insira o nome do feriado que esta cadastrando. 
Dia: Informe ao sistema a data desse feriado.
Clique no botão OK para salvar as informações no sistema.
Alterar Feriado 
Para modificar um feriado:
Utilize a ferramenta de filtro para localizar o feriado que deseja alterar na lista.

Selecione o feriado correspondente que será exibido na Grade 2.

Clique no botão “Alterar” para acessar a opção de edição.

Faça as alterações necessárias nas informações do feriado.

Após as modificações, clique em “Ok” para confirmar as alterações e atualizar o registro.
Excluir Feriado
Para excluir um feriado:
Utilize a ferramenta de filtro para localizar o feriado que deseja excluir na lista.

Selecione o feriado correspondente que será exibido na Grade 2.

Clique no botão “Excluir” para acessar a opção de exclusão.

Confirme e o feriado selecionado será removido do sistema.
