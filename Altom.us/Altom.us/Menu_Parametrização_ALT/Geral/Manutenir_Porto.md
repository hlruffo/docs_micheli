Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
4 - Botões de ação
Refentes as ações possíveis da Grid 2.
Incluir Porto: essa funcionalidade permite a criação de um novo registro de porto no sistema TOS. O usuário deve preencher as informações necessárias do novo porto, como nome, código, país, etc., e salvá-las no sistema.
Alterar Porto: essa funcionalidade permite a edição de um registro de porto existente no sistema TOS. O usuário pode atualizar as informações do porto, como nome, código, país, etc., e salvar as alterações.
Excluir Porto: essa funcionalidade permite a exclusão de um registro de porto existente no sistema TOS. O usuário deve selecionar o porto que deseja excluir e confirmar a ação de exclusão. Essa ação é irreversível e deve ser realizada com cautela.

Pesquisar/Filtrar um Porto
Para buscar um Porto específico na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Porto
essa funcionalidade permite a criação de um novo registro de porto no sistema TOS. O usuário deve preencher as informações necessárias do novo porto, como nome, código, país, etc., e salvá-las no sistema.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

ObrigatórioRed 
Nome: Informe o nome do Porto;
Sigla: Informe a sigla do Porto;
opcionalBlue 
País: Busque o país correspondente ao porto
Cor: Selecione a cor padrão para este porto. 
Alterar Porto: 
Essa funcionalidade permite a edição de um registro de porto existente no sistema TOS. O usuário pode atualizar as informações do porto, como nome, código, país, etc., e salvar as alterações.
Selecione o porto no qual deseja fazer a alteração e mude as informações.
Excluir Porto
Essa funcionalidade permite a exclusão de um registro de porto existente no sistema TOS. O usuário deve selecionar o porto que deseja excluir e confirmar a ação de exclusão. Essa ação é irreversível e deve ser realizada com cautela.
