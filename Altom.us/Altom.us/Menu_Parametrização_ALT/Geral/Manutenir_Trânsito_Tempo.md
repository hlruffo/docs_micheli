1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
4 - Botões de ação
Refentes as ações possíveis na Grid 2.

Pesquisar/Filtrar registro de Trânsito Tempo
Para encontrar um registro de Trânsito Tempo específico, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão “PESQUISAR” para obter todas as informações pré-existentes na tela.
Cadastrar Trânsito Tempo
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

RedObrigatório 
Tipo: selecione o tipo de trânsito 
Tempo: converta o tempo estimado em minutos.
Terminal: Informe os terminais de partida(0) e destino(1).
Areá: Informe as áreas de partida(0) e destino(1).
Clique no botão OK para salvar as informações no sistema.
Alterar Trânsito Tempo
Para modificar um registro de trânsito tempo:
Utilize a ferramenta de filtro para localizar o registro que deseja alterar.

Selecione o registro correspondente na Grade 2.

Clique no botão “Alterar” para acessar a opção de edição.

Faça as alterações necessárias nas informações do registro.

Após as modificações, clique em “Ok” para salvar e confirmar as alterações no registro.

Excluir Transito Tempo
Para excluir um registro de trânsito tempo:
Utilize a ferramenta de filtro para localizar o registro que deseja excluir.

Selecione o registro correspondente na Grade 2.

Clique no botão “Excluir” para acessar a opção de exclusão.

Confirme a exclusão, geralmente por meio de um pop-up de confirmação.

O registro selecionado será removido do sistema. Certifique-se de salvar qualquer alteração se necessário após a exclusão. Clique em “Ok” para confirmar a exclusão.
