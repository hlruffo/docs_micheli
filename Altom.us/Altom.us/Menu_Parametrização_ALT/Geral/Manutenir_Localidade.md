Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.

Pesquisar/Filtrar uma Localidade
Para encontrar uma Localidade especifico, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.

Alterar Localidade
Para efetuar a alteração de uma localidade, siga os passos abaixo:
Utilize o campo de filtro na grid para buscar o registro específico da localidade que deseja alterar.

Após localizar o registro desejado, selecione-o clicando sobre ele.

Utilize o botão de ação "Alterar" . Isso abrirá um formulário para realizar as modificações necessárias.

No formulário de alteração, modifique as informações desejadas.

Após realizar as alterações desejadas, clique em "OK" para salvar as modificações.

Excluir Localidade 
Para excluir uma localidade, siga os passos abaixo:
Utilize o campo de filtro na grid para buscar o registro específico da localidade que deseja excluir.

Após localizar o registro desejado, selecione-o clicando sobre ele.

Utilize o botão de ação "Excluir" para finalizar a ação.
