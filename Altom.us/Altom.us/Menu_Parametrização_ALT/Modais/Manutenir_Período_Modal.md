Manutenir Período Modal - A.0038.00
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 2. As informações vêm do banco de dados do TOS+.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis na Grid 2.

Pesquisar/Filtrar um Período Modal
Para encontrar um Período Modal específico, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão “PESQUISAR” para obter todas as informações pré-existentes na tela.

Excluir Período Modal
Essa função permite excluir um registro de Período Modal existente do sistema.
Utilize a função de filtro para buscar o Período Modal que deseja excluir. 

Analise os resultados da pesquisa e identifique o Período Modal desejado na lista exibida. Selecione o registro correspondente clicando sobre ele.
