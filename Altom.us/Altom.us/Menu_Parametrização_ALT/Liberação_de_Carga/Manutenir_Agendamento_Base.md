Pesquisar/Filtrar um Agendamento Base
Para encontrar um Agendamento base específico, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Cadastrar Agendamento Base
Essa função permite cadastrar um novo agendamento base no sistema.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

ObrigatórioRed 
Código: com um identificador único para o agendamento base. 
Área: busque em que o agendamento será realizado. 
Tipo Movimento: correspondente à operação que será agendada. 
Tipo de Documento: associado ao agendamento.
Entrada/Saída: Indique se o agendamento se refere a uma entrada ou saída de cargas no terminal.
OpcionalBlue 
Agendamento Dia: Busque o Agendamento dia.
Cliente: envolvido no agendamento. Busque pelo CNPJ.
Descrição: Adicione informações relevantes sobre a operação, como detalhes da carga, instruções especiais, entre outros.
Modalidade: adequada ao agendamento. 
Alterar Agendamento Base
Essa função permite realizar alterações em um agendamento base existente.
Na tela de Agendamento Base, utilize a função de filtro para buscar o agendamento que deseja modificar.

Analise os resultados da pesquisa e identifique o agendamento desejado na lista exibida. Selecione o registro correspondente clicando sobre ele.

Localize o botão de ação "Alterar" na interface da tela e clique nele. Isso abrirá uma nova janela onde você poderá realizar as alterações necessárias no agendamento.

Faça as modificações desejadas nos campos que precisam ser alterados. Isso pode incluir a data, horário, tipo de movimento, cliente, descrição ou qualquer outra informação relevante relacionada ao agendamento.

Após realizar as alterações, clique no botão "OK" para confirmar e salvar as informações atualizadas do agendamento.

Excluir Agendamento Base
Essa função permite excluir um agendamento base existente do sistema.
Utilize a função de filtro para buscar o agendamento que deseja excluir. 

Analise os resultados da pesquisa e identifique o agendamento desejado na lista exibida. Selecione o registro correspondente clicando sobre ele.

Localize o botão de ação "Excluir" na interface da tela e clique nele. Uma mensagem de confirmação será exibida para garantir que você realmente deseja excluir o agendamento.

Ativar/Inativar Agendamento Base
Essa função permite ativar ou inativar um agendamento base, controlando sua disponibilidade.
