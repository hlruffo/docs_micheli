Manutenir Motorista - A.0031.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
6 - Botões de ação
Refentes as ações possíveis da Grid 2.
Incluir Motorista: Este item permite que o usuário adicione um novo motorista ao sistema, inserindo informações como nome completo, número da carteira de motorista, número de identificação, endereço, entre outros dados relevantes. Ao incluir um novo motorista, é possível criar um registro único para ele no sistema e armazenar todas as informações relevantes que o usuário deseja manter.
Alterar Motorista: Este item permite que o usuário atualize as informações de um motorista existente no sistema. Isso inclui alterar informações como endereço, número de identificação, número da carteira de motorista, entre outras. Ao alterar as informações de um motorista, o usuário pode garantir que o registro no sistema esteja atualizado e preciso.
Associar/ desassociar Motorista a transportadora: este item permite que o usuário vincule ou desvincule um motorista a uma transportadora específica. Ao associar um motorista a uma transportadora, o usuário pode garantir que todas as atividades realizadas por esse motorista dentro do terminal sejam associadas à transportadora correta. Da mesma forma, ao desassociar um motorista de uma transportadora, o usuário pode remover qualquer associação incorreta ou desatualizada.
