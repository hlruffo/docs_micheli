Manutenir Operador Modal - A.0026.00
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
4 - Botões de ação
Referentes as ações possíveis da Grid 2.
Incluir Carrier:  utilizado para cadastrar uma nova transportadora (carrier) no sistema. Para incluir uma nova transportadora, é necessário preencher as informações solicitadas na tela e salvar os dados.
Alterar Carrier: este item é utilizado para alterar os dados de uma transportadora já cadastrada no sistema. Para alterar os dados de uma transportadora, é necessário selecionar a transportadora na lista de transportadoras cadastradas, editar as informações desejadas e salvar as alterações.
Excluir Carrier: este item é utilizado para excluir uma transportadora do sistema. Para excluir uma transportadora, é necessário selecioná-la na lista de transportadoras cadastradas e clicar no botão "excluir". É importante ressaltar que a exclusão de uma transportadora pode afetar outras operações logísticas já cadastradas no sistema.
Associar/Desassociar carrier portuário a carrier rodoviário: para associar ou desassociar uma transportadora portuária a uma transportadora rodoviária. Essa associação é importante para a realização de operações logísticas que envolvem o transporte de cargas do porto para o destino final por meio de rodovias. Para associar ou desassociar as transportadoras, é necessário selecioná-las na lista de transportadoras cadastradas, clicar no botão "associar" ou "desassociar" e salvar as alterações.

Na tela Manutenir Operador Modal - A.0026.00 é possível
Pesquisar/Filtrar Operador Modal
Para buscar um Operador Modal específico na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Operador Modal
 Utilizado para cadastrar uma nova transportadora (carrier) no sistema. Para incluir uma nova transportadora, é necessário preencher as informações solicitadas na tela e salvar os dados.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

Para iniciar o cadastro de um novo carrier, é necessário selecionar o tipo de transportadora que deseja cadastrar. Para isso, o usuário deve escolher entre as opções de pessoa jurídica ou estrangeiro, conforme as informações do cadastro. Em seguida, é possível preencher as demais informações solicitadas na tela para concluir o cadastro da transportadora no sistema.
RedObrigatório 
CNPJ: Informe o documento CNPJ da transportadora que deseja fazer o cadastro;
Nome: informe o nome da transportadora;
Sigla: Defina a sigla da trasportadora. 
Essa sigla será muito utilizada durante a utilização do sistema, quando for necessário relacionar a transportadora a uma ação específica. 
Modal: Informe o modal a qual a trasportadora utiliza. 
Após preencher as informações clique em Ok para salvar o Carrier no banco. 
Alterar Operador Modal
Utilizado para alterar os dados de uma transportadora já cadastrada no sistema. Para alterar os dados de uma transportadora, é necessário selecionar a transportadora na lista de transportadoras cadastradas, editar as informações desejadas e salvar as alterações.
Para alterar as informações de um carrier já cadastrado, o usuário deve procurar o carrier desejado no filtro disponível na Grid 1. Em seguida, é necessário selecionar o carrier desejado na Grid 2 e clicar no botão de ação "alterar". Nesta etapa, é possível editar as informações desejadas e, em seguida, salvar as alterações. Dessa forma, as informações do carrier serão atualizadas no sistema de forma precisa e segura.
Excluir Operador Modal
Este item é utilizado para excluir uma transportadora do sistema. Para excluir uma transportadora, é necessário selecioná-la na lista de transportadoras cadastradas e clicar no botão "excluir". É importante ressaltar que a exclusão de uma transportadora pode afetar outras operações logísticas já cadastradas no sistema.
