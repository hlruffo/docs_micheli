Consultar Organização Operacional - A.0018.00
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
4 - Botões de ação
Refentes as ações possíveis da Grid 2.
Incluir Despachante: Este item permite que o usuário adicione um novo despachante ao sistema, inserindo informações como nome completo, número de identificação, endereço, entre outros dados relevantes. Ao incluir um novo despachante, é possível criar um registro único para ele no sistema e armazenar todas as informações relevantes que o usuário deseja manter.
Alterar Despachante: Este item permite que o usuário atualize as informações de um despachante existente no sistema. Isso inclui alterar informações como endereço, número de identificação, entre outras. Ao alterar as informações de um despachante, o usuário pode garantir que o registro no sistema esteja atualizado e preciso.
Excluir Despachante: Este item permite que o usuário remova um despachante do sistema. Ao excluir um despachante, o usuário pode remover permanentemente o registro do sistema e garantir que não haja informações desnecessárias ou desatualizadas.
Associar Despachante a Transportadora: Este item permite que o usuário associe um despachante a uma transportadora específica. Ao associar um despachante a uma transportadora, o usuário pode garantir que todas as atividades realizadas por esse despachante dentro do terminal sejam associadas à transportadora correta. Essa associação pode ser necessária para fins de rastreamento e registro de atividades.

Pesquisar/Filtrar um Despachante
Para buscar um despachante específico na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar um despachante
Este item permite que o usuário adicione um novo despachante ao sistema, inserindo informações como nome completo, número de identificação, endereço, entre outros dados relevantes. Ao incluir um novo despachante, é possível criar um registro único para ele no sistema e armazenar todas as informações relevantes que o usuário deseja manter.

Redobrigatório 
Tipo: selecionar dentre as opções a que se encaixa ao despachante cadastrado. Pessoa física, pessoa jurídica ou estrangeiro. 
Documento: Informe o número de CPF do despachante, clique na lupa de pesquisa e o sistema trará o restante das informações.
Alterar Despachante
Este item permite que o usuário atualize as informações de um despachante existente no sistema. Isso inclui alterar informações como endereço, número de identificação, entre outras. Ao alterar as informações de um despachante, o usuário pode garantir que o registro no sistema esteja atualizado e preciso.
Para realizar uma alteração no cadastro de um despachante, é necessário localizá-lo na grade 2 e selecioná-lo. Em seguida, clique no botão "Alterar" e realize as mudanças necessárias nos dados.
Excluir Despachante
Este item permite que o usuário remova um despachante do sistema. Ao excluir um despachante, o usuário pode remover permanentemente o registro do sistema e garantir que não haja informações desnecessárias ou desatualizadas.
Associar Despachante a Transportadora
Este item permite que o usuário associe um despachante a uma transportadora específica. Ao associar um despachante a uma transportadora, o usuário pode garantir que todas as atividades realizadas por esse despachante dentro do terminal sejam associadas à transportadora correta. Essa associação pode ser necessária para fins de rastreamento e registro de atividades.
Para associar um despachante a uma transportadora, localize o registro desejado na grade 2 e selecione-o. Em seguida, clique no botão "Associar Despachante a Transportadora" e conclua a ação.
