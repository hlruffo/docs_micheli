1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.

Pesquisar/Filtrar uma Comissária
Para buscar uma Comissária específica na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Comissária
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

Ao preencher as informações necessárias para o cadastro, clique em OK e os dados serão armazenados no banco. 
ObrigatórioRed 
Tipo: escolher entre pessoa física, jurídica ou estrangeiro;
Documento: Após escolher um tipo esse campo será liberado para preenchimento. Preencha como numero do documento associado a Comissária a ser cadastrada, logo, clique na lupa e o campo Nome será preenchido automaticamente.
Alterar Comissária
Para efetuar a alteração de um registro de comissária, siga os passos abaixo:
Utilize o filtro disponível para facilitar a busca do registro que deseja alterar.

Após localizar o registro desejado, clique sobre ele para selecioná-lo.

Clique no botão de ação "Alterar". Imediatamente, o formulário de alteração será exibido na tela.

Faça as modificações necessárias nos campos desejados no formulário de alteração.

Para salvar as alterações, clique no botão "OK".

Excluir Comissária
Para realizar a exclusão de um registro de comissária, siga os passos abaixo:
Utilize o filtro disponível para facilitar a busca do registro que deseja excluir.

Após localizar o registro desejado, clique sobre ele para selecioná-lo.

Clique no botão de ação "Excluir". 

Após a confirmação, o sistema removerá o registro da comissária selecionada.
