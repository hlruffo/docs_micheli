Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Referentes as ações possíveis da Grid 2.
Incluir usuário: Esta funcionalidade permite que o usuário do sistema TOS inclua um novo usuário no sistema. Isso pode envolver o preenchimento de informações básicas do usuário, como nome, sobrenome, e-mail, login, senha, nível de acesso e outras informações relevantes.
Alterar Usuário: Esta funcionalidade permite que o usuário do sistema TOS inclua um novo usuário no sistema. Isso pode envolver o preenchimento de informações básicas do usuário, como nome, sobrenome, e-mail, login, senha, nível de acesso e outras informações relevantes.
Bloquear Usuário: Esta funcionalidade permite que o usuário do sistema TOS bloqueie o acesso de um usuário específico ao sistema. Isso pode ser útil em situações em que um usuário deixa a empresa ou quando há suspeita de que o acesso do usuário foi comprometido.
Novo Master: Esta funcionalidade permite que o usuário do sistema TOS crie um novo perfil de usuário com acesso total ao sistema, incluindo a capacidade de adicionar, alterar ou excluir usuários existentes. O perfil do Master geralmente é reservado para usuários de alto nível ou administradores do sistema.

Pesquisar/Filtrar Usuário 
Para buscar um usuário específico na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Usuário 
Permite que o usuário do sistema TOS inclua um novo usuário no sistema. Isso envolve o preenchimento de informações básicas do usuário, como nome, sobrenome, e-mail, login, senha, nível de acesso e outras informações relevantes.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

Após preencher as informações clique em Ok para salvar o usuário no banco.
ObrigatórioRed 
Cliente: Para iniciar o processo de cadastro do usuário, é necessário vinculá-lo a um cliente previamente cadastrado no sistema. Portanto, antes de prosseguir com o cadastro, é preciso realizar uma pesquisa pelo cliente no sistema.
CPF: Após localizar o cliente desejado, é importante informar o número de CPF do usuário a ser cadastrado. Logo após essa ação os outros campos serão liberados para preenchimento. 
Nome: Informe o nome do usuário.
E-mail: Preencha o campo com o e-mail do usuário e confirme o e-mail no campo ao lado. 
Senha: Senha: Por favor, escolha uma senha forte. Lembre-se de usar uma combinação de letras maiúsculas e minúsculas, números e símbolos, além de evitar sequências óbvias ou informações pessoais. Uma senha forte pode ajudar a proteger suas informações pessoais e garantir a segurança do sistema. Confirme a senha no campo ao lado.
opcionalBlue 
Ramal: Informe o Ramal que corresponde ao usuário. 
Celular: Informe o numero de celular do usuário. 
RG: Informe o numero do documento RG do usuário. 
Gênero: Selecione o gênero do usuário. 
Nascimento: Informe data de nascimento.
Alterar Usuário
Esta funcionalidade permite que o usuário do sistema TOS inclua um novo usuário no sistema. Isso pode envolver o preenchimento de informações básicas do usuário, como nome, sobrenome, e-mail, login, senha, nível de acesso e outras informações relevantes.
Para realizar uma alteração no cadastro de um usuário no sistema, siga estes passos:
Utilize o filtro de pesquisa para localizar o usuário desejado.

Selecione o usuário na grid 2, que exibirá as informações detalhadas.

Clique no botão de ação "Alterar" para modificar as informações desejadas.

Dessa forma, será possível realizar as alterações necessárias no cadastro do usuário de forma fácil e rápida.
Bloquear Usuário
Esta funcionalidade permite que o usuário do sistema TOS bloqueie o acesso de um usuário específico ao sistema. Isso pode ser útil em situações em que um usuário deixa a empresa ou quando há suspeita de que o acesso do usuário foi comprometido.
Para bloquear o acesso de um usuário no sistema, siga estes passos:
Localize o registro do usuário desejado na grid ou utilize o filtro de pesquisa para encontrá-lo.

Selecione o registro do usuário que deseja bloquear.

Clique no botão de ação "Bloquear" para bloquear o acesso do usuário ao sistema.

Ao seguir esses passos, o acesso do usuário selecionado será bloqueado e ele não poderá mais realizar o login no sistema até que seu acesso seja desbloqueado novamente.
Novo Master
Esta funcionalidade permite que o usuário do sistema TOS crie um novo perfil de usuário com acesso total ao sistema, incluindo a capacidade de adicionar, alterar ou excluir usuários existentes. O perfil do Master geralmente é reservado para usuários de alto nível ou administradores do sistema.
Para conceder a um usuário o nível de acesso de MASTER, siga estes passos:
Localize o usuário desejado na grid ou utilize o filtro de pesquisa para encontrá-lo.

Selecione o usuário que deseja conceder o acesso de MASTER.

Clique no botão de ação "Novo Master".

Uma poup-up irá aparecer no seu navegador para confirmar a ação.

Confirme a ação para conceder o acesso de MASTER ao usuário.

É importante destacar que essa ação é irreversível, portanto, certifique-se de conceder o acesso de MASTER apenas a usuários que realmente precisam desse nível de acesso e que estão devidamente autorizados para tal.
