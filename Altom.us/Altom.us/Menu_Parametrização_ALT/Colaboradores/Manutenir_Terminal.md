Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis da Grid 2.
Incluir Terminal: esta ação é utilizada para cadastrar um novo terminal no sistema. Para incluir um novo terminal, o usuário deve preencher as informações solicitadas na tela, como nome do terminal, endereço e informações de contato, e em seguida, salvar os dados.
Alterar Terminal: esta ação é utilizada para alterar as informações de um terminal já cadastrado no sistema. Para isso, o usuário deve selecionar o terminal desejado na lista de terminais cadastrados, clicar no botão "alterar" e editar as informações necessárias. Após fazer as alterações, é necessário salvar os dados para que as informações sejam atualizadas no sistema.
Excluir Terminal: esta ação é utilizada para remover um terminal do sistema. Ao selecionar o terminal que deseja excluir na lista de terminais cadastrados, o usuário deve clicar no botão "excluir" e confirmar a operação na tela de confirmação. É importante ressaltar que a exclusão de um terminal pode afetar outras operações logísticas já cadastradas no sistema, portanto, é necessário ter cuidado ao executar esta ação.
5 - Botões de ação
Refentes as ações possíveis da Grid 3.
Carregar Propriedades: esta ação é utilizada para carregar as propriedades já cadastradas no sistema para um determinado terminal. Ao selecionar um terminal na lista de terminais cadastrados, o usuário pode clicar no botão "carregar propriedades" para exibir as informações já cadastradas para o terminal selecionado.
Incluir Propriedades: esta ação é utilizada para cadastrar novas propriedades para um terminal específico. Para isso, o usuário deve selecionar o terminal desejado na lista de terminais cadastrados, clicar no botão "incluir propriedades" e preencher as informações solicitadas na tela. É importante lembrar que as informações devem ser precisas e completas para evitar problemas futuros na operação logística.
Excluir Propriedades: esta ação é utilizada para remover propriedades já cadastradas para um terminal específico. Ao selecionar o terminal desejado na lista de terminais cadastrados, o usuário deve clicar no botão "excluir propriedades" e selecionar as propriedades que deseja remover. Após a seleção, o usuário deve confirmar a exclusão na tela de confirmação. É importante ter cuidado ao excluir propriedades, pois a operação pode afetar outras informações cadastradas no sistema.

Grid Propriedades
Carregar Propriedades
Esta ação é utilizada para carregar as propriedades já cadastradas no sistema para um determinado terminal. Ao selecionar um terminal na lista de terminais cadastrados, o usuário pode clicar no botão "carregar propriedades" para exibir as informações já cadastradas para o terminal selecionado.
Incluir Propriedades
Esta ação é utilizada para cadastrar novas propriedades para um terminal específico. Para isso, o usuário deve selecionar o terminal desejado na lista de terminais cadastrados, clicar no botão "incluir propriedades" e preencher as informações solicitadas na tela. É importante lembrar que as informações devem ser precisas e completas para evitar problemas futuros na operação logística.
Para incluir propriedades no terminal selecionado, siga os seguintes passos:
Selecione o terminal desejado na lista disponível na tela.

Desça até a grid 3 e clique no botão "Incluir" para adicionar uma nova propriedade.

Informe a chave e o valor correspondente à propriedade que deseja incluir.

Clique em "Salvar" para completar a ação.

Certifique-se de que todas as informações inseridas estejam corretas antes de salvar a propriedade.
Excluir Propriedades
Esta ação é utilizada para remover propriedades já cadastradas para um terminal específico. Ao selecionar o terminal desejado na lista de terminais cadastrados, o usuário deve clicar no botão "excluir propriedades" e selecionar as propriedades que deseja remover. Após a seleção, o usuário deve confirmar a exclusão na tela de confirmação. É importante ter cuidado ao excluir propriedades, pois a operação pode afetar outras informações cadastradas no sistema.
