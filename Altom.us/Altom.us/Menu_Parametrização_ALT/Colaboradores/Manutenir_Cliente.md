Manutenir Cliente - A.0023.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis da Grid 2.
Incluir Cliente: Permite cadastrar um novo cliente no sistema. É necessário preencher os campos obrigatórios, como nome e CPF/CNPJ, para concluir o cadastro.
Alterar Cliente: Possibilita a alteração das informações já cadastradas para um cliente específico. É necessário selecionar o cliente desejado e, em seguida, atualizar as informações desejadas.
Excluir Cliente: Permite a exclusão de um cliente já cadastrado. É necessário selecionar o cliente e confirmar a exclusão.
Aprovar Cliente: Permite aprovar um cliente que ainda está pendente de aprovação no sistema. É necessário selecionar o cliente desejado e confirmar a aprovação.
Reprovar Cliente: Permite reprovar um cliente que ainda está pendente de aprovação no sistema. É necessário selecionar o cliente desejado e informar o motivo da reprovação.
Associar/Desassociar Cliente a Despachante: Possibilita a associação ou desassociação de um cliente a um despachante cadastrado no sistema. É necessário selecionar o cliente e o despachante desejados e confirmar a associação ou desassociação.
Associar/Desassociar Cliente a Carrier: Possibilita a associação ou desassociação de um cliente a um carrier cadastrado no sistema. É necessário selecionar o cliente e o carrier desejados e confirmar a associação ou desassociação.
6 - Botões de ação
Refentes as ações possíveis da Grid 3.
Os botões de ação variam conforme a aba selecionada.

Pesquisar/Filtrar um Cliente
Para buscar um cliente específico na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
