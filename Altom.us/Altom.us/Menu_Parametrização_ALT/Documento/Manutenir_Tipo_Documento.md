Manutenir Tipo Documento - A.0014.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Referentes as ações possíveis da Grid 2.
Cadastrar Tipo Documento: Nessa funcionalidade, o usuário terá a possibilidade de fornecer informações relevantes para criar um novo tipo de documento.
 Alterar Tipo documento:
permite ao usuário atualizar ou corrigir os dados relacionados a um tipo de documento.
Excluir Tipo documento:
Ao selecionar essa opção, o usuário poderá eliminar permanentemente um tipo de documento.
Associar/desassociar Tipo documento: possível associar um tipo de documento a um processo específico, de modo que ele seja automaticamente atribuído aos documentos criados nesse processo.
6 - Botões de ação
Referentes as ações possíveis da Grid 3.
Carregar Propriedades: Carregar propriedades associadas ao registro de Tipo Documento selecionado na grid 2. 
Incluir propriedades: Utilizado pra cadastrar propriedades associadas ao registro de Tipo Documento que deseja inserir as propriedades. 
Excluir propriedades: Utilizado pra excluir um registro de propriedades que pode ser encontrado na Grid 3.

Pesquisar/Filtrar um Tipo Documento
Para buscar um Documento específico na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Tipo Documento
Nessa funcionalidade, o usuário terá a possibilidade de fornecer informações relevantes para criar um novo tipo de documento.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed 
Nome: Nomeei o tipo documento a ser cadastrado.
Entrada/Saída: Informe se o Tipo documento é de entrada ou saída.
Sigla: Informe a Sigla correspondente ao documento.
Categoria: Selecione entre as categorias disponíveis 
Modal: Selecione o(os) modal(is) que corresponde ao Tipo documento a ser cadastrado.
Tipo saída: Caso tenha selecionado SAIDA no campo de Entrada/saída, selecione aqui o tipo da saída.
Alterar Tipo documento
permite ao usuário atualizar ou corrigir os dados relacionados a um tipo de documento.
Busque pelo registro do tipo de documento que deseja alterar.

Selecione o registro desejado.

Em seguida, clique no botão de ação "ALTERAR".

Uma janela pop-up será aberta, exibindo um formulário de alteração.

Faça as modificações desejadas nas informações do tipo de documento.

Após realizar as alterações, clique em "OK" para salvar a ação.

Excluir Tipo documento
Ao selecionar essa opção, o usuário poderá eliminar permanentemente um tipo de documento.
Busque pelo registro do tipo de documento que deseja excluir.

Selecione o registro desejado.

Em seguida, clique no botão de ação "EXCLUIR".

Uma janela de confirmação será exibida, solicitando a confirmação da exclusão.

Verifique novamente se o tipo de documento selecionado é o correto e confirme a exclusão.

Após confirmar a exclusão, o tipo de documento e todas as informações associadas serão permanentemente removidos do sistema.

Associar/desassociar Tipo documento 
possível associar um tipo de documento a um processo específico, de modo que ele seja automaticamente atribuído aos documentos criados nesse processo.
Busque pelo registro do tipo de documento que deseja associar ou desassociar.

Selecione o registro desejado.

Em seguida, clique no botão de ação "Associar/Desassociar".

Uma janela será aberta, exibindo as opções de associação ou desassociação.

Selecione o contexto ou processo no qual deseja associar o tipo de documento, ou escolha a opção de desassociar, caso já esteja associado.

Após fazer a seleção adequada, clique em "OK" para salvar a ação.
