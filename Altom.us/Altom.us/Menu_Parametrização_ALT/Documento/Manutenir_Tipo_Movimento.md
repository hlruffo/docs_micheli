Pesquisar/Filtrar um Tipo Movimento
Para encontrar um Tipo Movimento específico, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão “PESQUISAR” para obter todas as informações pré-existentes na tela.
Cadastrar Tipo Movimento
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Após preencher as informações clique no botão OK para salvar o registro.
RedObrigatório 
Nome: insira o nome do Tipo movimento. Ex: ARMAZENAGEM CARGA GERAL
Classe Carga: Selecione o tipo de carga. Carga, Granel ou Contêiner.
Categoria: Selecione a categoria do Movimento
Cor: Defina uma cor para esse tipo movimento. Isso ajudará a identifica-lá facilmente.
Blueopcional 
Tipo: Selecione o tipo correspondente a esse Tipo Movimento.
Sigla: Defina uma sigla.
Alterar Tipo Movimento
Para modificar um registro de Tipo Movimento:
Utilize a ferramenta de filtro para localizar o registro do tipo de movimento que deseja alterar.

Selecione o registro correspondente na Grade 2.

Clique no botão “Alterar” para acessar a opção de edição.

Faça as alterações necessárias nas informações do tipo de movimento.

Após as modificações, clique em “Ok” para confirmar as alterações e atualizar o registro. 

Excluir Tipo Movimento
Para modificar um registro de Tipo Movimento:
Utilize a ferramenta de filtro para localizar o registro do tipo de movimento que deseja alterar.

Selecione o registro correspondente na Grade 2.

Clique no botão “Excluir”.

Clique em “Ok” para confirmar.

Carregar Propriedades
Para carregar as propriedades, siga estes passos:
Na Grade 2, selecione o registro para o qual deseja visualizar as propriedades.

Role para baixo até a Grade 3.

Clique no botão de ação "Carregar" para carregar as propriedades correspondentes ao registro selecionado.

Incluir Propriedades
Para adicionar uma nova propriedade, siga os passos abaixo:
Selecione o registro desejado na Grade 2, para o qual deseja incluir propriedades.

Role para baixo até a Grade 3.

Preencha os campos 'CHAVE' e 'VALOR' com as informações relevantes da nova propriedade que deseja adicionar.

Clique no botão de ação 'Incluir' para adicionar a propriedade ao registro selecionado.

Excluir Propriedades
Para excluir as propriedades, siga estes passos:
Na Grade 2, selecione o registro para o qual Excluir as propriedades.

Role para baixo até a Grade 3.

Clique no botão de ação “Carregar” para carregar as propriedades correspondentes ao registro selecionado.

Selecione um registro de propriedade que deseja excluir e clique no botão de ação ''OK'' para finalizar.
