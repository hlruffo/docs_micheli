Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.

Na tela Manutenir Veículo - A.0036.00 é possível
Pesquisar/Filtrar uma Linha de Serviço
Para encontrar uma linha de Serviço especifica, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Cadastrar Linha de Serviço
Preencha os campos, conforme descrição abaixo.
Redobrigatório  Blueopcional  

Clique no botão Incluir da Grid 2 (+).

Ao clicar em OK as informações serão salvas no sistema. 
Redobrigatório 
Terminal: Pesquise pelo terminal responsável pela linha de serviço. O terminal deve estar cadastrado na tela de Manutenir Terminal.

Nome: Defina um nome para a linha de serviço. Ex: ABAC CONOSUR.

Sigla: Defina uma sigla conforme o nome definido anteriormente. Ex: COS.

Cor: defina uma cor pára a linha de serviço.

Blueopcional 
Constante: defina uma constante. Ex: COS-STD

Alterar Linha Serviço
Permite ao usuário modificar as informações de uma Linha de serviço previamente cadastrado no sistema. Ao selecionar essa opção, será exibido um formulário que permite a edição dos dados do veículo.
Selecione o registro no qual você deseja fazer a alteração.

Clique no botão de ação "Alterar".

Faça as modificações desejadas nas informações.

Após realizar as alterações, clique em "OK" para concluir a ação.

Excluir Veiculo
Permite ao usuário remover uma linha de serviço previamente cadastrado no sistema. Ao selecionar essa opção, o usuário é solicitado a confirmar a exclusão da Linha de Serviço.
Selecione o registro no qual você deseja Excluir.

Clique no botão de ação "Excluir" → 

Após realizar as alterações, clique em "OK" para concluir a ação.

Carregar Propriedades
Essa opção permite ao usuário importar propriedades atualizadas de uma linha de serviço especifica para o sistema. O sistema então processará essas propriedades e exibirá na tela informações como Chave e Valor.
Na grid 2, selecione o registro da linha de serviço desejada.

Desça a tela até a grid 3, onde você encontrará a aba de “Propriedades”.

Clique no botão de ação “Carregar” → 

O sistema iniciará o processo de carregamento das propriedades associadas a Linha de Serviço selecionada.

Incluir Prioridades
Essa opção permite ao usuário adicionar prioridades específicas a uma Linha de serviço registrada no sistema. Ao selecionar essa opção, o usuário pode escolher uma prioridade predefinida ou criar uma nova prioridade personalizada e associá-la a linha selecionado. Essa funcionalidade auxilia na organização e no planejamento de atividades relacionadas à manutenção e ao gerenciamento das Linhas de Serviço no sistema TOS+.
Na grid 2, selecione o registro do veículo no qual deseja adicionar as propriedades.

Desça a tela até a grid 3 “Propriedades”. 

Na aba “Propriedades”, informe o valor e a chave da propriedade que deseja adicionar.

Após preencher o valor e a chave, clique no botão de ação “Incluir” para adicionar a propriedade a Linha de Serviço. → 

O sistema processará a inclusão da propriedade e ela será associada a Linha de Serviço selecionada.

Certifique-se de salvar as alterações, se necessário, para que as propriedades adicionadas sejam devidamente registradas e reflitam as informações relevantes da Linha de Serviço no sistema.
Excluir Propriedades
Essa opção permite ao usuário remover propriedades específicas de uma Linha de serviço registrada no sistema. Ao selecionar essa opção, o usuário terá acesso a uma lista das propriedades da Linha de serviço e poderá selecionar quais propriedades deseja excluir. Após a confirmação, as propriedades selecionadas serão removidas do sistema, e as informações correspondentes serão atualizadas de acordo.
Carregue as propriedades disponíveis.

Na lista de propriedades carregadas, selecione aquela que deseja excluir.

Clique no botão de ação “Excluir”. → 

Uma mensagem de confirmação será exibida para garantir a exclusão da propriedade selecionada. 

Clique em “OK” para confirmar e concluir a ação de exclusão.
