Manutenir Composição - A.0033.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis da Grid 2.
Incluir Composição: Ao selecionar essa ação, você pode inserir os dados necessários para criar uma nova composição.
Alterar Composição: Essa opção permite modificar os dados de uma composição de transporte existente. Ao selecionar essa ação, você pode fazer alterações nos detalhes da composição, como veículo, carga, itinerário, entre outros, para manter as informações atualizadas.
Excluir Composição: Ao selecionar essa ação, você pode excluir uma composição específica, removendo-a do banco de dados. Tenha cuidado ao usar essa opção, pois a exclusão é permanente.
Iniciar Composição: Essa opção permite iniciar a execução de uma composição de transporte. Ao selecionar essa ação, você marca a composição como em andamento, indicando que o veículo e a carga associada estão prontos para seguir o itinerário definido.
Terminar Composição: Essa opção permite encerrar a execução de uma composição de transporte. Ao selecionar essa ação, você finaliza a composição, indicando que o veículo e a carga associada completaram o itinerário definido com sucesso.
Carregar Dado de um Veículo: Essa opção permite carregar os dados de um veículo específico no sistema TOS+. Ao selecionar essa ação, você pode inserir as informações relevantes do veículo, como características técnicas, capacidade, status de disponibilidade, entre outros, para utilizá-las nas composições de transporte.
6 - Botões de ação que resultam informações na Grid 3
Cada botão tem uma ação específica, representada nas imagens abaixo.
As ações mudam conforme a aba selecionada.
→ Aba Composição de Transporte
Incluir Composição transporte: Ao selecionar essa ação, você pode inserir os dados necessários para criar uma nova composição.
Excluir Composição transporte: Ao selecionar essa ação, você pode excluir uma composição específica, removendo-a do banco de dados. Tenha cuidado ao usar essa opção, pois a exclusão é permanente.
Ativar/Inativar Composição transporte: essa opção permite ativar ou inativar uma composição de transporte no sistema. Ao selecionar essa ação, você pode alternar o status da composição entre ativo e inativo. Quando uma composição está ativa, ela está disponível para ser utilizada nas operações de transporte. Já quando uma composição está inativa, ela não pode ser utilizada, mas suas informações ainda estão armazenadas no sistema.
Carregar Composição transporte: Essa opção permite carregar as informações de uma composição de transporte no sistema. Ao selecionar essa ação, você pode fornecer os dados relevantes da composição.
→ Aba Tipo de composição
Incluir Tipo de composição: permite adicionar um novo tipo de composição ao sistema. Ao selecionar essa ação, você pode inserir as informações necessárias para definir um novo tipo de composição, como nome, descrição, atributos específicos, entre outros.
Excluir Tipo de composição: Essa opção permite remover um tipo de composição existente do sistema. Ao selecionar essa ação, você pode excluir um tipo de composição específico, removendo-o do banco de dados. Tenha cuidado ao usar essa opção, pois a exclusão é permanente.
Alterar Tipo de composição: permite modificar os dados de um tipo de composição existente. Ao selecionar essa ação, você pode fazer alterações nos detalhes do tipo de composição, como nome, descrição, atributos, para manter as informações atualizadas.
Carregar Tipo de composição: permite carregar as informações de um tipo de composição no sistema. Ao selecionar essa ação, você pode fornecer os dados relevantes do tipo de composição.

Pesquisar/Filtrar uma Composição
Para encontrar uma composição especifica, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão "PESQUISAR" para obter todas as informações pré-existentes na tela.
Cadastra Composição 
Ao selecionar essa ação, você pode inserir os dados necessários para criar uma nova composição.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir da Grid 2 (+).

Redobrigatório 
Nome: Informe o nome da composição.
Modal: Selecione o modal correspondente. Rodoviário, Portuário, ferroviário, aeroviário e Mecanoviário. 
Transportadora: Busque pela transportadora responsável pela composição. 
Transporte Movimento: Busque o transporte Movimento.
Tipo de Composição: Selecione o tipo de composição: carrossel interno ou Externo.
Clique em OK pra gravar as informações no banco.
Alterar Composição
Essa opção permite modificar os dados de uma composição de transporte existente. Ao selecionar essa ação, você pode fazer alterações nos detalhes da composição, como veículo, carga, itinerário, entre outros, para manter as informações atualizadas.
Selecione o registro da composição que você deseja modificar.

Clique no botão de ação "Alterar".

Faça as alterações desejadas nas informações da composição.

Após realizar as alterações, clique em "OK" para confirmar as modificações.

Excluir Composição
Ao selecionar essa ação, você pode excluir uma composição específica, removendo-a do banco de dados. Tenha cuidado ao usar essa opção, pois a exclusão é permanente.
Selecione o registro da composição que você deseja Excluir.

Clique no botão de ação "Excluir".

Após realizar as alterações, clique em "OK" para confirmar a ação.

Iniciar Composição
Essa opção permite iniciar a execução de uma composição de transporte. Ao selecionar essa ação, você marca a composição como em andamento, indicando que o veículo e a carga associada estão prontos para seguir o itinerário definido.
Selecione o registro da composição que você deseja iniciar.

Clique no botão de ação "Iniciar".

Após clicar em "Iniciar", o registro da composição será ativado e a execução da composição terá início.

Terminar Composição
Essa opção permite encerrar a execução de uma composição de transporte. Ao selecionar essa ação, você finaliza a composição, indicando que o veículo e a carga associada completaram o itinerário definido com sucesso.
Selecione o registro da composição que você deseja encerrar.

Clique no botão de ação "Terminar".

Após clicar em "Terminar", a composição iniciada será interrompida e encerrada.

Carregar Dado de um Veículo
Essa opção permite carregar os dados de um veículo específico no sistema TOS+. Ao selecionar essa ação, você pode inserir as informações relevantes do veículo, como características técnicas, capacidade, status de disponibilidade, entre outros, para utilizá-las nas composições de transporte.
Na grid 2, selecione o registro de transporte desejado.

Role a tela até a grid 3.

Na aba "Composição de transporte", localize e selecione o registro que você deseja carregar as informações do veículo.

Clique no botão de ação "Carregar".

Após clicar em "Carregar", as informações detalhadas do veículo serão exibidas na grid 3.
