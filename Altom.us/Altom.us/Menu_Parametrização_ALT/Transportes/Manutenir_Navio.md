Manutenir Navio - A.0032.00
Descrição das áreas/campos da Tela
Clique na imagem para uma melhor visualização.
1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vem do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Refentes as ações possíveis da Grid 2.
Incluir Navio: Este item permite que o usuário adicione um novo navio ao sistema, inserindo informações como nome, capacidade, entre outros dados relevantes. Ao incluir um novo navio, é possível criar um registro único para ele no sistema e armazenar todas as informações relevantes que o usuário deseja manter.
Alterar Navio: Este item permite que o usuário atualize as informações de um navio existente no sistema. Isso inclui alterar informações como comprimento, altura, capacidade, entre outras. Ao alterar as informações de um navio, o usuário pode garantir que o registro no sistema esteja atualizado e preciso.
Excluir Navio: Este item permite que o usuário remova um navio do sistema. Ao excluir um navio, o usuário pode remover permanentemente o registro do sistema e garantir que não haja informações desnecessárias ou desatualizadas. No entanto, deve-se ter cuidado ao excluir navios, pois isso pode impactar outras informações no sistema.
6 - Botões de ação
Refentes as ações possíveis da Grid 3.
Carregar Propriedades: Esta funcionalidade permite que o usuário carregue as propriedades de um navio a partir de um registro existente na primeira grid. 
Excluir Propriedades: Esta funcionalidade permite que o usuário remova propriedades de um navio existente no sistema. Por exemplo, se uma determinada propriedade não for mais relevante ou precisa ser atualizada, o usuário pode excluí-la.
Incluir Propriedades: Esta funcionalidade permite que o usuário adicione novas propriedades a um navio existente no sistema. Por exemplo, o usuário pode incluir informações adicionais sobre o peso máximo suportado pelo navio, ou qualquer outra informação relevante.
Essas funcionalidades estão disponíveis em uma grade separada na tela "Manter Navio", onde o usuário pode visualizar e gerenciar todas as propriedades de um navio. Ao utilizar essas funcionalidades, o usuário pode manter um registro completo e atualizado das informações do navio.

Pesquisar/Filtrar um Navio
Para buscar um Navio específico na tela de filtro, basta inserir qualquer uma das informações disponíveis para preenchimento. Se desejar pesquisar todos os dados disponíveis na tela, deixe todos os campos em branco e clique no botão 'Pesquisar', como mostrado na imagem abaixo.
Cadastrar Navio
Este item permite que o usuário adicione um novo navio ao sistema, inserindo informações como nome, capacidade, entre outros dados relevantes. Ao incluir um novo navio, é possível criar um registro único para ele no sistema e armazenar todas as informações relevantes que o usuário deseja manter.
Preencha os campos, conforme descrição abaixo.

Clique no botão Incluir (+).

obrigatórioRed 
Nome: insira o nome do navio
Classe: selecione a classe do navio. Escolha entre Carga, Autoridade, Passageiro ou Diversos.
Classe carga: selecione a classe de carga do navio. Escolha entre container, carga ou granel;
IMO ID: insira o número de identificação IMO (Organização Marítima Internacional) do navio, sendo um número de sete dígitos atribuído a cada navio registrado.
País: país de registro do navio.
Chamada: insira o nome do porto de chamada do navio, porto onde o navio fará sua primeira parada após a partida.
opcionalBlue
Spec: Este campo permite que o usuário insira informações adicionais sobre o navio, como a capacidade de carga, o número de tripulantes, entre outros.
Comprimento: insira o comprimento total do navio, em metros.
Largura:  insira a largura total do navio, em metros.
Ano Construção: insira o ano em que o navio foi construído.
Porte: insira o porte bruto do navio, que é uma medida da capacidade de carga do navio, em toneladas de peso morto (DWT).
Arqueação Bruta:  insira a arqueação bruta do navio, que é uma medida do volume interno do navio, em unidades de arqueação bruta (GT).
Arqueação Líquida: insira a arqueação líquida do navio, que é uma medida do espaço disponível para carga, em unidades de arqueação líquida (NT).
Alterar Navio
Este item permite que o usuário atualize as informações de um navio existente no sistema. Isso inclui alterar informações como comprimento, altura, capacidade, entre outras. Ao alterar as informações de um navio, o usuário pode garantir que o registro no sistema esteja atualizado e preciso.
Selecione o registro navio que deseja alterar, clique no botão de ação ‘Alterar’ e modifique as informações desejadas.
Excluir Navio
Este item permite que o usuário remova um navio do sistema. Ao excluir um navio, o usuário pode remover permanentemente o registro do sistema e garantir que não haja informações desnecessárias ou desatualizadas. No entanto, deve-se ter cuidado ao excluir navios, pois isso pode impactar outras informações no sistema.
Carregar Propriedades
Esta funcionalidade permite que o usuário carregue as propriedades de um navio a partir de um registro existente na segunda grid. 
Para carregar as propriedades do navio, selecione o registro correspondente na grid 2 e, em seguida, desça a tela até a grid 3. Clique no botão "Carregar" e as informações referentes ao navio serão exibidas na grid 3.
Incluir Propriedades
Esta funcionalidade permite que o usuário adicione novas propriedades a um navio existente no sistema. Por exemplo, o usuário pode incluir informações adicionais sobre o peso máximo suportado pelo navio, ou qualquer outra informação relevante.
Excluir Propriedades
Esta funcionalidade permite que o usuário remova propriedades de um navio existente no sistema. Por exemplo, se uma determinada propriedade não for mais relevante ou precisa ser atualizada, o usuário pode excluí-la.
