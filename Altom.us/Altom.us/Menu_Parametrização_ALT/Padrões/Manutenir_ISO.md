1 - Campo filtro
Permite aos usuários restringirem ou filtrarem os dados exibidos na Grid 2, com base em critérios específicos determinados por esta tela. Esses critérios podem ser inseridos nos campos de filtro pelo usuário manualmente, selecionando opções pré-definidas ou inserindo valores específicos em seus respectivos campos mostrados acima.
2 - Campo de resultados do filtro (1)
Exibe os resultados de um filtro aplicado a um conjunto de dados ou informações fornecidas no campo 1. As informações vêm do banco de dados do TOS+.
3 - Campo de resultados da Grid 2
De acordo cem os resultados da Grid 1, o usuário pode carregar e pesquisar informações de um dado específico da Grid anterior.
4 - Botões de ação referentes ao filtro
Os botões de ação podem ser acionados quando alguma informação é cedida ao filtro.
O botão de ação PESQUISA pode ser acionado sem nenhuma informação cedida ao filtro. Feito isso, o sistema trará todas as informações referentes a esta tela.
5 - Botões de ação
Referentes as ações possíveis na Grid 2.

Pesquisar/Filtrar Código ISO
Para encontrar um Código ISO, basta inserir as informações desejadas no campo de busca desta tela. Você pode realizar a pesquisa de forma específica, preenchendo os filtros disponíveis, ou de forma geral, deixando o filtro em branco e clicando no botão “PESQUISAR” para obter todas as informações pré-existentes na tela.

Código: informe o código ISO correspondente [International Organization for Standardization]. Ex: 45G1

Grupo ISO: selecione o/os Grupos ao qual o código ISO está associado. Dry Box, High Cube, Reefer, Open Top, Flat Rack, Platform, Tank ou General Purpose.

Descrição: Descreva o ISO. Ex: PLATFORM BASED CONTAINERS WITH INCOMPLETE SUPERSTRUCTURE

Formato: Selecione o formato do ISO. EX: 

opcionalBlue 
Forneça informações como Altura (em Cm e Pes), Tara e Peso Máximo. São informações Opcionais, mas importantes para uma melhor classificação do ISO.
Alterar Código ISO
Basta selecionar o Código ISO que deseja alterar;

Clicar no botão de ação "Alterar" → 

Isso permitirá realizar as alterações desejadas no registro do Código ISO selecionado.

Clique em OK e o sistema gravá as informações no banco.
Excluir Código ISO
Basta selecionar o Código ISO que deseja Excluir;

Clicar no botão de ação "Excluir" → 

Clique em OK e o sistema gravá as informações no banco.
